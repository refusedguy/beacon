# Рабочие каталоги агентов

Здесь живут worktree для агентов. Правила взяты из скилла night-shift-manager.

Один агент получает одну ветку и один worktree. Агент работает только в своём worktree и только с файлами из поля «Владелец файлов» своей карточки.

Команды создания worktree:

```
git worktree add worktrees/<имя> feature/<имя>
```

Перед созданием убедись, что ветка ещё не занята другим worktree. Один branch нельзя checkout в два worktree.

Каждая выдача задания агенту содержит шесть вещей.

1. Цель. ID карточки, ожидаемый результат.
2. Периметр. Владелец файлов и чужие файлы, которые трогать нельзя.
3. База. Ветка main и свежие коммиты, на которые агент опирается.
4. Ограничения. Go, stdlib где нужно, тесты, запрет на чужие конфиги.
5. Проверка. Конкретная команда go test или измерение.
6. Выход. Условия готовности и что писать в отчёте.

Агент не делает git add . и не использует --no-verify. Стадит только свои файлы явно.

Менеджер не правит код в worktree агента. Менеджер проверяет итог командами go test и go build, затем mergeит ветку в main.

## Общий кэш зависимостей

Worktree изолированы по веткам и файлам, но зависимости не должны ставиться заново в каждом. Скрипт `tools/worktree/link-deps.sh` создаёт в worktree символические ссылки на общее хранилище `.deps-cache` в корне репозитория. Все worktree видят один и тот же каталог, а рабочие каталоги остаются раздельными. Это решение ADR 0030 пункт 5.

Линкнуть текущий worktree:

```
bash tools/worktree/link-deps.sh
```

Линкнуть все worktree репозитория сразу:

```
bash tools/worktree/link-deps.sh --all
```

Имя каталога кэша по умолчанию `node_modules`. Список задаётся повторяемым флагом `--cache-dir` или переменной `LINK_DEPS_DIRS`. Путь хранилища задаётся флагом `--cache` или переменной `LINK_DEPS_CACHE`.

Ссылки и хранилище перечислены в `.gitignore`, поэтому не попадают в diff. Повторный запуск идемпотентен: уже правильные ссылки остаются на месте. Если на пути ссылки лежит обычный файл или каталог, скрипт отказывается его заменять, чтобы не потерять данные.

Проверка карточки T3.15:

```
bash tools/worktree/link-deps.sh --self-test
```

Self-test в tmp создаёт два worktree, линкует оба на общее хранилище, пишет файл через первый и читает его через второй. Дополнительно сверяются device:inode обоих путей и то, что git игнорирует пути кэша. Скрипт не запускает go test и не является локальным гейтом.
