# W08_idempotency

## Сценарий

Идемпотентность. Ровно один вызов среды и одна квитанция на пару (obligationID, attempt).

## Проверки

- На пару (obligationID, attempt) приходится один вызов среды
- На ту же пару приходится одна квитанция
- Повтор после рестарта даёт EEXIST

## Негативный контроль

Убрать wx-claim и повторить указатель после рестарта адаптера. Число пробуждений не растёт.
