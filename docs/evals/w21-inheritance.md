# W21_inheritance

## Сценарий

Пять слоёв конфига: системный, глобальный, дальний предок, ближайший предок, BEACON_CONFIG. Системный задаёт requireApproval true, ближайший предок пытается его снять и меняет requiredChecks.

## Проверки

- ближайший предок побеждает для обычных полей
- системный requireApproval остаётся true
- массив requiredChecks заменяется, а не складывается с дальним предком
- неизвестное поле отклоняется с путём файла и JSON-указателем

## Негативный контроль

Сложить массивы предков вместо замены. Ожидаемый набор проверок не совпадает, и прогон обязан упасть.
