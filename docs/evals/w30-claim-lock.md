# W30_claim_lock

## Сценарий

Два воркера одновременно пытаются захватить одну и ту же задачу с зависимостью.

## Проверки

- Только один claim успешен
- Второй получает типизированный отказ
- Завершение задачи снимает блокировку зависимых

## Негативный контроль

Оба воркера считают себя владельцами и запускают работу дважды.
