# W24_wait_timeout_no_cancel

## Сценарий

delegate_task в режиме wait ждёт дольше таймаута, ребёнок продолжает работать.

## Проверки

- Результат содержит waitTimedOut true
- Ребёнок не отменён и позже публикует стабильный результат
- Pending question ребёнка возвращается отдельным флагом

## Негативный контроль

Таймаут wait отменяет ребёнка и теряет результат.
