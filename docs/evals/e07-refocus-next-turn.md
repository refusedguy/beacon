# E07_refocus_next_turn

## Сценарий

Изменён документ ориентации; executor работает без перезапуска; наступает граница turn.

## Проверки

- Новый контекст доставлен в следующем turn
- Без события turn этот файл не доставляется
- Медленный lookup оставляет gap и не блокирует turn

## Негативный контроль

Нет refocus-хука: изменение файла не отражается в поведении executor'а.
