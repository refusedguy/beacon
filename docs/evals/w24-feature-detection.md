# W24_feature_detection

## Сценарий

Новый TUI подключается к старому daemon без InputStream endpoints.

## Проверки

- Отсутствующий ответ показан как readError
- Нет выдуманных данных
- Клиент продолжает работать на доступных экранах

## Негативный контроль

Подставить фиктивные данные вместо отсутствующего ответа.
