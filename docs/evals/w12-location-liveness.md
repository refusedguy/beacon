# W12_location_liveness

## Сценарий

Живучесть локации. При location_idle_timeout 2 minutes адаптер исчезает из /api/plugin и wake теряется. В спайке выгрузка примерно через 2 минуты 47 секунд, при false плагин держался больше 3 минут 39 секунд.

## Проверки

- При 2 minutes адаптер исчезает из /api/plugin
- При false плагин держится больше 3 минут 39 секунд
- Ограничение задокументировано, способ смягчения проверен

## Негативный контроль

Выставить false и повторить после 3 минут тишины. Выгрузка локации не должна приводить к потере wake.
