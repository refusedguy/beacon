# E12_pagination_truncated

## Сценарий

Запрос списка с limit=100 при ровно 100 и при 234 строках.

## Проверки

- Ровно 100 не помечается truncated
- 234 даёт truncated=true и самую старую строку в ответе диагностики
- MCP и CLI согласованы

## Негативный контроль

Вернуть голый массив без маркера: тест обязан обнаружить потерю старых строк.
