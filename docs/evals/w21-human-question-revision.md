# W21_human_question_revision

## Сценарий

Вопрос показан человеку, затем изменён, затем приходит ответ со старой revision.

## Проверки

- Ответ отклонён с question_changed
- Повтор с тем же operation id идемпотентен
- Reply уходит asking seat один раз

## Негативный контроль

Принять stale ответ и показать двойное закрытие.
