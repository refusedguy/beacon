# W25_lease_release_fail

## Сценарий

Obligation закреплено за воркером, ответ потерян, аренда истекает без release.

## Проверки

- Повторный claim при живом lease отклонён
- После истечения obligation снова выглядит созданной
- fail несёт текст, видимый пользователю

## Негативный контроль

Obligation тихо висит в in-progress без причины и пути выхода.
