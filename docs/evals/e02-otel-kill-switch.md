# E02_otel_kill_switch

## Сценарий

Запуск с OTEL_SDK_DISABLED=true, с =1 и без переменной при недоступном коллекторе.

## Проверки

- true отключает OTLP, локальный NDJSON и stdout остаются
- значение 1 не отключает экспорт по спецификации OTel
- Watch регистрируется и читается во всех трёх режимах

## Негативный контроль

Коллектор выключен: приложение стартует и не падает.
