# W34_finish_grace

## Сценарий

Run получил FINISHED, но через минуту появился поздний дочерний report.

## Проверки

- Обязательство остаётся наблюдаемым в окне доза
- Поздний report доставляется родителю
- По истечении окна obligatory закрывается с явным вердиктом

## Негативный контроль

Первый FINISHED навсегда закрывает обязательство.
