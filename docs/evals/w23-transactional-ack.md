# W23_transactional_ack

## Сценарий

ack фиксируется вместе с событием, проекцией и outbox-эффектом; на середине транзакции store возвращает ошибку.

## Проверки

- Нет события, проекции и подписки при откате
- Подписчик видит событие только после коммита
- Повтор после успешного коммита не меняет состояние

## Негативный контроль

Событие публикуется до коммита и проекция обгоняет лог.
