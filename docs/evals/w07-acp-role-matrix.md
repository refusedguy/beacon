# W07_acp_role_matrix

## Сценарий

Нужно выбрать путь пробуждения для OpenCode, Cursor CLI и для редактора Zed.

## Проверки

- OpenCode и Cursor CLI speak ACP как агенты и применимы для универсального адаптера
- Zed и Cursor desktop значатся как клиенты ACP и не являются целями побуждения
- Для редактора сохраняется отдельный адаптер под его собственный API

## Негативный контроль

Попытка разбудить сессию внутри Zed средствами ACP не приводит к новой работе, потому что у Zed нет ACP-сервера.
