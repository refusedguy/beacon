# W08_stdio_mcp_no_wake

## Сценарий

Go stdio MCP-сервер пишет корректное уведомление в stdout, пока агент простаивает.

## Проверки

- Запись уведомления разрешена транспортом без активного tools/call
- Ни одно стандартное уведомление не вызывает новую итерацию LLM
- Без хост-адаптера сессия остается idle

## Негативный контроль

Heartbeat 30 с без плагина: правило 60 с тишины соблюдено, но пробуждения нет.
