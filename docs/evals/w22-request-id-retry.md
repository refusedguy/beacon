# W22_request_id_retry

## Сценарий

Клиент вызывает wake с clientRequestId, получает таймаут и повторяет тот же вызов после перезапуска процесса.

## Проверки

- Возвращается тот же receipt и тот же obligation ID
- Второй provider-эффект не запускается
- Ключ зафиксирован до внешнего вызова

## Негативный контроль

Тот же промпт без ключа создаёт вторую работу.
