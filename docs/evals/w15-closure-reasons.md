# W15_closure_reasons

## Сценарий

Попытаться закрыть обязательство без closure_reason, затем с handed_off_to без цели, затем корректно.

## Проверки

- Первые два вызова отклонены до записи
- Корректное закрытие создаёт successor
- Журнал содержит все три попытки

## Негативный контроль

Разрешить произвольный текст closure_reason и показать, чтоPSC группировка ломается.
