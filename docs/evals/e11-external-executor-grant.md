# E11_external_executor_grant

## Сценарий

Внешний ACP/hosted executor получает грант на одну строку и пытается закрыть чужую и записать ответ человека.

## Проверки

- Чужая строка недоступна
- Инструмент вне grant не зарегистрирован
- Попытка ответить за человека даёт typed denial

## Негативный контроль

Выдать общий bearer без пар объект/действие: тест обязан показать расширение прав.
