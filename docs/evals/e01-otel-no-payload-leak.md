# E01_otel_no_payload_leak

## Сценарий

Инструментированный beacon_watch_pr получает промпт с секретом и вызывает несколько wake-адаптеров.

## Проверки

- в экспортированных спанах нет текста промпта, ответа и токенов
- в лейблах метрик нет watchID, session ID, путей и полных моделей
- error.type это класс ошибки, а не её текст

## Негативный контроль

Тест намеренно кладёт prompt в атрибут и ожидает падение проверки.
