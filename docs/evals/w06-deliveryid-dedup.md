# W06_deliveryId_dedup

## Сценарий

Входящий webhook доставляет X-Webhook-ID=evt_1 дважды; затем steer с сетевой ошибкой повторяется с тем же deliveryId.

## Проверки

- Повтор по тому же ID не создаёт вторую работу
- Idempotency-Key с другим телом даёт 422, с тем же телом возвращает первый run
- Ключ зафиксирован до внешнего вызова

## Негативный контроль

Тот же промпт без deliveryId запускает второй turn, как в предупреждении Cursor про steer.
