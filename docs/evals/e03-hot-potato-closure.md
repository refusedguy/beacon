# E03_hot_potato_closure

## Сценарий

Попытка закрыть обязательство в done без причины, затем с handed_off_to без цели, затем корректное закрытие.

## Проверки

- Первые две попытки отклонены до записи
- Корректная попытка создаёт переход и audit
- Ни одна отклонённая попытка не появляется в журнале

## Негативный контроль

Разрешить done без closure_reason: валидатор нижнего уровня обязан отклонить мутацию.
