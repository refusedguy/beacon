# E05_draft_guard_no_enter

## Сценарий

В inputs_executor'a введён чужой незавершённый текст; система пытается доставить три сообщения из разных producer'ов.

## Проверки

- Enter не нажат ни разу
- Durable-записи созданы по одной на сообщение
- Статус delivered/retained различается для каждого producer

## Негативный контроль

Подменить общий guard прямым pane-write: тест должен поймать отправку чужого текста.
