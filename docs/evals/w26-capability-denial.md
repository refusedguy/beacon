# W26_capability_denial

## Сценарий

Агент запрашивает child obligation у адаптера без оркестрационного адаптера или с выключенным провайдером.

## Проверки

- Возвращается capability_denied или provider_unavailable с причиной
- Никакая очередь и никакой child run не создаются
- Дочерний режим не может быть шире родительского

## Негативный контроль

Запрос тихо уходит в несуществующую очередь.
