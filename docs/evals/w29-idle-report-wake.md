# W29_idle_report_wake

## Сценарий

Ребёнок заканчивает turn ошибкой API, пока родитель находится после конца turn в idle.

## Проверки

- Родитель просыпается по report с текстом ошибки
- Родительский run остаётся открытым
- Повторное чтение статуса не создаёт report

## Негативный контроль

Родитель спит и опрашивает статус пока не истечёт таймаут.
