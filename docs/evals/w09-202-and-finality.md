# W09_202_and_finality

## Сценарий

Hosted маршрут принял wake и сразу ответил; агент позже вернул FINISHED, но automation продолжается в следующем run.

## Проверки

- Ответ 202 не содержит результата
- Вердикт приходит отдельным событием с deliveryId
- FINISHED и IDLE не завершают задачу, завершает verdict=ready

## Негативный контроль

Считать FINISHED финалом: задача закроется до реального окончания работы, чего Cursor предостерегает.
