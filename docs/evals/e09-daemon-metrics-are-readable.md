# E09_daemon_metrics_are_readable

## Сценарий

Демон крутится с интервалом 300ms, затем выполняется beacon metrics --format json.

## Проверки

- poll_cycles_total больше нуля
- счётчик растёт между двумя чтениями
- формат json разбирается без ошибок

## Негативный контроль

Нули в свежем процессе при работающем демоне считаются провалом.
