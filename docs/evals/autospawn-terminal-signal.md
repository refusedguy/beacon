# autospawn-terminal-signal

## Сценарий

Watch получил терминальный вердикт, слот свободен, в индексе есть todo-карточка с готовыми зависимостями, main зелёный, квота доступна.

## Проверки

- Ровно один вызов spawn на один сигнал report_to_orchestrator
- cardID связан с watchID до запуска раннера
- worktree создаётся после fetch origin main
- Ни одного сообщения владельцу для заполнения слота

## Негативный контроль

Все слоты заняты. Повторный терминальный вердикт не вызывает spawn и не меняет revision.
