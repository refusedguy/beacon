# W16_wake_ladder_survives_restart

## Сценарий

Неудачная wake, затем рестарт daemon и техническая задержка больше интервала повтора.

## Проверки

- Позиция лестницы выведена из transition log
- Контент обязательства не дублируется
- Есть rung orchestrator

## Негативный контроль

Записать счётчик только в память и проверить обнуление после рестарта.
