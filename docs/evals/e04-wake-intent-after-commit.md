# E04_wake_intent_after_commit

## Сценарий

Создание строки с wake-intent, искусственный crash между транзакцией и отправкой, рестарт демона.

## Проверки

- Boot-sweep находит pending intent без факта отправки
- Отправка происходит один раз
- Повторный sweep не создаёт вторую работу

## Негативный контроль

Удалить intent при crash: работа остаётся без wake и тест обязан это обнаружить.
