# W20_policy_pinned

## Сценарий

Watch зарегистрирован с requireApproval true и хешем снимка. После регистрации агент правит .beacon/config.json в своём worktree и снимает флаг.

## Проверки

- повторное чтение политики не меняет уже записанный хеш
- мерж заблокирован без одобрения
- одобрение и новая ревизия разрешают мерж
- снимок в state dir не перезаписан правкой worktree

## Негативный контроль

Загрузить политику из worktree при каждом опросе. Одобрение перестаёт требоваться, и прогон обязан упасть.
