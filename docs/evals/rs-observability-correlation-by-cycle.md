# RS observability correlation by cycle

## Сценарий

Один прогон цикла создаёт события Watch, обязательства и квитанцию доставки. По cycleID собираются все связанные записи.

## Проверки

- найдены все события цикла
- найдена квитанция доставки
- role и adapter присутствуют в записях
- текст wake отсутствует

## Негативный контроль

Запись с чужим cycleID не попадает в выборку.
