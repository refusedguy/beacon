# E10_verify_scripts_cover_new_fields

## Сценарий

Запуск scripts/verify-beacon.sh и scripts/verify-daemon.sh в изолированном каталоге.

## Проверки

- проверки новых полей и метрик присутствуют в выводе
- код выхода 0 при корректной конфигурации
- подмена sessionID в логе приводит к ненулевому коду

## Негативный контроль

Старый набор проверок без новых полей не считается прохождением.
