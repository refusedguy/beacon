# RS MCP tools list stable across connections

## Сценарий

Два независимых соединения снимают tools/list и сравнивают результат побайтово. Проверяется уникальность имён и детерминированный порядок.

## Проверки

- оба листинга совпадают
- имена уникальны
- порядок совпадает с зафиксированным списком из десяти имён
- размер листинга равен числу байт, которое CI пересчитает после десятого инструмента

## Негативный контроль

Перестановка двух инструментов в реестре ломает проверку порядка.
