# W37_checkpoint_replay

## Сценарий

Прогон из четырёх задач прерван после второй, оператор запускает replay с третьей.

## Проверки

- Первые две задачи не выполняются повторно
- Контекст предыдущих задач доступен
- Число снимков не превышает предел

## Негативный контроль

Replay начинает весь прогон заново и дублирует эффекты.
