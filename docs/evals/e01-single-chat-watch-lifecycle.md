# E01_single_chat_watch_lifecycle

## Сценарий

Человек просит оператора следить за PR раз в час; оператор создаёт watch-строку с одноразовым таймером, таймер срабатывает, условие не выполнено, оператор перевооружает его, затем состояние выполняется и человек получает сообщение.

## Проверки

- Строка watch содержит слова человека, проверку, интервал, human address и условие остановки
- Первый fire не шлёт человеку «ничего ещё»
- После перевооружения ровно один живой таймер
- met -> сообщение с evidence-ref и закрытие строки

## Негативный контроль

Не перевооружить таймер после первого fire: watch замолкает, и тест обязан это показать, а не выдать успех.
