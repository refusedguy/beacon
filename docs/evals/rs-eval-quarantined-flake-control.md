# RS eval quarantined flake control

## Сценарий

Один стохастический кейс падает в одном прогоне из пяти и проходит в остальных четырёх.

## Проверки

- кейс блокирует выпуск
- запись в FLAKY содержит дату истечения
- при достижении лимита карантин не продлевается автоматически

## Негативный контроль

Четыре успеха из пяти считаются прохождением.
