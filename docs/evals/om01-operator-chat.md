# OM01_operator_chat

## Сценарий

Человек говорит в operator-сессию: создать команду из трёх ролей и следить за PR.

## Проверки

- Создаётся ровно одна operator-сессия проекта
- Роли получают адреса <role>@<project>
- Все уведомления приходят в эту сессию

## Негативный контроль

Каждый сабагент создаёт свою сессию и оператор теряет общую картину.
