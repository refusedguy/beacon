# eval-wake-typed-sse

## Сценарий

Подписаться на /api/v1/events, вызвать Wake и дождаться вердикта Watch. Затем отправить кадр с неизвестным именем события.

## Проверки

- Каждый кадр имеет имя из закрытого набора и версию контракта
- Полезная нагрузка разбирается в типизированную структуру без ручного разбора json.RawMessage
- Реплей по Last-Event-ID возвращает патчи после последнего snapshot
- Неизвестное имя события отклоняется явно
- Heartbeat не ломает разбор потока

## Негативный контроль

Отправить кадр с неизвестным event type. Клиент обязан сообщить об ошибке контракта, а не проигнорировать событие.
