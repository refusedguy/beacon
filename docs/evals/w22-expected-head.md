# W22_expected_head

## Сценарий

Watch дошёл до verdict=ready с HeadSHA из регистрации. Перед мержем head PR сменился, и REST-merge возвращает 409.

## Проверки

- мерж с несовпавшим head не выполняется
- запись в журнал (watchID, revision) не пишется при 409
- успешный мерж с совпавшим head пишет журнал один раз
- повтор с той же парой не вызывает второй запрос

## Негативный контроль

Убрать передачу sha в запрос мержа. Изменённый head смерживается, и прогон обязан упасть.
