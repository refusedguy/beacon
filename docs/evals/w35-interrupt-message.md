# W35_interrupt_message

## Сценарий

Turn агента прерван внешним сигналом, а затем возобновлён.

## Проверки

- В контекст агента попадает сообщение о прерывании
- Отключение настройки убирает сообщение
- Возобновление не продолжает устаревший план молча

## Негативный контроль

Агент не знает о прерывании и действует по старому плану.
