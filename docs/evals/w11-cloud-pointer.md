# W11_cloud_pointer

## Сценарий

Облачный указатель. Cursor получает указатель через beacon_wake_claim, локальный spool не смонтирован. Непроверенный спайк: доставка облачному агенту без spool не доказана.

## Проверки

- Указатель получен через beacon_wake_claim
- Доставка происходит без локального spool
- Доказательство не зависит от файловой системы

## Негативный контроль

Наставить PointerSource на локальный путь. Доставка всё равно происходит, доказательство не зависит от файловой системы.
