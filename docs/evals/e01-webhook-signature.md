# E01_webhook_signature

## Сценарий

POST на loopback receiver с неправильной подписью, без заголовка подписи и с контрольным вектором из документации GitHub.

## Проверки

- поддельная подпись даёт 401 и не создаёт строку в webhook_events
- отсутствующий X-Hub-Signature-256 даёт 401
- вектор 'It's a Secret to Everybody' / 'Hello, World!' проходит проверку
- тело больше 25 MB отклоняется до разбора JSON

## Негативный контроль

Handler без проверки подписи принимает поддельный payload и создаёт obligation.
