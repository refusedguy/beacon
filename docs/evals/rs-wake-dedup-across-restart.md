# RS wake dedup across restart

## Сценарий

Обязательство доставлено, агент прочитал вердикт, клиент перезапущен, приходит повтор того же конверта.

## Проверки

- повторный steer не отправлен
- квитанция чтения не изменена
- счётчик wake по Watch не вырос

## Негативный контроль

Повтор после рестарта создаёт новый steer по уже прочитанному вердикту.
