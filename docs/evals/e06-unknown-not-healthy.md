# E06_unknown_not_healthy

## Сценарий

Источник наблюдений executor'а недоступен; требуется статус и решение об эскалации.

## Проверки

- Активность = unknown, а не idle
- needs-input = null без authoritative source
- Эскалация не запускается по отсутствию признака

## Негативный контроль

Вернуть idle вместо unknown: тест обязан упасть на первом же assertions.
