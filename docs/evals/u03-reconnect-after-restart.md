# U03_reconnect_after_restart

## Сценарий

Демон перезапускается во время открытого TUI, сокет недоступен.

## Проверки

- TUI не выходит
- Показан статус offline
- После рестарта экран показывает новый снимок

## Негативный контроль

Оставить сокет недоступным и убедиться, что действия заблокированы.
