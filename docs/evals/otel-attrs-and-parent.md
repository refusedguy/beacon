# OTEL_ATTRS_AND_PARENT

## Сценарий

Включённый tracer создаёт родительский и дочерний спан с атрибутами и вызывает end дважды.

## Проверки

- атрибуты родителя сохранены в записи спана в порядке передачи
- дочерний спан имеет тот же trace ID и parent span ID родителя
- end идемпотентен: в Recorder ровно две записи на два спана

## Негативный контроль

Выключенный tracer с тем же вызовом Start не даёт записей и родительского контекста.
