# W31_hook_gate

## Сценарий

Хук TeammateIdle возвращает код 2 с фидбеком при попытке закрыть обязательство.

## Проверки

- Обязательство остаётся активным
- Фидбек попадает исполнителю
- Повторный запрос завершения проходит тот же gate

## Негативный контроль

Код 2 игнорируется и обязательство закрывается.
