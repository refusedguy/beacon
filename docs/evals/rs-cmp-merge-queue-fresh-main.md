# RS CMP merge queue fresh main

## Сценарий

Два PR меняют один файл. Первый зелёный и мержится. Второй должен провалиться при подготовке поверх свежего main.

## Проверки

- первый PR мержится
- второй PR не получает ready по старому снимку
- второй PR возвращается на повторную проверку

## Негативный контроль

Второй PR получает ready на основе устаревшего снимка без перепроверки.
