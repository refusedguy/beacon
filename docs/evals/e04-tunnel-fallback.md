# E04_tunnel_fallback

## Сценарий

Один активный Watch с pending check при работающем туннеле и при выключенном.

## Проверки

- с туннелем вердикт приходит за 1-3 секунды
- без туннеля вердикт приходит не позже 60 секунд
- рассылка через SSE не добавляет запросов к GitHub
- при backoff по Remaining=0 интервал растёт до 5 минут

## Негативный контроль

Постоянный polling каждые 5 секунд тратит около 4700 GraphQL-поинтов в час на 15 Watch.
