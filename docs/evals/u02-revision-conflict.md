# U02_revision_conflict

## Сценарий

Оператор жмет ack, сервер возвращает stale revision.

## Проверки

- Экран возвращает прежний снимок
- Сообщение называет конфликт revision
- Второе состояние не создано

## Негативный контроль

Вернуть тот же revision и убедиться, что ack применяется без отката.
