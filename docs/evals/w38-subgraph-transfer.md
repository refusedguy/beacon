# W38_subgraph_transfer

## Сценарий

Дочерний граф изменил состояние, родительский граф читает только общее хранилище.

## Проверки

- Обновление не считается доставленным без transfer
- Явный transfer делает результат видимым
- Конфликт двух transfer разрешён детерминированно

## Негативный контроль

Родитель считает изменения видимыми сразу и пропускает результат.
