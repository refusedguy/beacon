# E07_trace_session_last_ten_minutes

## Сценарий

Агент спрашивает, чем он занимался 10 минут назад и почему залип.

## Проверки

- beacon trace --session ses_test --since 10m возвращает wake, ack и retry с источниками
- каждая строка содержит at, watchID, revision и reason
- при отсутствии фактов команда печатает no evidence

## Негативный контроль

Вывод без доказательств или с выдуманной причиной считается провалом.
