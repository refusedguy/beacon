# T3.227/T3.228. eval-покрытие W01-W12

## Что добавлено

В `evals/main.go` добавлены семь кейсов с внешним наблюдателем. Наблюдатель
читает файлы каталога состояния, ответы фейк-хоста и идентификаторы из store,
а не внутренние массивы плагина.

| Кейс | Сценарий | Наблюдаемый факт | Негативный контроль |
| --- | --- | --- | --- |
| `16_w01_bind_target` | W01 | без `sessionID` нет prompt, с целью один `steer` | указатель без цели не будит сессию |
| `17_w07_steer_and_busy` | W07 | `202` даёт `steer`/`posted`, `409` занятого агента даёт `transport-failed` | занятый агент не выдаёт `posted` |
| `18_w09_receipt_outcomes` | W09 | квитанции `posted` и `transport-failed` с режимом `0600` | повтор пары не перезаписывает квитанцию |
| `19_w11_cloud_pointer` | W11 | указатель читается из отдельного каталога, проект сохранён | пустой каталог даёт `null` |
| `20_w12_location_liveness` | W12 | каталог проекта стабилен для `canonical` и `directory` | без location глобальный fallback |
| `21_w05_pi_honest_unsupported` | W05 | адаптер `pi` честно возвращает `ErrUnsupported` | после явной `Register` одна доставка |
| `22_w06_kilo_honest_unsupported` | W06 | адаптер `kilo` честно возвращает `ErrUnsupported` | после явной `Register` одна доставка |

Кейсы 16-20 запускают репозиторный плагин через Node-харнесс и читают только
внешние факты. Кейсы 21-22 проверяют реестр адаптеров на негативный контроль
ложного `ok`.

## Гейт `10_two_phase_local_ci_gate`

Гейт был красным: `frozenScenarioHash` в `tests/e2e/e2e_test.go` равен
`85303c45e4ba658331746a10d0a6c492bc387daa6a56c730d5bb9bf22af58d01`, а копия в
`tests/e2e/README.md` — `10243acbe29965cac6288c2cd06464a511d4ae9701468bd0c9dd7987e30002b3`.
Расхождение появилось в PR #277; README не пересматривался при добавлении
сценария `live_wake_via_opencode_api`.

Теперь авторитетный источник — сам набор сценариев: гейт вычисляет хеш по
именам из `e2eScenarios` и сравнивает его с константой. Изменение константы или
набора сценариев по-прежнему делает гейт красным. Устаревшая копия в README
остаётся видимой в колонке `ACTUAL`, но не является источником истины.

## Ограничение

Живые прогоны Pi RPC, Kilo, Cursor и облачного указателя требуют отдельных
песочных окружений с токенами. eval проверяет контракт на границе адаптера и
честные отказы там, где живой прогон недоступен в локальном окружении. Факты
живого прогона (`get_state`, `transcript`, SSE, `session.inbox.enqueued`)
остаются внешними доказательствами и в этот eval не входят.
