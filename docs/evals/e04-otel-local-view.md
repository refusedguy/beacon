# E04_otel_local_view

## Сценарий

Локальный запуск с file exporter, Jaeger и otel-lgtm без Prometheus-сервера.

## Проверки

- beacon-trace.json это NDJSON и читается jq
- дерево спанов видно в Jaeger на порту 16686
- локальный summary печатает счётчики и перцентили по имени спана

## Негативный контроль

Без коллектора приложение работает и пишет спаны в stdout.
