# W36_child_privilege_ceiling

## Сценарий

Родитель имеет read-only режим, ребёнок запрашивает write и управление расписанием.

## Проверки

- Write и управление расписанием отклонены
- Возвращён capability_denied с причиной
- Ребёнок может только ужесточить режим

## Негативный контроль

Ребёнок получает более широкие права через конфиг.
