# OM03_config_digest

## Сценарий

Исполнитель приходит с digest, не совпадающим с config_id сервера.

## Проверки

- Регистрация отклонена config_digest_mismatch
- Watch не создан
- Аудит содержит оба digest

## Негативный контроль

Watch привязывается к конфигурации, которую исполнитель не видел.
