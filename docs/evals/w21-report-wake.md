# W21_report_wake

## Сценарий

Родитель вызывает async delegate и продолжает работу; ребёнок завершается, пока родитель находится в idle после конца turn.

## Проверки

- Результат ребёнка доставляется как wake и начинает новый turn родителя
- Родительский run не закрывается завершением ребёнка
- Повторное чтение статуса не запускает новую работу
- Stop ребёнка не посылает report

## Негативный контроль

Родитель спит и опрашивает agent_status; новый turn не наступает, работа считается потерянной.
