# W08_lease_release_fail

## Сценарий

Воркер получил claim, ответ потерян, но turn ещё использует воркер.

## Проверки

- Повторный claim при живом lease отклоняется
- Release возможен только после освобождения turn
- Fail несёт текст, видимый пользователю

## Негативный контроль

Тихий таймаут без fail не даёт причины, почему воркер не поднялся.
