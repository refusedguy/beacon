# E08_two_reviewers_wave

## Сценарий

Волна из трёх срезов; два среза пытается проверить автор, третий — два независимых ревьюера.

## Проверки

- Автор не назначен reviewer ни одного среза
- Волна не seal', пока два гейта не clear на одной ревизии
- Findings содержат context-gap/judgment-gap

## Негативный контроль

Один ревьюер на волну: teст обязан отказать в seal.
