# W13_two_adapter_parity

## Сценарий

Паритет двух адаптеров. Один beacon_watch_pr обслуживается двумя мостами без правки Go-кода.

## Проверки

- Один beacon_watch_pr работает с двумя мостами
- Go-код не меняется
- Тест не находит имён агентов в internal/infra/mcp

## Негативный контроль

Добавить имя агента в internal/infra/mcp. Без правки ядра тест не находит имён агентов, один вызов работает с двумя мостами.
