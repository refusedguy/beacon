# OM02_register_seat

## Сценарий

Hosted member регистрируется по гранту с capability и notify target.

## Проверки

- Записьagent_registry содержит config_id и digest
- Токен показан один раз
- Повторная регистрация идемпотентна

## Негативный контроль

Повторная регистрация создаёт второго исполнителя и удваивает wake.
