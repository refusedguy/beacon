# W28_mailbox_validation

## Сценарий

В mailbox obligation попадает битая запись и два валидных сообщения от разных детей.

## Проверки

- Битая запись удаляется с сообщением об ошибке
- Валидные сообщения доставляются
- Отправитель получает ошибку только при неудачной записи

## Негативный контроль

Одна битая запись блокирует всю доставку.
