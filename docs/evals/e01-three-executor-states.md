# E01_three_executor_states

## Сценарий

Executor берёт карточку, сдаёт PR, ждёт вердикта, после залитого PR переходит в «закончил».

## Проверки

- наблюдаются три состояния: «в работе», «жду», «закончил»
- «жду» сохраняет активный мониторинг PR
- «закончил» отвязывает executor от мониторинга и не требует новых действий
- после «закончил» состояние остаётся видимым

## Негативный контроль

Тихий отчёт сабагента со словом waiting не означает «закончил» до залитого PR.
