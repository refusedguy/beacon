# W27_webhook_dedupe

## Сценарий

Подписанный webhook приходит дважды с тем же X-Webhook-ID, затем с тем же ключом и другим телом.

## Проверки

- Повтор с тем же ID и телом не создаёт run
- Тот же ключ с другим телом отклоняется
- Схлопывание wake не меняет источник истины в store

## Негативный контроль

Каждая доставка webhook запускает новый turn.
