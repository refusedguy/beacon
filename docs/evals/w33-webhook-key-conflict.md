# W33_webhook_key_conflict

## Сценарий

Один Idempotency-Key приходит дважды, второй раз с изменённым телом.

## Проверки

- Повтор с тем же телом возвращает исходный run
- Конфликт тела отклоняется
- Новый ключ создаёт новую работу

## Негативный контроль

Любой повтор создаёт отдельное обязательство.
