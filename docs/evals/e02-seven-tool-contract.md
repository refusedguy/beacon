# E02_seven_tool_contract

## Сценарий

Вызвать tools/list через stdio, HTTP и in-memory transport после добавления сервера.

## Проверки

- ровно десять имён
- OutputSchema у каждого
- аннотации девяти прежних инструментов сохранены
- десятый инструмент beacon_task_close аддитивный
- бюджет 64 KiB

## Негативный контроль

добавление одиннадцатого инструмента ломает тест
