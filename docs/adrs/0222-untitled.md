# ADR 222: Экспериментальные контакты под явным флагом

Статус: accepted

## Контекст

Hosted members experimental и off by default: сервер поднимается только вручную, токен выдаётся отдельно, публичный доступ не поддерживается.

## Решение

Beacon включает сетевые и внешние контакты только явной конфигурацией с минимальным грантом.

## Последствия

По умолчанию ничего не слушается вне loopback; включение фиксируется в аудите.
