# ADR 207: Артефакт привязан к ревизии кандидата

Статус: accepted

## Контекст

C1-заголовок proof drop содержит candidate_sha, artifact_type из закрытого набора и evidences; ручная укладка файла в proof/ — антипаттерн.

## Решение

Beacon хранит proof-артефакты с явной привязкой к точной ревизии кандидата и типу доказательства.

## Последствия

Ребаз требует перевыполнения доказательств; медиа без drop не считается подтверждением.
