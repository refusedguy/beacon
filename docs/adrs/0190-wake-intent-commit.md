# ADR 190: Wake-intent в транзакции, доставка после commit

Статус: accepted

## Контекст

OpenRig создаёт wake-intent в той же транзакции, что и строку/handoff, а доставку выполняет после коммита; notify-отказ не откатывает мутацию.

## Решение

Beacon пишет намерение пробуждения атомарно с обязательством и отделяет сохранение намерения от факта доставки.

## Последствия

Крах после commit оставляет intent для boot-sweep; повтор использует прежний идентификатор обязательства.
