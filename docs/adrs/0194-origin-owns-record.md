# ADR 194: Origin owns record при межхостовой передаче

Статус: accepted

## Контекст

Кросс-хостовая очередь OpenRig не использует 2PC. Строка живёт в базе целевого хоста, successor создаётся первым, source закрывается вторым, ID детерминирован из sha256.

## Решение

Beacon применяет ту же модель: at-least-once передача, идемпотентность по ключу и message-passing closure вместо распределённой транзакции.

## Последствия

Крах между шагами оставляет дубликат, который сходится повторной передачей. Обратный порядок запрещён, он теряет обязательство.
