# ADR 310: Отказ от A2A, UTCP и тяжёлого Code Mode в Go-ядре

Статус: proposed

## Контекст

Источник: docs/research/audit-04-protocols.md, раздел в. У Beacon один loopback-сервер с bearer-токеном в connection.json с режимом 0600 (internal/infra/httpapi/server.go:648-678,725-734) и один JSON-RPC формат (internal/infra/mcp/client.go:164-230). Watch, Obligation, Verdict и Ladder уже описывают жизненный цикл и доставку. Дрейф 7/9/10/11 показывает цену нескольких каталогов.

## Решение

Не вносить A2A для локального запуска, не добавлять /utcp и CLI call templates вместо шлюза, не строить песочницу JavaScript или динамический реестр инструментов внутри Go. A2A и UTCP остаются внешними протоколами.', 'Code Mode остаётся в среде агента. При необходимости удалённой оркестрации адаптер живёт на границе в cmd или отдельном infra-пакете.

## Последствия

Одна модель авторизации и один каталог инструментов. RAM не растёт за счёт второго рантайма. Домен internal/domain остаётся на stdlib. Решение фиксируется карточки PROTO-06 со статусом dropped.
