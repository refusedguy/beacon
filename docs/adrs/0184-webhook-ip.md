# ADR 184: Локальный приём webhook без публичного IP

Статус: accepted

## Контекст

Beacon работает на машине разработчика без публичного адреса. GitHub Docs рекомендует smee.io только для локального теста, ngrok даёт публичный HTTPS и Traffic Inspector с replay, cloudflared Quick Tunnel работает без аккаунта, но меняет hostname, ограничивает 200 в-flight запросов и не поддерживает SSE. Все туннели это транспорт, а не граница доверия.

## Решение

Receiver слушает только 127.0.0.1. smee, ngrok или cloudflared используются как публичный транспорт по выбору оператора. Подпись проверяется внутри Beacon даже если туннель уже проверил её. Секрет webhook'а хранится в файле с правами 0600 рядом с state. Низкочастотный Refresh остаётся обязательным fallback: 15 секунд при pending check, 60 секунд в покое, до 5 минут без подписчиков.

## Последствия

Второй credential store не появляется: токен для чтения GitHub по-прежнему один. Публичный endpoint в самом Beacon не открывается. cloudflared Quick Tunnel не годится как постоянный канал и как канал для SSE. При выключенном туннеле вердикт приходит не позже 60 секунд.
