# ADR 257: Формат отчёта research-агента по workflow

Статус: open

## Контекст

Схема в internal/infra/batchapply/apply.go требует source_reports и строки короче 600 символов.

## Решение

Финальное сообщение содержит только имя файла и счётчики.

## Последствия

Оркестратор применяет batch только после команды владельца (см. AGENTS.md:17).
