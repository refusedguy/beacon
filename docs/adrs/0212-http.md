# ADR 212: Тонкие клиенты поверх одного HTTP-контракта

Статус: accepted

## Контекст

CLI (93 команды), TUI и MCP (39 инструментов) OpenRig говорят с демоном через один DaemonClient и projections.

## Решение

Beacon держит один HTTP/RPC контракт, а CLI, TUI и MCP остаются тонкими рендерерами.

## Последствия

Новая возможность сначала появляется в контракте; дублирование бизнес-логики в клиентах запрещено.
