# ADR 205: REST и SSE как равноправный API рядом с MCP

Статус: proposed

## Контекст

Только MCP не годится для TUI, веб-клиента и внешних интеграций.

## Решение

Все доменные сервисы доступны и через REST, и через MCP, и через stdio bridge.

## Последствия

Один набор тестов на поведение для всех transport.
