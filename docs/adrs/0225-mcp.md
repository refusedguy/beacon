# ADR 225: Контракт остаётся в семи инструментах MCP

Статус: proposed

## Контекст

contract_test.go:22-28 и tool_ack.go:26-31 фиксируют ровно семь инструментов. Восьмой инструмент для состояния агента сломал бы контракт и тесты.

## Решение

Расширить StatsOutput полями byExecutorState, blocked, orphanSessions. Расширить subscribers в ListRunningOutput полями state, stateSince, parentSessionID и добавить фильтр executorState. Новый инструмент не добавляется.

## Последствия

Оркестратор видит состояния через существующие вызовы. Рост схемы ответа требует обновления contract-тестов и проверки, что старые клиенты не падают.
