# ADR 139: Turn, run и финализация как отдельные записи

Статус: proposed

## Контекст

Поздний checkpoint заставляет клиент показывать провайдера активным.

## Решение

Завершение провайдера и завершение post-turn работы пишутся отдельно. Terminal guard запрещает поздние изменения.

## Последствия

Статусы стабильны. Нужны тесты на seeded late event.
