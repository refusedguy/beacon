# ADR 221: Измерение вместо догадки о liveness

Статус: accepted

## Контекст

OpenRig отклоняет transcript-quiescence и pane-scraping как primary truth и хранит dated receipts отклонённых оракулов.

## Решение

Beacon ведёт список отклонённых эвристик с датой и причиной, чтобы не переизобретать их повторно.

## Последствия

Новый оракул проходит trial и продакшен-согласование до включения.
