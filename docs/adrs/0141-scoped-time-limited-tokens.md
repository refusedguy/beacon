# ADR 141: Токены с областью действия и сроком жизни

Статус: proposed

## Контекст

Один токен даёт доступ ко всем сессиям и живёт вечно.

## Решение

CredentialVault выдаёт токен на проект, сессию, исполнителя и capability с истечением по времени и простою.

## Последствия

Меньше последствий утечки. Требуется отзыв при освобождении сессии.
