# ADR 208: Ожидание прерывается, когда нужен человек

Статус: proposed

## Контекст

wait_result висит до таймаута, пока агент ждёт ответа на вопрос.

## Решение

Wait возвращает hasPendingQuestion и pendingApproval и заканчивается без отмены работы.

## Последствия

Человек отвечает в чате. Требуется pending request tools.
