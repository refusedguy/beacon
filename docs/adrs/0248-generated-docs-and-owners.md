# ADR 248: Сгенерированные документы и их владельцы

Статус: open

## Контекст

Harbor developer workflow: docs-artifacts. Проверено в /home/nbook/Projects/Harbor-Harness.

## Решение

Harbor: docs/DEVELOPMENT.md содержит раздел Who owns which markdown fact и таблицу фактов, а docs/BENCHMARKS.md единственное место, где фиксируется измеренное число.
