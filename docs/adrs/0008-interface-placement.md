# ADR 0008. Место интерфейсов

Статус: accepted

## Решение

Интерфейсы лежат в `internal/domain`. Domain описывает, что ему нужно от GitHub, состояния и уведомлений. Реализации лежат в `internal/infra`.

## Причина

Так domain тестируется без подмены конкретных реализаций. Это сохраняет правило, что внутренний слой не зависит от внешнего.

## Последствия

- Интерфейсы `Clock`, `Store`, `CIProvider`, `Notifier` находятся в domain.
- Infra реализует эти интерфейсы.
- Гейт из ADR 0005 проверяет, что domain не импортирует infra.
