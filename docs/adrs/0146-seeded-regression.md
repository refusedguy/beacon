# ADR 146: Seeded regression для общих путей

Статус: accepted

## Контекст

В OpenRig arteries это области, где маленькое изменение даёт большой эффект. Pull request, затрагивающий artery, добавляет stub сценарий или объясняет, почему нельзя.

## Решение

Beacon проверяет изменение общих путей парой сценариев: здоровый прогон и посеянный отказ, который обязан провалиться.

## Последствия

Покрытие только тестами impl не считается. Сценарий должен проверять наблюдаемое поведение.
