# ADR 192: Отдельные реестры runtime, identity и grants

Статус: accepted

## Контекст

OpenRig регистрирует исполнителей через карты runtime adapters, tmux metadata и whoami, host registry, human registry и MCP grants. Это разные источники истины.

## Решение

Beacon держит раздельные реестры типа адаптера, identity исполняющей сессии и прав доступа, без единого смешанного списка.

## Последствия

Решение о маршрутизации принимается по явному реестру. Отсутствие записи означает skip, а не догадку.
