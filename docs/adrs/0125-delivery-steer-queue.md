# ADR 125: Различие delivery steer и queue при приёме ввода

Статус: accepted

## Контекст

Нужно выбрать режим доставки, который будит сессию, и понять поведение при уже идущем выполнении и на границах шагов.

## Решение

steer: приём сразу планирует agent loop; если цикл идёт, ввод разбирается на следующей границе шага, не в конце очереди. По умолчанию для prompt, synthetic, compact. queue: хранится в порядке постановки и сам не планирует побуждение; interrupt с resume true оставляет queued prompts припаркованными.

## Последствия

Источники: hook работает один раз при admission; steers идут в порядке enqueue на Safe Step Boundary; при idle steers имеют приоритет. 409 в реализации - дублирующий message id, не занятость сессии. Хуки не вызываются для synthetic, shell, compaction, move.
