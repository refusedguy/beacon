# ADR 201: Лестница доказательств с повышением po prodane

Статус: accepted

## Контекст

r3 self-report, r2 хуки (Codex — после 50 согласованных наблюдений за час), r4 видимый prompt, r1 сэмплирование; fixture даёт только TRIAL.

## Решение

Beacon ранжирует источники наблюдений и повышает их доверие только по согласованным продакшен-наблюдениям.

## Последствия

Новый rung сначала изолирован, затем trial, затем участвует в решении; откат видим.
