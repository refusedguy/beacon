# ADR 186: MCP остаётся границей протокола без расширения семи инструментов

Статус: proposed

## Контекст

Контракт tools/list требует ровно семь имён и бюджет 64 KiB; новые задачи требуют новых возможностей.

## Решение

Первая версия не добавляет MCP-инструменты. Новые возможности идут через REST, SSE и внутренние сервисы.

## Последствия

Цикл агента и контракт не ломаются. часть функций доступна только через API.
