# ADR 256: Сводный ADR: workflow-практики Harbor в Beacon

Статус: open

## Контекст

В Harbor найдены слои инструкций, regression-first, gate result, rules gate, docs gate и conveyor.

## Решение

Переносить общие практики через карточки и файлы Beacon, не копировать C# и .NET детали.

## Последствия

Каждое правило имеет владельца и проверку.
