# ADR 281: Указатель wake несёт только идентификаторы

Статус: accepted

## Контекст

ADR 0017 требует, чтобы повтор нёс указатель на запись, а не содержимое. Текущий buildPromptText добавляет в prompt поля untrusted.checkName, untrusted.prTitle и untrusted.branch. Это экранированные данные, но уже не чистый указатель.

## Решение

Текст пробуждения это обёртка <beacon-event> с watchID, obligationID, revision и verdictRef. verdictRef это токен без тела проверки. Запрещено подставлять в код, агента, тип RPC или URI имена проверок и заголовки PR. Ограничение длины 512 символов.

## Последствия

Рекомендуется убрать три поля untrusted из buildPromptText и оставить только идентификаторы. Для прода нужно зафиксировать в карточке. Экранирование <, >, &, кавычек и управляющих символов уже реализовано в escapeUntrusted.
