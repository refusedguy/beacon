# ADR 199: Доставка с guard на черновик и retained

Статус: accepted

## Контекст

DraftAwareDelivery проверяет input до ввода и повторно перед Enter; при отказе сообщение остаётся retained и не replay'ится автоматически.

## Решение

Beacon применяет центральный guard на финальной границе записи ввода и различает доставлено/удержано/неопределённо.

## Последствия

Чужой черновик никогда не отправляется; повтор требует явного решения и читает запись.
