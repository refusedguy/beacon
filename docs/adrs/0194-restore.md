# ADR 194: Честный restore с перечислением исходов

Статус: accepted

## Контекст

Restore в OpenRig различает resumed, rebuilt, fresh-primed, awaiting-decision, attention_required, failed; failed откатывает пустую сессию.

## Решение

Beacon возвращает структурированный результат восстановления и не смешивает «процесс жив» с «разговор восстановлен».

## Последствия

Оператор видит конкретный исход и следующий шаг; автоматический fresh возможен только как явный выбор.
