# ADR 218: Фоновый коннектор владеет долгим запуском

Статус: accepted

## Контекст

rig exec держит состояние в $OPENRIG_HOME/acp/runs/, переживает закрытие терминала и помечает interrupted при смерти коннектора.

## Решение

Beacon выносит долгий запуск в отдельный процесс-коннектор с durable записью состояния.

## Последствия

Один run на строку; повтор без --again не отправляет работу дважды.
