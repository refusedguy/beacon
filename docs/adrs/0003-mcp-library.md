# ADR 0003. MCP библиотека

Статус: accepted

## Решение

Использовать официальный `github.com/modelcontextprotocol/go-sdk`.

## Причина

Отчёт A сравнил две библиотеки. `go-sdk` имеет формальную политику совместимости v1, выводит input и output схемы из Go-типов и не имеет пула на пять воркеров. Это важно для долгих wait_result вызовов до девяти минут. В замере на семи инструментах он требует меньше ручного кода.

Владелец согласился с рекомендацией.

## Последствия

- Схемы инструментов выводятся из Go-типов.
- `notifications/message` устарел в ревизии 2026-07-28. Для уведомлений используем `NotifyProgress` или sending middleware. Проверить спайком.
- В бинарник попадает OAuth-стек. Это цена официального SDK, около 1,4 MB после strip по замеру отчёта A.
- Требуется Go 1.25.0 или новее.

## Отклонённое

`github.com/mark3labs/mcp-go`. У него есть tasks extension и произвольные уведомления, но stdio пул на пять воркеров мешает долгим вызовам, а документация отстаёт от кода.
