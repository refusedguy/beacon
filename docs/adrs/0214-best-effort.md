# ADR 214: Best-effort уведомления с дедупом

Статус: accepted

## Контекст

NotificationDispatcher OpenRig шлёт best-effort, дедуплицирует по (qitem, mechanism) и пишет событие успеха/отказа в аудит.

## Решение

Beacon считает уведомление побочным эффектом: отказ не откатывает действие, но фиксируется как факт.

## Последствия

Ни одно уведомление не трактуется как прочтение; повтор безопасен по ключу.
