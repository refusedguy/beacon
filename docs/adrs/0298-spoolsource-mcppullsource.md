# ADR 298: Два источника указателей: SpoolSource и McpPullSource

Статус: accepted

## Контекст

Локальные плагины читают events.jsonl, а процессы вне локации и облачные агенты не имеют локального spool. Нужны два способа получить указатель без второго протокола.

## Решение

SpoolSource читает $XDG_STATE_HOME/beacon/events.jsonl, держит курсор {offset, epoch} по хешу прочитанного префикса и пропускает незавершённую строку. Перед вызовом адаптера создаёт receipts/<id>.wrote через open(path, "wx", 0o600). McpPullSource сам становится MCP-клиентом и вызывает beacon_wake_claim и beacon_wake_receipt.

## Последствия

Добавление двух инструментов меняет контракт из семи имён, поэтому нужен отдельный ADR по правилу ADR 0020. Альтернатива long-poll beacon_wait_result не рекомендуется: её семантика про вердикт агента, а не про очередь доставки.
