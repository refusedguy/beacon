# ADR 206: Классификация находок: context-gap против judgment-gap

Статус: accepted

## Контекст

Review OpenRig классифицирует каждый miss по причине и считает drift/plot-loss находкой первого класса.

## Решение

Beacon хранит причину находки ревью и использует её для калибровки инструктажа, а не только счётчика дефектов.

## Последствия

Исправление context-gap идёт в спецификацию, judgment-gap — в проверку; частота видна в метриках.
