# ADR 209: Минимальный исход против процесс-механизмa

Статус: accepted

## Контекст

Product-journey SDLC требует сначала назвать doghouse, проверить door через публичный интерфейс и только потом углубляться на один слой.

## Решение

Beacon{ssue} требует от карточки пользовательски наблюдаемый исход и запрещает разворачивать механику без доказательства.

## Последствия

Карточки без публичного признака завершения не принимаются в план.
