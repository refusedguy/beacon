# ADR 210: Версия wire-схемы и совместимость сохранённых событий

Статус: proposed

## Контекст

Старый клиент не может прочитать события после миграции схемы.

## Решение

Каждое событие имеет schema_version. Старые поля сохраняются, новые клиенты объявляют версию при подключении.

## Последствия

Апгрейд без потери истории. Нужна проверка декодируемости при старте.
