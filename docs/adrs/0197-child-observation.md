# ADR 197: Наблюдение за ребёнком без монопольного доступа к его истории

Статус: accepted

## Контекст

Devin показывает родителю саммари, а не сырой вывод ребёнка. Cursor запрещает follow-up и steer на сабэйджента и просит обратиться к родителю. Codex показывает approval из неактивного thread с меткой источника. Goose разрешает выбрать полный вывод или только финальный результат.

## Решение

Родитель получает управляемый return mode ребёнка и метку источника для запросов подтверждения. Прямое управление ребёнком со стороны третьего отправителя запрещено, если только он не адресован родителю.

## Последствия

Шумные логи ребёнка не замусоривают родительский контекст. Подтверждение не приходит из неизвестного потока. Parent остаётся единственной точкой маршрутизации.
