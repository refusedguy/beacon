# ADR 193: Конфиг пула агентов и потолок прав ребёнка

Статус: accepted

## Контекст

Codex задаёт лимит в [agents].max_concurrent_threads_per_session и не даёт кастомному агенту менять разрешения, провайдера и MCP серверы. Devin запрещает вложенность по умолчанию и требует admin-переключатель Default subagent model None для полного отключения. Goose держит лимит 5 на сессию и запрещает ребёнку порождать агентов и менять расписания. Kilo разрешает делегирование только Code, Plan и Debug. OpenCode вводит отдельное permission-действие subagent.

## Решение

Beacon хранит конфиг пула как данные: лимит параллелизма, режим ребёнка, модель, предел шагов, таймаут, список разрешённых типов. Права ребёнка только ужесточаются относительно родителя. Управление планировщиком и расписаниями ребёнку недоступно.

## Последствия

Нельзя поднять режим или модель ребёнка выше родителя. Один рост нагрузки не создаёт неограниченное дерево. Администратор может отключить делегирование без правки кода.
