# ADR 253: Сопоставление Harbor-скиллов с установленными в Beacon

Статус: open

## Контекст

Harbor developer workflow: beacon-gap-closure. Проверено в /home/nbook/Projects/Harbor-Harness.

## Решение

Проверено: в Harbor 32 уникальных имени скиллов во всех каталогах, в ~/.config/opencode/skills 64 каталога, точных совпадений имён ноль.

## Последствия

Требует карточек HD и eval HD. Правила применяются к Beacon без переноса кода Harbor.
