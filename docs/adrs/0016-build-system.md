# ADR 0016. Билд система

Статус: accepted

## Решение

Гейты собираются в один бинарник `beacon-gates` на Go. Только стандартная библиотека, без внешних модулей. Коды выхода 0 зелёный, 1 нашёл нарушение, 2 не смог запуститься. У каждого гейта есть self-test с посаженным нарушением.

Команды для владельца и агентов живут в одном бинарнике `beacon` с подкомандами. Обязательны `build`, `test`, `gates`, `list --format json`, `doctor`, `what`.

Правило кодов выхода обязательно для всех команд `beacon`, а не только для гейтов. Код 1 означает ошибку валидации пользовательского ввода: неизвестный флаг, неизвестное значение `--format`, лишний аргумент, неизвестная подкоманда или команда. Код 2 означает сбой запуска или системной операции. Неверный `--format` даёт код 1 и в `task list`, и в `list`. Раннеры берут коды из `taskstore.ExitOK`, `taskstore.ExitValidation` и `taskstore.ExitStartup` вместо числовых литералов.

## Причина

Владелец заметил, что Harbor в основном крутится в GitHub Actions. Гейт должен запускаться там, где нет ничего, кроме Go. Отчёт F показал, что в Harbor 42 гейта уже собраны в один бинарник `harbor-gates` с `go.mod` из трёх строк. Это рабочий пример для CI.

Владелец уточнил, что Harbor это пример, а не образец для точного копирования. Поэтому Fallout и NUKE не переносятся.

## Почему не just

`just` требует отдельный внешний бинарник и action в CI. `go run ./tools/beacon` не различает коды выхода 1 и 2, потому что оболочка получает 1 в обоих случаях. Один скомпилированный бинарник не имеет этих недостатков.

## Последствия

- `list --format json` даёт машиночитаемый каталог команд. Агент в opencode не придумывает команды, а спрашивает каталог.
- Каталог обязан перечислять все обязательные команды из этого решения, включая `test`. Тест `TestADR0016MandatoryCommandsInCatalogAndDispatch` проверяет наличие каждой такой команды и в каталоге, и в диспетчере.
- Машинный поток идёт в stdout, шум в stderr.
- Сборка воспроизводимая, как в Harbor: `CGO_ENABLED=0`, `-trimpath`, `-buildvcs=false`, `-ldflags="-buildid= -s -w"`.
- Гейты из ADR 0005 реализованы как подкоманды `beacon-gates`.
