# ADR 164: Реестр исполнителей с capability и потолком прав

Статус: proposed

## Контекст

Адаптеры различаются по режиму, а агент может запросить более широкие права.

## Решение

ExecutorRegistry хранит capabilities, runtime, режимы и auth state. Дочерний режим не может быть шире родительского.

## Последствия

Недоступный executor виден, но помечен недоступным. Отказы типизированы.
