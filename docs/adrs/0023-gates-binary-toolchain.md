# ADR 0023. Сборка beacon-gates и версия Go

Статус: accepted

## Решение

Закоммиченный бинарник `tools/beacon-gates/beacon-gates` собирается строго версией Go из файла `go.mod`, через `actions/setup-go@v5` с `go-version-file: go.mod`. Сейчас это Go 1.26.0.

Флаги сборки фиксированы: `CGO_ENABLED=0 go build -trimpath -buildvcs=false -ldflags="-buildid= -s -w"`.

## Причина

Первый пуш дал расхождение хешей. Локальная сборка на Go 1.27.4-X:nodwarf5 дала `c0af0eb...`, сборка в CI на Go 1.26.0 дала `d6d76a9...`. Workflow `gates-binary.yml` требует побайтового совпадения и упал. Пересборка локально через Go 1.26.0 дала хеш, совпавший с CI.

## Последствия

- Перед коммитом обновлённого бинарника гейтов собирать его версией Go из go.mod.
- При изменении версии Go в go.mod бинарник гейтов пересобирается в том же коммите.
- CI остаётся источником истины: если хеши расходятся, PR красный.
