# ADR 210: Удаление данных как аудируемый scrub/delete

Статус: accepted

## Контекст

Queue erasure различает scrub (тело удалено, строка остаётся) и delete (строка исчезает, остаётся erased-id); ledger пишется до мутации.

## Решение

Beacon реализует удаление как идемпотентный батч с ledger вне backup и разными режимами.

## Последствия

Replay после восстановления из backup воспроизводит только закоммиченные батчи; неопределённый батч требует решения.
