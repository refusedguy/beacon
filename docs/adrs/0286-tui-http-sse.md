# ADR 286: TUI как тонкий клиент HTTP и SSE

Статус: proposed

## Контекст

TUI может писать состояние напрямую и расходиться с MCP.

## Решение

TUI читает готовые проекции /api/v1 и шлёт команды REST. Прямых записей в БД нет.

## Последствия

Меньше дублирования. TUI требует работающего сервера или встроенного режима.
