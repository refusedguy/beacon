# ADR 180: Feature detection и версионный контракт клиента

Статус: accepted

## Контекст

TUI OpenRig читает только существующие daemon projections и при несовместимой версии показывает check version skew, не выдумывая данные.

## Решение

Beacon клиенты объявляют поддерживаемые возможности и деградируют честно при несовместимости с сервером.

## Последствия

Неудачные чтения видны как readErrors. Новый клиент работает со старым сервером без падения.
