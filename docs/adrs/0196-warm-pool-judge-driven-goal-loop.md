# ADR 196: Warm pool и judge-driven goal loop для долгоживущей работы

Статус: accepted

## Контекст

OpenHands Agent Server прогревает поды заранее и активирует их через POST /api/init. Goal Completion Loop использует judge-driven цикл, который продолжает работу до проверяемой цели. CrewAI hierarchical process заставляет менеджера проверять результаты до перехода к следующим задачам.

## Решение

Beacon различает готовность воркера и факт его активации, а проверку цели оформляет отдельным обязательством с судьёй, а не таймаутом ожидания.

## Последствия

Всплеск нагрузки не ждёт холодного старта. Работа не считается завершенной по истечении времени, а только по проверенному результату.
