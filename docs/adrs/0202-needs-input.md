# ADR 202: needs-input как счётчик и причина

Статус: accepted

## Контекст

OpenRig хранит needs-input как {count, reason} и отображает его через единственный мост deriveDisplayActivity.

## Решение

Beacon хранит ожидание ввода как счётчик с причиной, а не как состояние обязательства.

## Последствия

Ноль промптов без авторитетного источника не означает «чисто»; причина сохраняется.
