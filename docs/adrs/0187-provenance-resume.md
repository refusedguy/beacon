# ADR 187: Ранг provenance для resume-токена

Статус: accepted

## Контекст

OpenRig ранжирует resume-token: operator 3, hook 2, adoption 1, scrape 0; младший ранг не перезаписывает старший.

## Решение

Beacon хранит provenance вместе с токеном возобновления и запрещает понижать ранг при повторном наблюдении.

## Последствия

Скриптовый источник не может перезаписать операторский токен; при конфликте выбирается более высокий ранг.
