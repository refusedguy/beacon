# ADR 0012. Версионирование, corpus и redaction

Статус: accepted

## Решение

- `state.json` содержит поле `version`.
- Каждая строка `events.jsonl` содержит версию схемы.
- В тестах есть corpus старых файлов состояния для проверки миграций.
- Redaction работает как правило на записи и не даёт секретам попасть в состояние и логи.

## Причина

Владелец сказал, что миграции форматов вероятны. Без corpus нельзя проверить, что новая версия читает старые данные. Контракт v2 требует, чтобы токен GitHub никогда не попадал в state.json и логи. Redaction закрывает это требование в одном месте.

## Последствия

- Миграция формата проверяется на наборе зафиксированных старых файлов.
- Любая запись в состояние проходит через фильтр redaction.
- Версия в журнале позволяет понять, какой обработчик читал строку.
