# ADR 211: Событие после commit и курсор replay

Статус: accepted

## Контекст

EventBus.withNotifyEnvelope публикует сохранённые события только после коммита; SSE читает историю страницами и учитывает Last-Event-ID.

## Решение

Beacon публикует уведомления после фиксации транзакции и держит курсор для восстановления подписки.

## Последствия

Reconnect не теряет события; transient-уведомления не смещают durable watermark.
