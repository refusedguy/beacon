# ADR 220: Права как параметр запуска, а не только файл

Статус: accepted

## Контекст

OpenRig выбирает режим запуска нативно: per-launch team default, kernel default, full_bypass; rig seat set-permissions меняет будущие запуски без перезапуска.

## Решение

Beacon хранит желаемую политику отдельно от фактических аргументов запуска и не утверждает enforcement без доказательства.

## Последствия

seat status показывает оба значения; смена политики не меняет текущий процесс.
