# ADR 0021. Изоляция агентов через worktree

Статус: accepted

## Решение

Каждый агент работает в отдельном git worktree и отдельной ветке. Worktree лежат в `beacon-impl/worktrees/`. Ветки имеют вид `feature/<имя>`.

Один агент получает одну ветку, один worktree и один набор файлов по полю «Владелец файлов» своей карточки. Менеджер не правит код в worktree агента.

Выдача задания содержит шесть частей: цель с ID карточки, периметр файлов, базовая ветка, ограничения, команда проверки, условие выхода.

## Причина

Владелец попросил делать как в night-shift-manager. Там каждый агент получает свой branch и isolated workspace. Это убирает конфликты между平行 агентами и даёт менеджеру честную картинку, что именно сделано.

## Последствия

- rules в `worktrees/README.md` обязательны для всех агентов следующих волн.
- Агент не делает `git add .` и не использует `--no-verify`.
- Менеджер проверяет итог командами `go test` и `go build`, затем mergeит ветку в main.
- Коммит бинарника `beacon-gates` обязателен по Harbor и ADR 0016. Он не попадает в `.gitignore`.
