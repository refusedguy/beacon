# ADR 0010. Тесты обязательны в каждой задаче

Статус: accepted

## Решение

Каждая задача при написании обязана быть покрыта тестами. Задача без behavior-теста не считается готовой. Property-тесты и хаос-тесты выделяются в отдельные задачи, потому что им нужен готовый код.

## Причина

Владелец прямо сослался на правило Harbor. Это обязательное правило, а не рекомендация.

## Последствия

- В каждой task-карточке есть поле «проверка» с конкретным тестом.
- Готовность задачи равна артефакт плюс приёмка пройдена.
- Восемь уровней тестов из WORKER-PROMPT сохраняются.
- Гейты из ADR 0005 тоже обязаны иметь посаженное нарушение.
