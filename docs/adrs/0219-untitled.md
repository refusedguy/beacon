# ADR 219: Ребёнок не может быть привилегированнее родителя

Статус: accepted

## Контекст

t3code-соседи по экосистеме отклоняют расширение runtime/interaction mode; OpenRig фиксирует permission posture на level запуска.

## Решение

Beacon запрещает дочернему инструменту или агенту расширять права родителя и возвращает типизированный отказ.

## Последствия

Попытка эскалации записывается в аудит; понижение прав разрешено.
