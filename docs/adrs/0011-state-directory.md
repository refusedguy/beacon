# ADR 0011. Каталог состояния

Статус: accepted

## Решение

Состояние живёт в `$XDG_STATE_HOME/beacon`, то есть примерно `~/.local/state/beacon`. Конфиг лежит отдельно в `~/.config/beacon/config.json`. Переменные окружения начинаются с `BEACON_`.

## Причина

Владелец согласовал решение D9. Каталог `~/.config/opencode` это конфиг, который можно синхронизировать между машинами. Состояние конкретной машины должно жить отдельно.

## Последствия

- Права на каталог состояния 0700.
- Квитанции адаптера пишутся в подкаталог `receipts/` внутри каталога состояния.
- В конфиге OpenCode не меняется ничего без явного разрешения владельца.
