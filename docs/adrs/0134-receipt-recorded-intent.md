# ADR 134: Квитанция означает записанное намерение

Статус: proposed

## Контекст

Агент считает ack подтверждением завершения работы.

## Решение

Receipt содержит intent_committed и effect_status как отдельные поля.

## Последствия

wait_result остаётся долговечным. Требуется обновление контракта и документации.
