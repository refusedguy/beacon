# ADR 191: Раздельные факты wake, claim, pickup и прочтения

Статус: accepted

## Контекст

lastNudgeWireResult, claimedAt и pickup в OpenRig — разные поля; wake не доказывает прочтение, close не является новой квитанцией.

## Решение

Beacon хранит отдельные факты отправки, принятия, захвата и прочтения и не выводит одно из другого.

## Последствия

UI показывает оговорку при неподтверждённой доставке; эскалация не решается одним полем.
