# ADR 0007. Раскладка каталогов

Статус: accepted

## Решение

На первом этапе четыре каталога:

- `internal/domain` для Watch, Obligation, вердиктов и невариантов;
- `internal/infra` для MCP, GitHub, состояния и уведомлений;
- `internal/app` для сборки и запуска;
- `cmd/beacon` для точки входа.

Каталога `pkg` пока нет. Новый каталог добавляется только когда внутри появится больше одного файла.

## Причина

Владелец согласовал упрощённую структуру. Мелкие каталоги на старте усложняют навигацию без выгоды.

## Последствия

Правила слоёв из ADR 0005 проверяют эти четыре каталога. При росте проекта каталоги дробятся по мере необходимости.
