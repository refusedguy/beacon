# ADR 217: Внешний executor через грант, без pane

Статус: accepted

## Контекст

Hosted member OpenRig — адрес <member>@rig, MCP-грант и инструкция member-workflow/v2; listed tool не равняется доступу.

## Решение

Beacon различает инструменты, доступные по гранту, и declares grant как пары объект/действие.

## Последствия

Грант можно отозвать; работа переживает смену разговора внешнего исполнителя.
