# ADR 197: Состояние в границах проекта по resolved cwd

Статус: proposed

## Контекст

Клиент может подменить окружение или попасть в другой проект.

## Решение

Проект ключуется resolved cwd и git root. Overlay не имеет fallback в другое окружение.

## Последствия

Изоляция предсказуема. Требуется явная привязка thread к worktree и branch.
