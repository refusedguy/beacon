# ADR 195: Состояние проекта учитывается при выборе адаптера

Статус: accepted

## Контекст

AutoGen архивирован, Microsoft прямо советует миграцию в Microsoft Agent Framework. Roo Code остановлен 15 мая 2026 года. Домен amp.dev отдаёт документацию AMP HTML, а предполагаемые адреса coding-агента Amp вернули 404. Для этих трёх проектов нет подтверждённых текущих контрактов.

## Решение

Реестр адаптеров Beacon хранит статус проекта и источник факта. Архивированные и остановленные проекты не порождают карточек и не считаются текущими конкурентами. Непроверенные утверждения маркетинга не попадают в бэклог.

## Последствия

Адаптер не строится на коде проекта, который больше не поддерживается. Каждая карточка имеет проверяемую ссылку. Раздел 8 отчёта остаётся фильтром для новых идей.
