# ADR 195: Периодический snapshot как страховка, а не история

Статус: accepted

## Контекст

PeriodicSnapshotScheduler снимает auto-periodic snapshot для работающих rig'ов каждые 300 с, хранит 10 последних и пропускает запись при смене occupants во время refresh.

## Решение

Beacon периодически фиксирует восстановимую точку для активных исполнителей с пер-исполнителной изоляцией ошибок.

## Последствия

Один сбой не останавливает проход; частичный occupant set не публикуется как корректный.
