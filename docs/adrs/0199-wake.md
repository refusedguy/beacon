# ADR 199: Реестр wake-адаптеров с честной поддержкой

Статус: proposed

## Контекст

Адаптеры различаются по имени, а часть не реализована.

## Решение

Registry держит opencode, acp, pi, kilo, cursor. Неизвестное имя падает на opencode, недоступный адаптер возвращает ErrUnsupported.

## Последствия

Wake не теряется из-за плохого имени. Отказ типизирован, а не фейковым ack.
