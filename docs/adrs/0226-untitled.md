# ADR 226: Наблюдаемость не копируется как пробел

Статус: accepted

## Контекст

В ядре OpenRig нет экспорта OTel; метрики и диагностика живут в CLI/TUI поверх projections. Это recognised limitation, а не образец для копирования.

## Решение

Beacon держит структурную наблюдаемость отдельным контуром и не смешивает её с доменными таблицами.

## Последствия

MCP и демон сохраняют корреляцию; отсутствие метрик не маскируется как «всё зелёное».
