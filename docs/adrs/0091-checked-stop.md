# ADR 91: Проверенный останов исполнителя

Статус: accepted

## Контекст

Останов исполнителя убивает процесс по команде оператора. Два отказа делают его опасным. Выбор в registry успел смениться после того, как оператор решил остановить, и kill попадёт по другому исполнителю. Kill прошёл, а запись состояния сохранить не удалось, и система не знает, что уже остановлено. checked-seat-stop OpenRig читает expected перед kill, чтобы не убить чужой seat. Beacon держит ожидаемые watchID, revision, sessionID и fencing token в registry.

## Решение

Останов начинается с precondition. Команда читает из registry ожидаемые watchID, revision, sessionID и token и сравнивает их с текущими. При расхождении она возвращает selection_changed, не посылая kill. Kill уходит только при полном совпадении.

Мутации registry защищены монотонным fencing token из ADR 0037. Каждая мутация увеличивает token, и устаревший вызов не меняет запись. Token не путать с revision Watch из ADR 0019. Revision считает версии состояния, token считает аренду.

Если kill прошёл, а сохранение состояния нет, операция возвращает stop_uncertain с stopPhase и причиной. Успех печатается только после сохранения состояния. Повтор начинается с нового precondition и нового чтения expected.

## Последствия

Смена выбора останавливает команду до terminal effect: kill не уходит. Неизвестный исход не выдаётся за успех. Оператор видит фазу останова и причину и повторяет команду с актуальными ожидаемыми значениями.
