# ADR 107: Внешние толчки в чат через канал с opt-in

Статус: proposed

## Контекст

Webhook или CI может подбросить произвольный текст в активный turn.

## Решение

Channel требует capability и явное включение. Payload проверяется, экранируется и направляется ровно в одну сессию.

## Последствия

Безопасный wake без клиента. Требуется channel_reply для детерминированного ответа.
