# ADR 185: Демон как единственный владелец durable-состояния

Статус: accepted

## Контекст

OpenRig держит очередь, события и сессии в SQLite WAL, а tmux использует только как транспорт ввода и захвата; scrollback не является источником истины.

## Решение

Beacon хранит обязательства, события и реестр исполняет в одном хранилище с транзакциями. Любой транспорт (CLI, MCP, терминал, ACP) является клиентом этого состояния.

## Последствия

Адаптер не может изменить состояние обязательства помимо store. Неподтверждённая доставка помечается indeterminate, а не failure.
