# ADR 204: TUI как чистый клиент сервера

Статус: proposed

## Контекст

TUI может писать состояние напрямую и расходиться с MCP.

## Решение

TUI читает готовые проекции и шлёт команды только через REST. Локальный control socket не пишет в БД.

## Последствия

Меньше дублирования. TUI требует работающего сервера или встроенного режима.
