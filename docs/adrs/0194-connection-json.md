# ADR 194: Адрес сервера в connection.json

Статус: proposed

## Контекст

Адрес демона захардкожен в конфиге клиента, а демон может переехать.

## Решение

Endpoint пишется в connection.json рядом с beacon.db и перечитывается при каждом старте клиента.

## Последствия

Service discovery без центра. Требуется атомарная запись файла.
