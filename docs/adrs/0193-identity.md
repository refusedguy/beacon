# ADR 193: Раздельные реестры адаптера, identity и гранта

Статус: accepted

## Контекст

OpenRig отдельно хранит карты runtime-адаптеров, session-registry, host/human registry и MCP grants; hosted member вообще не имеет pane.

## Решение

Beacon держит три независимых реестра: тип адаптера, identity исполняющей сессии и права доступа.

## Последствия

Маршрутизация идёт по явному реестру; отсутствие записи означает skip, а не догадку.
