# ADR 191: Durable mailbox и idle-report как единый контракт уведомления

Статус: accepted

## Контекст

Claude Code agent teams держат mailbox в JSON файле ~/.claude/teams/{team}/inboxes/{agent}.json и считают отправку состоявшейся только после успешной записи. При чтении каждая запись проверяется, битые удаляются. Тиммейт, закончивший turn, шлёт idle-уведомление с финальным ответом или текстом ошибки. OpenCode шлёт report при idle и снова после каждого раунда. Crush превращает subagent-report в скрытый prompt нового turn.

## Решение

Все доставки результата ребёнка в Beacon идут через один контракт: durable запись, валидация на чтении, явный idle-report с финальным текстом и отдельный флаг ошибки. Wake остаётся подсказкой перечитать состояние, а не источником истины.

## Последствия

Сообщение не теряется при обрыве socket. Битая запись не блокирует остальные. Родитель завершает turn и просыпается по report, а не опросом. Повторный report после нового раунда не создаёт вторую работу.
