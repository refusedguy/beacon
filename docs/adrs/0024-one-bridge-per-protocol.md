# ADR 0024. Один мост на протокол, а не на каждый продукт

Статус: accepted

## Решение

Ядро Beacon говорит только MCP. Каждый внешний агент подключается одним тонким мостом, который переводит шесть операций в его CLI, HTTP API или ACP. Шесть операций: `start`, `status`, `events`, `wake`, `cancel`, `artifacts`.

Мост живёт рядом с адаптером, как сейчас `.opencode/plugins/beacon-bridge.js`. В Go-коде ядра нет названий конкретных агентов. Один и тот же вызов `watch_pr` работает с двумя разными мостами без правок в ядре.

## Причина

Отчёт M3 в разделах «Общий знаменатель» и «Предлагаемый интерфейс адаптера» показал, что почти все живые среды дают шесть одинаковых по смыслу операций. Разница только в том, где они живут: локальный процесс, REST-запрос или ACP-метод ([документы OpenCode](https://opencode.ai/docs/api/), [документы Cursor](https://cursor.com/docs/cloud-agent/api/overview), [ACP](https://agentclientprotocol.com/protocol/v1/prompt-turn.md)). ACP описывает `session/new`, `session/load`, `session/prompt`, `session/update`, `session/cancel` и другие методы, но не решает вопросы worktree, облачного жизненного цикла, очередей follow-up и получения артефактов. Поэтому сам протокол не является границей.

ADR 0006 уже вынес код OpenCode из ядра в один JS-файл. Это решение продолжает ту же границу и снимает привязку к одному агенту. ADR 0020 требует, чтобы задача приходила из согласованного решения, поэтому карточка моста появляется только после статуса `accepted`.

## Последствия

- Ядро не содержит имён агентов. Тест проверяет это в Go-коде.
- Новый агент подключается мостом без пересборки ядра.
- Из этого решения выходит одна небольшая карточка в `docs/tasks/` по правилам ADR 0020. Карточка затронет `internal/infra/mcp/server.go`, `internal/infra/mcp/tool_watch_pr.go`, `internal/infra/mcp/tool_watch_pr_test.go` и новый мост рядом с `.opencode/plugins/beacon-bridge.js`.
- Проверка карточки: один вызов `watch_pr` работает с двумя мостами, тест не находит названий агентов в ядре.

## Отклонённое

Отдельный адаптер на каждый продукт внутри Go-ядра. Он дублирует шесть операций и ломает границу из ADR 0006 при каждом новом агенте.
