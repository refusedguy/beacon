# ADR 205: Волна как настройка заботы о куске работы

Статус: accepted

## Контекст

Wave model: параллельная сборка в непересекающихся территориях, серийный integrator, одно независимое review на волну двумя разными вендорами.

## Решение

Beacon{cols} поддерживает волновую упаковку работы: территория, один интегратор, две независимые проверки на границе волны.

## Последствия

Автор не проверяет себя; границы territory конфликтуют -> stop and rule, а не silent merge.
