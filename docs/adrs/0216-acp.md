# ADR 216: ACP как двусторонний мост, а не замена адаптера

Статус: accepted

## Контекст

rig acp run передаёт row внешнему агенту, а rig acp serve предлагает команду OpenRig как агента; permission request становится отдельной queue row.

## Решение

Beacon поддерживает оба направления ACP через тонкий мост, сохраняя владельца строки на своей стороне.

## Последствия

Результат агента — report, принятие работы остаётся за владельцем строки.
