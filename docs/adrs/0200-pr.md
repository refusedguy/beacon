# ADR 200: Спектр фоновых задач сервера за пределами PR

Статус: proposed

## Контекст

Сервер умеет только ждать CI и мержить PR, хотя владеет состоянием и планировщиком.

## Решение

Добавить задачи мониторинга карточек, cron-проверок, уведомлений, rebase, dependabot, синхронизации backlog и ночной смены.

## Последствия

Расширение спектра без новых MCP-инструментов. Каждая задача — воркер с идемпотентностью.
