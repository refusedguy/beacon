# ADR 0014. Квитанции адаптера

Статус: accepted

## Решение

Плагин OpenCode после вызова `ctx.session.prompt` пишет квитанцию в подкаталог `receipts/` внутри каталога состояния Beacon. Одна квитанция на событие и попытку. Создание файла атомарное через флаг `wx`. Beacon читает только целые строки.

## Причина

Beacon не может узнать, дошло ли уведомление до сессии, потому что у него нет доступа к OpenCode API. Квитанция позволяет отличить отправленное сообщение от неотправленного и не делать повтор там, где доставка уже состоялась.

## Последствия

- Три состояния доставки: `posted`, `transport-failed`, `indeterminate`.
- Для `posted` и `indeterminate` повторов нет.
- Для `transport-failed` есть повтор по лестнице.
- Квитанция не пишется в конфиги OpenCode.
