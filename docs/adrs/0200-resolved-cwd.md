# ADR 200: Состояние в границах проекта по resolved cwd

Статус: proposed

## Контекст

Клиент может подменить окружение или незаметно попасть в другой проект.

## Решение

Workspace ключуется resolved cwd и git root. Проектный overlay не имеет fallback в другое окружение.

## Последствия

Изоляция предсказуема. Требуется явная привязка thread к worktree и branch.
