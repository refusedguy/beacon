# ADR 224: Ретенция и erasure как отдельный контур

Статус: accepted

## Контекст

OpenRig ежедневно архивирует transitions, чистит историю и по опции стирает закрытые строки; все батчи ограничены и журналируются.

## Решение

Beacon держит ретенцию отдельным idempotent батчем с лимитом времени удержания store.

## Последствия

Сбой одного батча не останавливает остальные проходы; повтор сходится.
