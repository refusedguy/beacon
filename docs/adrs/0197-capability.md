# ADR 197: Гранты выдаются на capability, а не на имя проваридера

Статус: accepted

## Контекст

Grant service OpenRig даёт каждой сессии одно seat и набор пар object/action, каждая пара это ровно один инструмент. Рост прав дочернего агента над родителем запрещён в t3code типизированными отказами. Beacon работает с 15+ агентами разных harness.

## Решение

Выдавать grant на роль, проект и capability. Инструмент доступен только если его пара object/action есть в гранте. Дочерний режим не может быть шире родительского. Отзыв гранта не удаляет уже сделанную работу.

## Последствия

Список инструментов не равен доступу. Требуется аудит с актором и ingress. Удалённый доступ только через loopback плюс bearer и явный proxy.
