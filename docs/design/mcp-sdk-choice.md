# Выбор MCP SDK для Beacon

Дата решения: 2026-11-21.
Карточка: [RS-MCP-07](../tasks/RS-MCP-07.md).
Бюджет размера: 100 МБ, зафиксирован в [ADR 0060](../adrs/0060-cli-adapter-boundary-and-live-loop.md).

## Решение

Оставить официальный `github.com/modelcontextprotocol/go-sdk` версии v1.8.0. Возврат к ручному JSON-RPC не нужен. SDK уже входит в `go.mod` на `0198f6b`, а `cmd/beacon/mcp.go` и `internal/infra/mcp/` импортируют его. Первое появление в зависимостях датируется коммитом `7e02c87` (T2.1).

В карточке записана premise `grep -c modelcontextprotocol go.mod = 0` для `c9a0e3f`. Замер на этом же коммите даёт 1. Premise устарела. Решение принято по числам ниже, а не по тексту карточки.

`go.mod` основного репозитория в этом PR не менялся. Прототип собран вне репозитория.

## Замер

Среда, 2026-11-21:

- `go version` даёт `go1.27.4-X:nodwarf5 linux/amd64`.
- `go.mod` требует `go 1.26.0`.
- Порог 100 МБ равен 100 000 000 байт. Граница 100 МиБ равна 104 857 600 байт. Оба значения больше результатов замера.

Базовый бинарник beacon:

- `/home/nbook/Projects/beacon-handoff/beacon-impl/.opencode/bin/beacon`: 23 958 531 байт (22,85 МиБ). Сборка от 2026-11-21 10:00:12 +0500, коммит `d3b1bfb`, `CGO_ENABLED=1`, без strip. Источник: `stat -c '%s' <путь>` и `go version -m <путь> | grep vcs.revision`.
- `/tmp/opencode/beacon-fresh`: 23 860 050 байт. Сборка от 2026-11-21 09:22:44 +0500, коммит `c9a0e3f`, который карточка называет main. Источник тот же.

Прототип: модуль `example.com/mcp-sdk-proto` в `/tmp/opencode/mcp-sdk-proto-t22`. Программа поднимает сервер на двух in-memory транспортах, регистрирует один инструмент `greet` и вызывает его клиентом. Зависимость `github.com/modelcontextprotocol/go-sdk v1.8.0`, флаг `-mod=mod`, офлайн-разрешение через `GOPROXY=off`.

Команда сборки с флагами CI из `.github/workflows/ci.yml`:

```
cd /tmp/opencode/mcp-sdk-proto-t22
CGO_ENABLED=0 GOPROXY=off go build -trimpath -buildvcs=false -ldflags="-buildid= -s -w" -o proto-stripped .
```

Результаты:

| Сборка | Время | Размер, байт | Размер, МиБ |
| --- | --- | --- | --- |
| Флаги CI, тёплый кеш | 3 072 мс | 8 081 532 | 7,71 |
| Флаги CI, пустой GOCACHE | 18 249 мс | 8 081 532 | 7,71 |

Время снято по `date +%s%N` до и после `go build`. Размер снят `stat -c '%s'`. Для пустого кеша использовался отдельный `GOCACHE=/tmp/opencode/mcp-proto-gocache-t22`. `ldd proto-stripped` сообщает, что файл не является динамическим исполняемым. Запуск `./proto-stripped` вывел `Hi user`, значит прототип работает.

## Сравнение с порогом

Минимальный бинарник на SDK занимает 8,08 % от 100 МБ. Текущий beacon занимает 24,0 % от того же порога. Оба результата ниже границы 100 МиБ.

Отказ от SDK не даёт выигрыша по размеру, который можно было бы доказать этим замером. Весь beacon с SDK уже занимает 23,96 МБ и укладывается в бюджет. Перенос работающего кода обратно на ручной JSON-RPC добавляет работу без измеренной пользы. Поэтому решение оставлено в силе.
