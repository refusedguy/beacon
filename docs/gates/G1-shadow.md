## Проверка, что никто не разбужен

Проверка выполняется по логам shadow-прогона, а не локально. Требуется приложить вывод, который показывает две вещи.

1. В логах нет событий `session.execution.started`, вызванных Beacon.
2. `pgrep -fc 'gh pr checks --[w]atch'` во время прогона показывает 0.

Вывод не приложен. Проверка не пройдена. Конфиг агентов и строки про `gh --watch` в инструкциях в этой задаче не трогались.

## Решение владельца

Решение о переходе на G2 не принято. Воркер гейт не открыл. ADR 0018 запрещает проходить гейт самовольно, поэтому после заполнения таблиц и приложения логов переход подтверждает владелец.

## Блокеры

1. PR #43 с T4.1 открыт, статус UNSTABLE. Числа хаос-прогона зафиксированы в тесте, но PR не влит.
2. PR #44 с T4.2 открыт, статус UNSTABLE. Таблица SLO в `docs/perf/README.md` заполнена прочерками.
3. В `main` нет подкоманды `mcp` и демона, который может вести наблюдение на реальных PR.
4. ADR 0022 запрещает локальные тесты, сборки и замеры как гейт. Проверка идёт только в CI через PR.
5. Нет логов реального shadow-прогона, поэтому проверку «никто не разбужен» нельзя подтвердить.
