# CA-14. Локальная проверка синтаксиса до отправки в CI
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: docs/templates/executor-task.md
Зависимости: 
Ссылка: docs/research/comp-aider.md
Агент: нет
Время: нет
Цель: Ловить синтаксические ошибки parsed-деревом до пуша, не запуская полные проверки.
Контекст: Источник: docs/research/comp-aider.md, дополнение к CA-05. aider парсит файл tree-sitter и собирает узлы `ERROR` и `is_missing` в список номеров строк (`aider/linter.py:201-231`, `:259-269`), показывая их с контекстом. Это отдельный от полного lint дешёвый проход. В beacon исполнителю локально разрешён только `gofmt -w` (`docs/templates/executor-task.md:152`), все проверки уходят в GitHub Actions; синтаксическая ошибка обнаруживается только после пуша. Baseline: один лишний cycle CI на каждую опечатку.
Шаги: Добавить локальный синтаксический предпроход для изменённых файлов с выводом path:line. Запретить пуш при найденной ошибке. Оставить полные проверки в CI и не запускать `go test`, `go build` и `beacon gates` локально.
Проверка: Взять 10 файлов: пять с синтаксической ошибкой и пять корректных. Требовать 5 отказов до пуша с верным номером строки и 5 проходов. Сравнить число лишних CI-запусков: должно быть 0 вместо 5. Baseline 5 лишних запусков.
Приёмка: Все пять битых файлов остановлены до пуша с точной строкой, корректные файлы прошли, лишние CI-запуски равны нулю.
