# T3.375. Журнал webhook-доставок с ключом event_id
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/store/webhook_events.go, internal/infra/store/db.go, internal/domain/identity.go, docs/adrs/0261-webhook-event-id.md
Зависимости: 
Ссылка: ADR 0261
Агент: нет
Время: нет
Цель: Записывать каждую доставку GitHub один раз и делать повтор идемпотентным.
Контекст: X-GitHub-Delivery это GUID, уникальный для события. При ручном redelivery заголовок тот же. domain.IdempotencyKey уже строит детерминированный ключ из namespace и значения. ADR 0015 требует одной транзакции и UNIQUE-индекса.
Шаги: Добавить таблицу webhook_events с delivery_id PRIMARY KEY, event, action, repo, pr, head_sha, watch_id, revision, status, received_at и outcome. Написать RecordDelivery и DeliverySeen. Использовать IdempotencyKey('github-delivery', deliveryID). Покрыть тестами повтор и конфликтующее тело.
Проверка: Повторная запись того же delivery_id не создаёт вторую строку, статус не откатывается, тесты проходят на полностью пустой базе и после рестарта.
Приёмка: Одна доставка GitHub соответствует одной строке журнала; повтор redelivery возвращает сохранённый outcome.
