Goal: permission denial becomes a typed diagnosis instead of an interactive ask.
Evidence: requireOrchestrator allows absent metadata, so a call with no agent info falls through to OpenCode permission ask and returns Permission.DeclinedError. The assistant retried instead of diagnosing because the error did not name the observed role.
Steps: add CodePermissionDenied to pkg/core/errors.go; refuse absent or worker metadata with that code and a message naming observed and required role; add table tests for worker, absent and orchestrator metadata.
Accept: a worker or metadata-less call to an orchestrator tool returns a coded refusal that names both roles and cannot execute.
