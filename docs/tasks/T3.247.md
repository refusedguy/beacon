# T3.247. Проверка input box
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. Карточка просит подтвердить, что текст реально был в поле ввода: при transport.verify_input_box OpenRig сравнивает idle shape кадра, точное содержимое box и пустой box после Enter для Claude 2.1.296 и Codex 0.160.0, а шаги требуют matchеры кадров, сравнение по word boundary и 500 мс дедлайны на дополнительные чтения; занятый или неопознанный seat даёт unconfirmed. В internal/infra/wake/deliver.go нет захвата кадра, input box, idle shape, word boundary, matchеров, модели seat, статуса unconfirmed и таймингов 500 мс. Доставка идёт через PromptFunc: весь Envelope уходит в существующую сессию ses_ по HTTP API или CLI fallback, а не набором текста в composer с последующим Enter и чтением экрана. Фейковый PromptFunc проверяет только попытку доставки, но не подтверждает содержимое живого поля ввода: в deliver.go нет точки захвата кадра/idle shape и модели seat. Настоящая проверка требует живого pane/кадра с OpenRig transport.verify_input_box и эмуляцией Claude 2.1.296 / Codex 0.160.0, включая чтение после Enter. Здесь доступны только правка текста и gofmt на слабом ПК, живого pane и capture кадра нет. Сестёрские карточки T3.243-T3.246 и T3.249 в main несут Premise с тем же выводом, а T3.266, T3.267 и T3.268 сняты в PR #394 формулировкой "tmux нет, заглушка deliver.go". Зависимость T3.246 в main остаётся todo. Ссылка на ADR 0087 расходится с темой: оба файла 0087 про wake-указатель и идентичность конфигурации, а не про проверку input box. Статус todo сохранён, карточка остаётся непроверенным спайком до появления живого pane/кадра-зонда, блокер возвращён оркестратору. OwnerFiles не менял, код не писал, gofmt не применял, дубль не создал, правка только текстовая.
