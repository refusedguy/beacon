# T3.247. Проверка input box
Premise: перепроверено 2026-11-21 по свежему origin/main (86ceaec; ветка fix/ag2 обновлена ребейзом). Функционал проверки input box в main отсутствует, дубль не создан. Карточка просит подтверждать наличие текста в поле ввода через transport.verify_input_box OpenRig: idle shape кадра, точное содержимое box и пустой box после Enter для Claude 2.1.296 и Codex 0.160.0, плюс matchеры кадров, сравнение по word boundary, 500 мс дедлайны на дополнительные чтения и unconfirmed для занятого или неопознанного seat. Это механизм OpenRig `--verify` над tmux pane с живым TUI-сеансом Claude/Codex. По заданию оркестратора проверил wake delivery, envelope и dedupe. Доставка wake есть: `OpenCodeDeliverer.Deliver` (`internal/infra/wake/deliver.go:104`) шлёт текст через `PromptFunc` (:174) с CLI fallback (:195). Envelope это `Envelope` (:274) и `T202Envelope` (:686), они кладут в текст только идентификаторы. Dedupe это `seen` map (:86), проверка `DeliveredAt` в store (:140), `DeliveryLeaseGuard` (:412, :450), `T211DeliveryRegistry` (:1105) и `CursorDeliverer` (:1501). Все три механизма решают доставку текста в сессию `ses_` через ACP или API и защиту от повторного пробуждения. Ни один не захватывает pane и не подтверждает текст в поле ввода. `verifyAck` (:381) проверяет, что API принял промпт и вернул id сообщения, а не экран. Вхождение `verify_input_box` в origin/main есть только в этой карточке. Пакета openrig в дереве нет. Файлов `internal/infra/tmux/pane.go`, `internal/infra/wake/capture.go`, `internal/infra/session/pane.go` и `internal/infra/openrig/verify.go` в origin/main нет. Шесть совпадений шаблона в deliver.go это комментарий "exact match" (:888) и пять строк про `Matches` в history search T3.250 (:1528-1604), ни одно не про input box. Вхождения `unconfirmed` живут в `internal/infra/github/batch_provider.go:356`, `internal/infra/mcp/tool_wake.go:488,719` и его тесте, они про подтверждение merge и fallback доставки. Единственное совпадение `500.?ms` это `shutdownTimeout: 1500ms` в `internal/infra/server/config_test.go:74`. Словарь статусов deliver.go это T206 и T210, ни один не описывает input box. Beacon доставляет указатель в сессию через ACP или API, tmux pane для захвата кадра у него нет. Сестёрские карточки T3.245, T3.246 и T3.266/267/268 сняты по тому же основанию: tmux нет, OwnerFiles заглушка deliver.go (PR #394, #728, #729). Зависимость T3.246, проверка рендера в pane, в origin/main всё ещё todo. Настоящая проверка требует живого pane и OpenRig `--verify` с конкретными версиями Claude 2.1.296 и Codex 0.160.0. Здесь доступны только правка текста и gofmt, живой зонд поднять нельзя. Код не писал, OwnerFiles не менял, gofmt не применял, чужие файлы, wiring и .beacon не трогал.
