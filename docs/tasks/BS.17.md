# BS.17. SSE реплей без разрыва
Статус: done
Фаза: P1
Тип: task
Владелец файлов: internal/infra/server/events.go
Зависимости: BS.16
Ссылка: ADR 0194
Агент: нет
Время: нет
Цель: Клиент не теряет события между реплеем и живым потоком.
Контекст: openrig routes/events.ts подписывается до чтения реплея и буферизует.
Шаги: Подписка до реплея, страницы по 500, Last-Event-ID, дедупликация по seq.
Проверка: Событие, пришедшее во время реплея, доставляется один раз.
Приёмка: Заголовок Last-Event-ID имеет приоритет над query.

## Подтверждение
- Дубль: реплей без разрыва уже в main через коммит 3573721 и PR #455. `internal/infra/server/events.go` задаёт страницы по 500 через `PageSize`, объединяет реплей и живой поток в `ReplayAndLive` с подпиской до чтения и дедупликацией по seq. `CursorFromRequest` даёт заголовку Last-Event-ID приоритет над query. Версионированную оболочку и SSE-кадры покрывают тесты `internal/infra/server/events_test.go`. Код не менялся.
