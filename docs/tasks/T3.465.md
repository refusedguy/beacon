# T3.465. Воспроизведение gating через сценарии
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/test/scenarios/README.md
Зависимости: T3.391
Ссылка: ADR 0224
Агент: нет
Время: нет
Цель: Сценарий считается парой: здоровый проход и seed-регрессия.
Контекст: OpenRig scenario library требует header с defect class и seed; сценарий без seed-провала не считается.
Шаги: Формат сценария с up/send/expect; сид регрессии в отдельном контуре.
Проверка: Один и тот же сценарий проходит на здоровом коде и падает на seed.
Приёмка: Регрессионная ценность сценария измерима.
