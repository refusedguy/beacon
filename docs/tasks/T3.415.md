# T3.415. Durable ключ доставки вместо in-memory карт
Premise: проверено 2026-11-21, дубль. Механизм доставки, переживающий рестарт, уже в origin/main. OpenCodeDeliverer держит не только in-memory seen, но и порт Obligations (internal/infra/wake/deliver.go:141). Перед доставкой он читает обязательство из store и пропускает повтор, если DeliveredAt уже проставлен (deliver.go:143). После успешной доставки markDelivered пишет receipt в SQLite через MarkObligationDelivered с obligationID и attempt (deliver.go:233,238). Порт объявлен в ObligationDeliveryStore (deliver.go:45,47) и подключён в бою: reconcileWaker передаёт db в Obligations (cmd/beacon/mcp.go:1230). Хранилище реализует Obligation (internal/infra/store/db.go:461) и MarkObligationDelivered (internal/infra/store/blockers.go:475), который сохраняет DeliveredAt и номер попытки в SQLite. Персистентность подтверждена тестом TestMarkObligationDeliveredPersists (internal/infra/store/blockers_test.go:341) и тестами адаптера с Obligations: store (internal/infra/wake/deliver_ports_test.go:86,111). Приёмка «повтор после рестарта не создаёт второй prompt» закрыта: новый процесс получает пустой seen, но читает DeliveredAt из SQLite и пропускает доставку. Дополнительно DeliveryLeaseGuard (deliver.go:406,525) не даёт двум разным указателям доставить в одну цель и восстанавливается после рестарта. In-memory карта осталась как первая линия защиты, а не единственная, что сильнее буквальной формулировки «вместо». OwnerFiles не менял, код не писал, дубль не создан.
baseline: `git show FETCH_HEAD:internal/infra/wake/deliver.go | sed -n '139,151p'` даёт коммент «The store is the durable half of dedup» и проверку `o.DeliveredAt.IsZero()`; `git show FETCH_HEAD:internal/infra/wake/deliver.go | sed -n '231,239p'` даёт вызов `d.Obligations.MarkObligationDelivered(p.ObligationID, time.Now(), 1, "")`; `git grep -n 'Obligations' FETCH_HEAD -- 'cmd/beacon/mcp.go'` = строка 1230 `Obligations: db`; `git show FETCH_HEAD:internal/infra/store/blockers.go | sed -n '475p'` = `func (d *DB) MarkObligationDelivered`; `git show FETCH_HEAD:internal/infra/store/db.go | sed -n '461p'` = `func (d *DB) Obligation`; `git grep -n 'TestMarkObligationDeliveredPersists' FETCH_HEAD` = blockers_test.go:341; `git log --all --oneline --grep='T3\.415'` = 0 коммитов; `gh pr list --repo refusedguy/beacon --state all --search 'T3.415'` = 0 PR.
