## Goal
Make the store the only writer of the task graph and keep task fingerprints consistent across processes.

## Evidence
From T-5115e3a5: syncCache is process-local, so two processes keep different fingerprints for one tasks table. docs/tasks and worktrees have multiple writers with no cross-process coordination.

## Steps
Make the store the single writer for task graph changes and keep dispatch read-only. Derive fingerprints from store state rather than a process-local cache. Add tests in internal/infra/sqlite/tasks_test.go that two instances opening one temp DB see one fingerprint and at most one writer.

## Accept
Two processes never disagree about one tasks table, and dispatch cannot mutate cards.
