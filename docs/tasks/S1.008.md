# S1.008. Bearer token и проверка loopback
Статус: dropped
Фаза: P0
Тип: task
Владелец файлов: internal/infra/server/http/auth.go
Зависимости: S1.006, S1.002
Ссылка: ADR 0090
Агент: нет
Время: нет
Цель: Защита записи и явное включение удалённого доступа.
Контекст: Слушатель по умолчанию должен быть доступен только локально.
Шаги: Middleware bearer token, обнаружение loopback и Tailscale bind, отказ при неявном внешнем доступе.
Проверка: Тест запроса без токена и с токеном.
Приёмка: Внешний запрос без токена получает 401 или 403.
