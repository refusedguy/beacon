# T2.1. MCP-сервер на go-sdk и реестр семи инструментов
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/infra/mcp/server.go, internal/infra/mcp/server_test.go
Зависимости: T1.1
Ссылка: ADR 0003
Агент: нет
Время: нет
Цель: Поднять MCP-сервер на stdio через официальный go-sdk, зарегистрировать 7 инструментов-стабов и передать протокол цикла в instructions при handshake.
Контекст: ADR 0003 выбирает официальный `github.com/modelcontextprotocol/go-sdk`, совместимость v1, Go 1.25+, OAuth-стек около 1,4 MB после strip. WORKER-PROMPT §4.1 задаёт ровно 7 инструментов и требует протокол цикла в MCP instructions, а не отдельным инструментом. WORKER-PROMPT §2 запрещает experimental tasks ревизии 2025-11-25 и требует legacy protocol и stdio. ADR 0007 размещает код в internal/infra.
Шаги: 1. Создать сервер go-sdk с stdio transport и legacy protocol. 2. Зарегистрировать 7 инструментов-стабов с ожидаемыми именами. 3. Записать протокол цикла в текст instructions handshake.
Проверка: server_test.go поднимает сервер на in-memory transport, вызывает tools/list и сравнивает имена с ожидаемым списком из 7 штук. Отдельная проверка читает instructions и ищет в ней протокол цикла.
Приёмка: tools/list возвращает ровно 7 инструментов, handshake отдаёт instructions с протоколом цикла, сервер стартует на stdio без experimental-расширений.
