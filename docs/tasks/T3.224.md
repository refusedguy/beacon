Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.219
Ссылка: ADR 0064
Агент: нет
Время: нет
Цель: Выяснить, можно ли передать deliveryId в Cloud Agents v1.
Контекст: НЕ ПРОВЕРЕНО: открытый вопрос 3. Тело steer ограничено полями prompt и delivery, поэтому дедупликация сейчас остаётся на стороне адаптера.
Шаги: Проверить, принимает ли API deliveryId. Пока хранить и проверять deliveryId адаптером.
Проверка: Повтор после сетевой ошибки может доставить промпт дважды.
Приёмка: Дубль доставки обнаруживается и не приводит к двум wake.

## Подтверждение
- PR #312 (feat/w320): `CursorDeliverer` хранит `deliveryId` в адаптере, тело steer ограничено полями `prompt` и `delivery`. Повтор с тем же id и телом схлопывается в duplicate, повтор после сетевой ошибки не вызывает повторную доставку, другое тело с тем же id отклоняется.
- Проверка: `go test ./...` зелёный, gofmt не запускался.
