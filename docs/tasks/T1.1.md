# T1.1. Модуль domain: типы Watch, Obligation, Subscriber, Verdict
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/domain/types.go, internal/domain/types_test.go
Зависимости: нет
Ссылка: ADR 0007
Агент: нет
Время: нет
Цель: Описать сущности и статусы контракта v2 на стандартной библиотеке Go без зависимостей от инфраструктуры.
Контекст: WORKER-PROMPT §4.2 задаёт состав Watch: id, repo, pr, headSHA, baseRef, status watching|notifying|closed, verdict watching|ready|rebase|retry|keep_working|timeout|merged|closed, revision uint64, checks, merge, flaky, policy, subscribers, deadlineAt, createdAt; Obligation: id = f(watchID,revision,subscriberID), verdictPointer, stagedAt, attempts, deliveredAt, claimedAt, readAt, escalatedAt, escalationLevel. ADR 0007 размещает типы в internal/domain. ADR 0008 требует, чтобы интерфейсы Clock, Store, CIProvider, Notifier лежали в domain, а реализации в infra. ADR 0009 фиксирует AppError с кодом и статусом вместо Result[T].
Шаги: 1. Объявить Watch, Obligation, Subscriber, Verdict, Attempt и перечисления статусов с именами из §4.2. 2. Объявить интерфейсы Clock, Store, CIProvider, Notifier и тип AppError по ADR 0008 и ADR 0009. 3. Покрыть типы тестом на нулевые значения и совместимость с json.Marshal из stdlib.
Проверка: go test ./internal/domain -run TestTypes; go list -deps ./internal/domain не содержит внешних модулей.
Приёмка: Все поля из §4.2 имеют тип, package domain импортирует только stdlib, гейт ADR 0005 не находит импорта internal/infra из domain.
