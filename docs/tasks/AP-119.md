Цель: Отзывать токен при освобождении сессии.
Контекст: Слушатель по умолчанию loopback, токены выдаются на сессию, а дочерний агент не расширяет права родителя.
Шаги: Связать credential vault с lifecycle сессии.
Проверка: Мёртвая сессия не имеет действующего токена.
Приёмка: Сырой токен не сохраняется в состоянии.
