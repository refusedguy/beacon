# T3.242. Per-target delivery lease
Статус: todo
baseline: до правки d.mu в Deliver защищал только карту seen, поэтому два разных obligationID на один ses_ проходили к транспорту одновременно. Ссылка на проверку: тесты TestOpenCodeDelivererSerializesConcurrentWakesToSameTarget и TestOpenCodeDelivererCoalescesConcurrentDuplicateWake в deliver_test.go. После правки второй wake с другим obligationID получает ErrTargetBusy до вызова PromptFunc, а повтор того же obligationID остаётся no-op.
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.241
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Сериализовать доставку одному исполнителю.
Контекст: SessionTransport в OpenRig берёт per-seat lease из seat-delivery-guard на каждую запись.
Шаги: Добавить lease с владельцем, таймаутом и reject при занятом target. Хранить в SQLite или in-memory с restore.
Проверка: Две одновременные wake одному target не вводят текст в pane.
Приёмка: Порядок сообщений в одном адресе сохраняется.
