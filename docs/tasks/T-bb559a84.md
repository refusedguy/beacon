Goal: ACP sessions must not spawn a process per call or allocate a goroutine per RPC.

Evidence: opt-harness.md findings 3 to 5 show repeated JSON decode, a process per session and a goroutine per RPC.

Steps: Reuse one decode buffer per process, pool the request goroutines with a bounded semaphore, and keep process lifetime tied to the harness session.

Check: Fake ACP agent handles 1000 RPCs with one process, bounded goroutines, identical messages and zero errors.

Accept: No ACP wire change.

Open a PR, call beacon_watch_pr, do not self-merge.
