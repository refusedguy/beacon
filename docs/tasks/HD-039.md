# HD-039. Два входа вердикта
Статус: done
Premise: проверено 2026-11-20, дубль. PR #501 слит 2026-11-20 и закрыл HD-039 в main. Он вынес форматы строк отчёта batch-apply в именованные константы в internal/infra/batchapply/apply.go и добавил тесты TestReportFormatContract и TestCheckReportOutput в apply_test.go. Текущий apply.go хранит форматы checkReportFormat, summaryReportFormat, mergeReportFormat и renumberReportFormat с указанием на HD-039. Тест фиксирует точный вывод строк. Отрицательный контроль отклоняет старые варианты с подписями, скобками и стрелкой. Текст карточки говорит о двух входах вердикта, но её OwnerFiles не считают вердикты гейтов. cmd/batch-apply/main.go только разбирает флаги, internal/infra/batchapply/apply.go печатает отчёт batch-apply. Новый код создал бы вторую копию форматов, поэтому я не писал код и не менял OwnerFiles.
