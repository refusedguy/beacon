# T3.180. Адаптер ACP для доставки wake
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/acp.go, internal/infra/wake/acp_test.go
Зависимости: T3.179
Ссылка: ADR 0070
Агент: нет
Время: нет
Цель: Доставлять wake в ACP-цикл через session/prompt и продолжать ту же сессию через session/resume
Контекст: ADR 0070 п2. ADR 0024 описывает ACP-методы session/prompt и session/resume и оставляет ядро на MCP. ADR 0026 требует честно различать steer, queue и unsupported. ACP не становится вторым мостом рядом с MCP-сервером.
Шаги: Реализовать Deliverer на ACP в internal/infra/wake; отправлять session/prompt с указателем, а не с текстом проверки; при продолжении той же сессии вызывать session/resume; возвращать steer, queue или unsupported по факту ответа клиента; ошибку транспорта помечать transport-failed без повтора; написать unit-тесты на подставном ACP-клиенте, включая подмену ответа на queue и повтор пары obligationID и attempt
Проверка: go test ./internal/infra/wake
Приёмка: Адаптер реализует интерфейс из T3.179; в ядре нет имён ACP-методов; queue не выдаётся за доставку в текущий ход; повтор пары не создаёт второй prompt
