# BS.49. Атрибуты метрик низкой кардинальности
Статус: done
Фаза: P4
Тип: task
Владелец файлов: internal/infra/server/metrics.go
Зависимости: BS.46
Ссылка: ADR 0195
Агент: нет
Время: нет
Цель: Метрики не взрываются по количеству вотчей.
Контекст: 
Шаги: Атрибуты signal, reason, adapter; не класть watchID в labels.
Проверка: Число серий не растёт линейно от PR.
Приёмка: Длительность в секундах, счётчики в {call}.

## Подтверждение
- Premise проверен 2026-11-20, дубль. Функциональность уже в main: коммит 236d2e3 (PR #481) добавил `internal/infra/server/metrics.go` с тестами и закрыл BS.49 по ADR 0195. Метрики используют ровно три ключа: `signal`, `reason`, `adapter`; ключей `watchID`, `pr` и `sessionID` нет, поэтому рост числа вотчей и PR не увеличивает число серий. `Attributes` не содержит поля Watch, `Normalize` сводит неизвестные значения к `Other`, а `NewMetrics` заранее создаёт все комбинации закрытых доменов, поэтому `SeriesCount()` постоянен и проверка «число серий не растёт линейно от PR» выполнена. Счётчик `beacon_call_total` (`CounterCalls`) двигается через `IncCall`, гистограмма `beacon_call_duration_seconds` (`HistogramCallDuration`) принимает длительность в секундах через `ObserveDuration` и `ObserveSeconds`, а `beacon_rss_bytes` — gauge без меток с одной серией. Это закрывает приёмку «длительность в секундах, счётчики в {call}». Статус done карточка получила в коммите 236d2e3. Новый код не писал, дубль в OwnerFiles не создавал.
