# T3.394. HTTP loopback и bearer-аутентификация
Статус: todo
Фаза: P0
Тип: task
Владелец файлов: internal/infra/server/auth.go, internal/infra/server/routes.go
Зависимости: T3.391
Ссылка: ADR 0188
Агент: нет
Время: нет
Цель: Дать единую точку входа для MCP, CLI и TUI.
Контекст: OpenRig слушает 127.0.0.1:7433 и проверяет bearer на write-маршрутах.
Шаги: Слушать loopback по умолчанию, bearer для write, явное включение Tailscale или proxy.
Проверка: Запрос без токена получает 401; публичный порт не открывается по умолчанию.
Приёмка: Безопасная локальная установка без второго credential store.
