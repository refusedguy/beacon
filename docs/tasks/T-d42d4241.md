Goal: cut repeated task writes and sequential agent launch.

Evidence: tasks.go:40 SyncTasks deletes and reinserts every task on each Dispatch without PrepareContext or a fingerprint check. dispatcher.go launch runs planned slots sequentially after reservation. dispatcher.go:730 spawnPrompt uses two fmt.Fprintf calls.

Variants: V1 replace both Fprintf with b.WriteString. V2 use tx.PrepareContext for tasks and task_deps inserts with deferred Close. V3 add a last-sync fingerprint cache reset by SetTaskStatus and transaction errors, with tests on fresh and changed databases. V4 launch reserved agent slots in parallel with guarded out, batch.ensured and batch.modelRefs, then run claimSlots after the wave.

CI commands: BenchmarkE2EOperatorPaths, BenchmarkSpawnPrompt, full -race. Limiter: SQLite write transaction and sequential Workspace.Create or Harness.Spawn.
