Статус: dropped
Фаза: P3
Тип: task

Зависимости: T3.362

Агент: нет
Время: нет
Цель: Превратить байты файла в типизированную структуру с проверками и дефолтами.
Контекст: Неизвестное поле это ошибка. Лимит 64 KiB на файл. autoMerge различает отсутствие и явный false через указатель в промежуточной структуре.
Шаги: Использовать json.Decoder с DisallowUnknownFields и LimitReader. Валидировать имена, длительности и диапазоны. Отклонять пересечение requiredChecks и ignoreChecks. Запретить ключи token, secret, password, apiKey.
Проверка: go test ./internal/infra/config. Таблица невалидных примеров даёт ошибку с путём файла и JSON-указателем.
Приёмка: После разбора внутренний код не повторяет проверок. Ошибка содержит имя поля, ожидаемый тип и путь файла.
