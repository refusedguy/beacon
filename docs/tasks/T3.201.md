# T3.201. Побуждение отложенной задачи через PATCH inbox
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.200
Ссылка: ADR 0073
Агент: нет
Время: нет
Цель: Превратить уже отложенную задачу в побуждение без повторной отправки текста.
Контекст: Задача ждёт в inbox с delivery queue или была принята с resume false; известен inboxID из data.id.
Шаги: GET /api/session/{sessionID}/inbox, найти item, PATCH /api/session/{sessionID}/inbox/{inboxID} с {"delivery":"steer"}; при необходимости обратная смена на queue.
Проверка: PATCH возвращает 204; приходит session.inbox.delivery.changed, затем session.execution.started.
Приёмка: Отложенная задача будит сессию; обратная смена возвращает её в очередь без потери текста.
