Goal: a red matrix cell reported by GitHub must block merge.
Evidence: ParseWorkflowJobNames drops jobs with strategy.matrix at internal/infra/shared/workflow.go:102-110 and 218-249, while GitHub reports only cell names. Failure(required...) in pkg/core/verdict.go:129-136 and evaluateChecks in internal/infra/policy/configurable.go:229-265 inspect only the required list, so a failing cell such as test-modules (root app, ...) is invisible. DetectUnreportableJobNames already identifies matrix parents.
Steps: expand strategy.matrix axes and include values into reported cell names in the workflow parser; feed those names into Workflow.Names so they enter the required set; add a test with a matrix job whose cell fails and assert VerdictWait instead of Merge.
Accept: a PR with any failed test-modules cell cannot merge until that cell passes.
