Context: repeated `workspace: conflict: refusing to remove dirty worktree` loops. Verified mechanism: `dispatcher.go:167` MarkInWorkspace rewrites the card to in_progress inside the new worktree; if Harness.Spawn fails, `handleStartFailure` (dispatcher.go:218-220) calls `Workspace.Remove`, which REFUSES to remove a dirty worktree (git_worktree.go:244-245), ignores the error, and leaves a dirty tree. Next dispatch hits the stale-path check in `GitWorktree.Create` (git_worktree.go:101-118) and fails with the conflict, creating a new closed run each time. Also `git branch -D` at L117 silently fails when the branch is checked out elsewhere (e.g. a /tmp worktree), then `git worktree add` fails with 'branch already exists'. Card status sync is NOT the cause: cards come from docs/tasks on disk and SyncTasks consumed the edit.

Goal: a failed spawn never leaves a dirty worktree that blocks the next dispatch.

Steps:
1. In `internal/app/dispatcher.go` `handleStartFailure` (~L218-220), use `ForceRemove` instead of `Remove` (port already exists in `pkg/core/ports.go:30`). No interface change.
2. In `internal/infra/workspace/git_worktree.go` `Create` (~L101-118), use ForceRemove for the stale path instead of non-force Remove, and return a clear error when `git branch -D` cannot delete a branch checked out in another worktree instead of ignoring it with `_, _ =`.
3. Tests in `internal/app/dispatcher_test.go` and `internal/infra/workspace/git_worktree_test.go`: spawn failure with a dirty worktree force-removes it; stale dirty path in Create is force-removed and the worktree is recreated; a branch checked out elsewhere produces a clear error.
4. Run `gofmt -w`, targeted `go test ./internal/app ./internal/infra/workspace`.
5. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Check: after a failed spawn, the next dispatch for the same task succeeds without a workspace conflict.

Accept: no task card logic changes. Keep files under 350 lines. Do not edit AGENTS.md or another card.
