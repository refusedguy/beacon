Агент: нет

Цель: Находить нужный Watch по событию и отбрасывать устаревшие и fork-события.
Контекст: check_run и check_suite несут head_sha и pull_requests, но для fork push массив пуст. sender может быть ghost. pull_request.synchronize несёт before и after. cibridge.publish уже перечитывает Watch и проверяет Verdict и HeadSHA до записи.
Шаги: Написать чистую функцию matchWatch(repo, pr, headSHA) по ActiveWatches. Для check_run и check_suite брать pull_requests, при пустом массиве искать по head_sha. Для pull_request брать number и pull_request.head.sha. Помечать NoChecksSince как признак начала проверок, не трогая Verdict.
Проверка: Событие со старым head_sha игнорируется; fork-событие с пустым pull_requests находится по head_sha; sender ghost не участвует в решении; два матча для одного Watch дают один refresh.
Приёмка: Вердикт меняется только после перечитывания состояния, а не фактом доставки.
