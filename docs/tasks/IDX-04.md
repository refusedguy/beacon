# IDX-04. CI проверка сгенерированного индекса
Статус: done
Фаза: P1
Тип: task
Владелец файлов: .github/workflows/ci.yml, tools/beacon-gates/cardindex/check.go
Зависимости: 
Ссылка: 
Агент: нет
Время: нет
Цель: Обязательная проверка побайтового совпадения индекса с деревом карточек.
Контекст: Premise: ROADMAP_STATUS разошёлся на 119 позиций потому что сгенерированный файл не проверялся.
Шаги: Гейт пересобирает индекс и сравнивает, добавить job в ci.yml, негативный тест на расхождение.
Проверка: gofmt, go test и гейты в CI.
Приёмка: Расхождение даёт красную проверку.

## Решение
- Новый гейт `tools/beacon-gates/cardindex/check.go` в отдельном `package main`, по образцу `docsgate`. Закоммиченный бинарник гейтов не меняется, поэтому пересборка с флагами ADR 0023 не нужна: `gates-binary.yml` пересобирает только корневой пакет.
- Гейт повторяет алгоритм `tools/roadmap-sync`: git log только с `(#NNNN)`, извлечение ID карточек, приоритет dropped над done, продвижение по OwnerFiles и подмножествам, подсчёт done/dropped/todo и фаз. Пересобранные строки применяются к тексту закоммиченного индекса так же, как `--write`, после чего байты сравниваются целиком.
- Негативный тест в `--self-test`: эталонный индекс даёт зелёный код, подменённое число в индексе и новый мержный коммит в дереве карточек дают красный код.
- В `ci.yml` добавлена обязательная job `cardindex`: checkout с `fetch-depth: 0` (иначе усечённая история ломает разрешение статусов), `go run ./cardindex --self-test` и `go run ./cardindex -root ../..`.
- Команда толерантна к отсутствию `docs/ROADMAP_STATUS.md`: IDX-11 планирует убрать производные документы из git, и после этого проверка становится no-op.
- Первый прогон CI дал шесть находок CAP-FILE-IN-OUTSIDE за вызовы `os.ReadFile` и `os.WriteFile`. Чтение переведено на `fs.ReadFile` через `os.DirFS`, а негативные тесты строят отдельные фикстуры через `gate.Fixture` вместо записи файлов. Файл исключений гейтов не тронут.
- gofmt применён к новому файлу. go test и go build локально не запускались по правилам репозитория, проверка идёт в CI.
