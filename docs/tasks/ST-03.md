Контекст: `docs/adrs/0023-gates-binary-toolchain.md:13` описывает два разных хеша: локальная сборка на Go 1.27.4-X:nodwarf5 дала `c0af0eb...`, CI на Go 1.26.0 дал `d6d76a9...`. Шаги: Добавить в workflow печать `go version`, `go env GOTOOLCHAIN GOEXPERIMENT` и версии из `go.mod` до шага сравнения. При расхождении байтов печатать отдельную строку `toolchain mismatch: go.mod=<version> runner=<version>`, если версии различаются. Оставить `cmp -s` финальной проверкой. Обновить ADR 0023 ссылкой на новое сообщение.
Проверка: На раннере с Go 1.27.4-X:nodwarf5 workflow печатает `toolchain mismatch` и красный результат. На Go 1.26.0 из `go.mod` сравнение проходит.
Приёмка: Причина расхождения видна в первом же логе джобы, без ручного сравнения хешей.
