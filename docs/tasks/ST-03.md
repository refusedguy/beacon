Цель: Показывать версию тулчейна в сообщении о расхождении байтов `gates-binary`.
Контекст: `docs/adrs/0023-gates-binary-toolchain.md:13` описывает два разных хеша: локальная сборка на Go 1.27.4-X:nodwarf5 дала `c0af0eb...`, CI на Go 1.26.0 дал `d6d76a9...`. Причина в `GOEXPERIMENT=nodwarf5`, который попадает в build info. `.github/workflows/gates-binary.yml:41-59` сравнивает байты через `cmp -s` и печатает только команду пересборки. Демон не пишет об этой причине, поэтому в его логах нет записей с `gates-binary`.
Шаги: Добавить в workflow печать `go version`, `go env GOTOOLCHAIN GOEXPERIMENT` и версии из `go.mod` до шага сравнения. При расхождении байтов печатать отдельную строку `toolchain mismatch: go.mod=<version> runner=<version>`, если версии различаются. Оставить `cmp -s` финальной проверкой. Обновить ADR 0023 ссылкой на новое сообщение.
Проверка: На раннере с Go 1.27.4-X:nodwarf5 workflow печатает `toolchain mismatch` и красный результат. На Go 1.26.0 из `go.mod` сравнение проходит.
Приёмка: Причина расхождения видна в первом же логе джобы, без ручного сравнения хешей.
