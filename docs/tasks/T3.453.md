# T3.453. Коннекторный shutdown drain
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/app/orchestrator/shutdown.go
Зависимости: T3.401
Ссылка: ADR 0226
Агент: нет
Время: нет
Цель: Не выдавать неопределённый дренаж за чистый выход.
Контекст: OpenRig оплачивает shutdown drain конечным REFERENCES таймером и возвращает 1, если запись потеряна или drain не подтверждён.
Шаги: Shutdown с bounded timer; код выхода 0 только при подтверждённом drain; лог причины.
Проверка: Таймаут даёт ненулевой код; teardown идемпотентен.
Приёмка: Неизвестность о записи не маскируется.
