# T3.453. Коннекторный shutdown drain
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/app/orchestrator/shutdown.go
Зависимости: T3.401
Ссылка: ADR 0226
Агент: нет
Время: нет
Цель: Не выдавать неопределённый дренаж за чистый выход.
Контекст: OpenRig оплачивает shutdown drain конечным REFERENCES таймером и возвращает 1, если запись потеряна или drain не подтверждён.
Шаги: Shutdown с bounded timer; код выхода 0 только при подтверждённом drain; лог причины.
Проверка: Таймаут даёт ненулевой код; teardown идемпотентен.
Приёмка: Неизвестность о записи не маскируется.

Premise проверен 2026-11-21 по origin/main (c6cff98): реализационного PR не было, единственный вызов дренажа в cmd/beacon/observe.go отбрасывал ошибку, OwnerFiles internal/app/orchestrator/shutdown.go отсутствовал. Старый блокер снят реализацией.

## Подтверждение
- PR #1119 (https://github.com/refusedguy/beacon/pull/1119): добавлен `internal/app/orchestrator/shutdown.go` с `BoundedShutdown` и дедлайном 5s по умолчанию; `cmd/beacon/observe.go` использует его вместо отброшенной ошибки и выходит с кодом 1 при ошибке дренажа, ошибки коллектора или таймауте, код 0 остаётся только при подтверждённом дренаже; teardown обёрнут в `sync.Once`. Комментарий `OTLPExporter.Shutdown` в `internal/infra/observe/otel.go` обновлён.
- Тесты `internal/app/orchestrator/shutdown_test.go` и `cmd/beacon/observe_shutdown_test.go` покрывают подтверждённый дренаж, ошибку коллектора, таймаут с проверкой времени, код выхода и однократность teardown. gofmt применён, go test и go build переданы CI по ADR 0022.
