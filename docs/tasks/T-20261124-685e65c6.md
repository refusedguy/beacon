Context: the Beacon detail panel shows ▼ section markers but they do not collapse. Verified against OpenCode v2.3.2 / @opentui/solid 0.8.4: `setProp(node, name, value)` falls through to `node[name] = value`, so toggling `visible` in refresh() is safe (only `createElement` needs a renderer). `@opentui/core` `visible=false` sets display None and removes the node from Yoga layout with no gap. Escape cannot be reliably claimed by a plugin (global `session.interrupt`, modal layers, our box not focusable), so the `esc` hint is misleading.

Goal: ▼/▶ actually collapse sections; close hint shows a key that works.

Steps:
1. In `ui_view.js`, make `section(label, key)` emit `marker: collapsed[key] === false ? '▶' : '▼'` and `sectionKey: key`. Pass a `collapsed` argument (default {}) to `detailLines(run, metrics, now, collapsed)` and skip each section's body rows when collapsed, keeping the section header visible. Sections: Identity, Timing, Attempts, Reason, Timeline, Decisions. Keep the 20-decision cap.
2. In `ui.js`, add `ctx.storage.store('beacon-detail-sections', { initial: { Identity: false, Timing: false, Attempts: false, Reason: false, Timeline: false, Decisions: false } })`. In `createRowMount`, fire `onRow` for `item.sectionKey` as well as `runID`. A section click toggles its flag, persists via the store setter, then calls `sync()` and only the affected slot's `apply()`; no `createElement`/`insert` in refresh. Toggle `visible` on the pooled body rows rather than removing them.
3. Replace the misleading `esc` hint in `makeDetail()` with `ctrl+g`. Make `detailCommand` a true toggle: if `ctx.ui.panel.current()?.name === PANEL_NAME`, call the existing `closeDetail()`, otherwise open. Keep the one-shot suppress guard and the ✕ button.
4. Tests: extend `ui_view_test.js` for ▶ markers and omitted collapsed fields; extend `ui_setup_test.js` stubs so clicking a section row flips `visible` on pooled nodes with zero new `createElement`, the store mutation fires, and ctrl+g toggles close/open.
5. Run `node --check` and `node --test .opencode/plugins/beacon-project/*_test.js`. Report pass count. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Check: clicking ▼ collapses a section to ▶ with no blank gap; clicking again expands; ctrl+g closes and reopens; no `esc` label remains.

Accept: only plugin JS files. Verified APIs only (onMouseDown/onMouseUp, setProp, visible, storage.store). Keep files under 350 lines.
