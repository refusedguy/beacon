Extend `internal/infra/tasksource/parse.go` and the markdown adapter so YAML frontmatter accepts `kind: epic`, `base_branch`, `require_review` and a `plan` array of child specs `{title, scope, depends, priority}`. Generate deterministic child IDs as `<epic-id>-NN`. Keep the parser behind an interface so another decomposition strategy can replace it. Add tests for parsing and markdown Create. Do not change the dispatcher or reconciler yet. Run gofmt and targeted go test for changed packages, then open a PR and call beacon_watch_pr.
