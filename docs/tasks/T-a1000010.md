Goal: the harness reports a cancelled or deleted session, and the liveness probe tells an ended session from a busy one.

Evidence: harnesses/opencode/sse.go:85-101 drops every SSE frame except session.idle, so no cancel or delete frame reaches Beacon. HarnessEvent.Kind is a plain string at pkg/core/ports.go:84-90 with no death value today. opencode.go:363-375 returns false from IsAlive only on HTTP 404, and a cancelled session still answers 200. opencode.go:251-253 treats a 409 from Wake as delivery, so a nudge to a dead session is lost.

Steps: forward a session cancel or delete frame from the SSE reader in harnesses/opencode/sse.go and emit it from opencode.go with the kind value `session_dead` that the core handler branches on. Change IsAlive in opencode.go to distinguish an ended session from a busy one using an available API signal, and treat a 409 from Wake as failed delivery. Add harnesses/opencode/session_death_test.go proving the cancel frame is emitted and a dead session reports not alive.

Accept: a cancelled session produces a death event, IsAlive returns false for it, and a busy live session stays alive.
