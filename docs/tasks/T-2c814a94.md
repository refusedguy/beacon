Goal: Index the filtered and ordered reads used by FindByPR, FindActiveByTask, ListActive and ListByIncident.

Evidence: final-12. Those queries filter on one column and sort by updated_at using only single-column indexes. runs_state_idx is a redundant prefix of runs_state_updated_idx.

Steps: Add runs(pr_number, updated_at DESC), runs(task_id, updated_at DESC), a partial index on updated_at for active states and runs(blocked_incident_id, state). Confirm each with EXPLAIN and drop the redundant prefix.
