# S5.004. Время жизни workspace
Статус: dropped
Фаза: P4
Тип: task
Владелец файлов: internal/infra/server/projects/lifetime.go
Зависимости: S5.002, S2.005
Ссылка: ADR 0081
Агент: нет
Время: нет
Цель: Workspace живёт, пока есть SSE поток, с коротким grace window.
Контекст: Crush уничтожает workspace после отключения последнего потока.
Шаги: Счётчик активных streams, grace window после POST, teardown, сохранение сессий на диске.
Проверка: Тест отключения последнего клиента.
Приёмка: После teardown данные остаются, а живой процесс исчезает.

## Подтверждение
- PR #394 DROPPED: internal/infra/server/projects/lifetime.go отсутствует; жизненный цикл SSE-потоков брошен, HTTP/SSE не реализован, один процесс без серверного teardown (п.6, ADR 0086/0094).
