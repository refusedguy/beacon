Goal: CI publishes performance numbers for labeled PRs without blocking merge.

Evidence: cibench-02 and cibench-05. Ten perf2 PRs carry benchmark plans in their bodies, but CI never runs those plans. Local execution is forbidden. A full run on every PR costs 10 to 25 minutes and risks the 20 minute cap.

Steps: Add a job gated on the `perf` label with pull_request types opened, synchronize, reopened and labeled. Checkout head.sha with fetch-depth 0 and persist-credentials false. Use one cache key, warm the build, run the head-only smoke benchmark, upload raw log as a seven day artifact, and post or update one PR comment with a hidden marker. The job must exit zero on every path and add no required Criterion name. Do not set GOMAXPROCS in the shell.

Check: A labeled PR produces an artifact and a comment with work counts, error counts and limiter strings.

Accept: Unlabeled PRs skip the job. The job never blocks merge.
