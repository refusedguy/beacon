Goal: let an epic plan define a body for each child card, so creating an epic with plan produces children that carry their own instructions. No plugin or docs edits.

Evidence:
- pkg/core/task.go:123 ChildSpec has Title, Scope, Depends and Priority, but no Body.
- internal/app/taskcreate.go:462 childTasks copies those four fields into the generated child task. The child card is written without a body, so the operator saw five empty children after creating the ACP epic with plan.
- internal/infra/mcp/server.go:83 epicChildArg has the same four fields. buildCreateInput at :107 copies them into core.ChildSpec. There is no way to pass a child body through beacon_task_create.
- internal/infra/tasksource/parse.go:53 planSpec is the YAML wire shape and also has no body. childSpecs at :79 and planSpecs at :96 cannot round-trip one.

Steps:
1. Add Body string to core.ChildSpec.
2. Copy Body in childTasks in internal/app/taskcreate.go. Do not change epicTaskID or the idempotency key, so repeated creation stays stable; body changes should not create new card IDs.
3. Add body to internal/infra/mcp/server.go epicChildArg with JSON name "body", and copy it in buildCreateInput. Keep the basic single-card create path unchanged.
4. Add Body to planSpec in internal/infra/tasksource/parse.go with YAML key "body,omitempty", and handle it in childSpecs and planSpecs so markdown round-trips the child body. Do not put a child body in frontmatter of the epic card outside the plan array.
5. Tests: beacon_task_create with an epic plan containing child bodies produces child cards with those bodies; markdown write then read preserves each child body; a plan without bodies still works; single-card create is unchanged; existing epic idempotency tests keep passing.
6. Keep funlen <= 80 lines, statements <= 40, complexity <= 20. Run gofmt -w, targeted go test ./internal/app ./internal/infra/mcp ./internal/infra/tasksource and root go test . for arch. Leave full lint to CI.
7. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Accept: only pkg/core/task.go, internal/app/taskcreate.go and its test, internal/infra/mcp/server.go and its test, internal/infra/tasksource/parse.go and its markdown tests. No plugin JS, no docs, no task card edits.
