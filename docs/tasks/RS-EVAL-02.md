Цель: Запускать кейсы 12-15 и 19-20 пять раз и требовать пять успехов из пяти, остальные оставить однопроходными. Добавить таблицу карантина с лимитом в пять строк и сроком семь дней.
Контекст: Premise: проверено 2026-11-21, все кейсы проходят один раз. baseline: `grep -n 'contractToolCount' evals/main.go` = 43, `contractToolCount = 7` расходится с восемью инструментами в AGENTS.md. Источник: Anthropic demystifying evals, pass^k при 75 процентах даёт около 42 процентов на три trials.
Решение: Baseline подтверждён контрактом в `internal/infra/mcp/contract_test.go`: инструментов восемь, включая `beacon_defer_wiring`. Константа `contractToolCount` удалена, `contractTools` стал единственным источником истины, счётчик берётся как `len(contractTools)`. Хеш отсортированных имён заморожен в `frozenContractToolsHash` по образцу `frozenScenarioHash`. Харнесс `checkBridgeWakeDelivery` вызывается пять раз, кейсы 12-15 и 19-20 проходят через `passGate` с требованием ровно пяти успехов из пяти. Ошибка харнесса считается провалом прогона. Остальные кейсы читают первый прогон. Карантин живёт таблицей в `evals/README.md`: лимит пять строк, срок семь дней, просроченная строка блокирует.
Шаги: Пометить стохастические кейсы в таблице. Добавить счётчик повторов и требовать все пять. Завести таблицу FLAKY с датой истечения и лимитом. Сделать один источник истины для списка инструментов и заморозить его хеш по образцу frozenScenarioHash.
Проверка: gofmt чистый. Локальные `go test` и `go build` не запускались по правилам AGENTS.md, прогон eval и негативный контроль остаются за CI. Перед коммитом проверено скриптом: вычисленный хеш `contractTools` совпадает с замороженным, `passGate` блокирует при 4/5 и при четырёх прогонах, таблица карантина пуста, ровно шесть кейсов переведены на pass^5. Негативный контроль `PC01_pass5_negative_control`: один провал из пяти блокирует. `FQ01_flaky_quarantine_limits` проверяет лимит строк и срок негативными контролями. `CT01_contract_tools_frozen` ловит правку списка без обновления хеша.
Приёмка: Средний pass rate больше не скрывает нестабильность. Карантин не становится постоянной свалкой.
