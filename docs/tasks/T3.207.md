# T3.207. Разделить приём wake и вердикт через 202
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: 
Зависимости: T3.205
Ссылка: ADR 0079
Агент: нет
Время: нет
Цель: Сделать wake-вызов неблокирующим и не считать приём завершением работы.
Контекст: Hosted Agent SDK отвечает 202 Accepted и запускает handler фоном; steer Cursor отвечает 202 с delivery; Pi disposition started/queued/handled; Kilo resume:false — admit-only.
Шаги: Wake-handler отвечает 202 сразу, запускает работу фоном и публикует событие с deliveryId; вердикт приходит отдельным каналом.
Проверка: Ответ не содержит результата; hosted и локальный режим ведут себя одинаково; финальный статус не выводится из 202.
Приёмка: FINISHED/IDLE и agent_end не завершают задачу; завершает только verdict=ready, что соответствует оговорке Cursor про опрос latestRunId.
