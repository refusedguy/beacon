# CA-10. Подключение файлов по упоминанию в ответе
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/app/session/delegation.go, docs/templates/executor-task.md
Зависимости: 
Ссылка: docs/research/comp-aider.md
Агент: нет
Время: нет
Цель: Автоматически предлагать агентам файлы, которые они упомянули в ответе или карточке.
Контекст: Источник: docs/research/comp-aider.md, дополнение к CA-01. aider ищет в тексте ответа имена файлов и идентификаторы длиной от 5 символов, сопоставляет идентификаторы с файлами по нормализованному имени (`aider/coders/base_coder.py:690-707`), предлагает_add файлы группой подтверждений и запоминает отказ в `ignore_mentions` (`:1761-1781`). Успешное добавление возвращается как reflected message и вызывает следующий ход (`:1560-1567`). В beacon вход потомка задаётся полями `beacon_task_claim` (`docs/templates/executor-task.md:27-38`), а `ContextSnapshot` копируется от родителя (`internal/app/session/delegation.go:123-152`); упоминания из текста карточки или PR не расширяют контекст. Baseline: 0 файлов добавляется по упоминанию.
Шаги: Разобрать упоминания путей и идентификаторов в тексте карточки и ответе исполнителя. Сопоставить их с файлами репозитория по имени без расширения. Добавить в `ContextSnapshot` только после подтверждения, запомнить отказ. И отказ становится причиной reflected-сообщение для следующего хода.
Проверка: Взять 10 карточек с тремя упоминаниями файлов каждая. Требовать добавления не менее 25 из 30 уникальных файлов, отсутствия повторного запроса после отказа и появления reflected-сообщения при добавлении. Baseline 0 из 30.
Приёмка: Не менее 25 из 30 упомянутых файлов попадают в контекст после подтверждения, отказы не повторяются.
