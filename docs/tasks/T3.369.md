Статус: todo

Тип: task

Зависимости: T3.368

Агент: нет
Время: нет
Цель: Ограничить ожидание проверок и задать поведение при красном флейке.
Контекст: ADR 0072 п. 4 говорит, что красный классифицирует сабагент, а тулза не угадывает причину по названию проверки. FlakyConfig уже есть в домене.
Шаги: Подключить ci.waitFor к DeadlineAt, ci.pollInterval к интервалу моста. Политику classify оставить на сабагенте, retry разрешить только повтор в пределах maxRetries, block удерживать retry.
Проверка: go test ./internal/infra/cibridge. По истечении ci.waitFor Watch уходит в timeout без мержа.
Приёмка: Ни одна политика флейков не превращает красный в ready. Повтор не переносит расход retries в новый Watch без новой ревизии.
