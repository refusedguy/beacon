Add a read-only way to see what finished recently. In `pkg/core/ports.go` extend `RunStore` with `ListRecent(ctx context.Context, limit int) ([]*Run, error)`. Implement it in `internal/infra/sqlite/store.go` as `SELECT <runColumns> FROM runs WHERE state IN ('merged','closed','dropped') ORDER BY updated_at DESC LIMIT ?`. Add `StatusService.Recent(ctx, limit)` in `internal/app/status.go`. Add MCP tool `beacon_recent` in `internal/infra/mcp/server.go` with an optional `limit` argument, returning the runs as JSON; keep `beacon_status` unchanged. Add CLI flag `beacon status --recent` in `cmd/beacon/commands.go` that prints recent runs instead of active ones. Update fake stores in `internal/app/mocks_test.go` and add tests for ordering, limit and empty result. Keep all production files under 350 lines. Run gofmt and targeted tests, open a PR and call beacon_watch_pr.
