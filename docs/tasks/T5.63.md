## Подтверждение

PR #1128: https://github.com/refusedguy/beacon/pull/1128. Workflow `.github/workflows/tests.yml` добавляет job `registry-check`. Позитивный прогон читает `tools/beacon-gates/gate/config/registry.json` и ожидает код 0. Негативный прогон пишет во временный каталог конфиг с неизвестным ключом `bogus_key` и ожидает код 1, поэтому плохой конфиг роняет gate. В `cmd/beacon/main.go` подключена подкоманда `registry check --config <file>` поверх существующего `checkRegistryConfig`. Валидаторы не дублированы, `registry_stop.go`, `ci.yml` и реестр beacon-gates не тронуты, cardindex-правки не повторены. gofmt применён к `cmd/beacon/main.go`, новые YAML файлы разобраны локально. `go test` и `go build` по ADR 0022 не запускались, приёмка идёт в GitHub Actions.
