## Реализация

PR #1130 (ветка `fix/t3248-seat-address`) добавил адресную модель в `internal/domain` и путь доставки в `internal/infra/wake/deliver.go`. `ParseAddress` разбирает `member@rig` и отвергает роли, wildcard, пустые части и лишние разделители. `ResolveAddress` через порт `SessionResolver` возвращает одну конкретную сессию `ses_...`. `ValidSessionID` не даёт роли или адресу подменить сессию. `DeliverToAddress` резолвит адрес и проходит проверку `SubscriberTarget`.

Владелец закрепил в PR #1130 решение закреплять владельца обязательства за конкретной сессией. Адрес остаётся именем, которое резолвится в сессию. Это решение снимает блокер T3.241: модель seat появилась, доменные правки вне OwnerFiles внесены, решение владельца зафиксировано в слитом PR. Это решение закрывает проверку «смена сессии не меняет владельца обязательства», а не отдельный дубль кода.
