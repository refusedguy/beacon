# T3.241. Адрес исполнителя
Статус: todo
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. В `internal/infra/wake/deliver.go` нет типа адреса, парсера и резолвера для имени вида member@rig. `SubscriberTarget` принимает только точный `ses_...` подписчика Watch с ролью executor, orchestrator или fixer. Функция прямо запрещает подменять идентификатор сессии ролью или широкой рассылкой. `ValidateT210Target` проводит ту же проверку для wake-указателя. Владелец обязательства вычисляется как `ObligationKey(watchID, revision, subscriberID)` в `internal/domain/identity.go`, то есть привязан к сессии, а не к стабильному адресу роли. Смена сессии меняет владельца, поэтому проверка карточки «смена сессии за адресом не меняет владельца обязательства» не выполнена. `internal/domain/capabilities.go` даёт только `Role` и `ParseRole`. Этого недостаточно для адреса, который переживает рестарт агента. ADR про стабильный адрес роли в main отсутствует: main содержит ADR 0186 про указатель wake, а ADR 0186 «Стабильный адрес роли и поколение владельца» живёт только в ветке feat/batch-openrig-1103 без кода за ним. Родственные карточки T3.291, T3.321, T3.322, T3.323, T3.353 и T3.357 сняты в PR #394 по той же причине: в Beacon нет модели seat, а deliver.go для неё заглушка. diff HEAD..origin/main по OwnerFiles пуст. Реализация в OwnerFiles потребовала бы доменных изменений вне OwnerFiles и нарушила бы запрет на маршрутизацию по роли, зафиксированный в SubscriberTarget. Я её не писал. Статус todo сохранён, карточка остаётся неподтверждённым спайком до появления модели seat в Beacon, блокер возвращён оркестратору. OwnerFiles не менял, код не писал, дубль не создал, правка только текстовая.
