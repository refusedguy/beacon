Цель: Типизированные рёбра зависимостей и статус ready, blocked, stale, выводимый запросом по рёбрам
Контекст: ADR 0066. Сейчас зависимости это текст поля «Зависимости», а готовность задачи хранится отдельно. dev-graph держит зависимости рёбрами Blocks, ParentChild, WaitsFor, ConditionalBlocks и вычисляет ready, blocked и stale запросом по рёбрам.
