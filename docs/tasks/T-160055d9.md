Goal: Compile once in the workflow, then let downstream jobs restore warm objects.

Evidence: ciopt-06. Parallel jobs restore at start and their saves are first-writer-wins, so siblings never share compiled objects within a run. Each pays the cold compile cost.

Steps: Add one warm-up job that builds root and harness modules and runs go test -race -run '^$' over the matrix packages. Make verify, test-modules and perf-smoke depend on it.

Check: Downstream jobs restore a cache containing both normal and race objects and skip the cold compile.

Accept: GOCACHE is content addressed, so stale objects cannot be served.
