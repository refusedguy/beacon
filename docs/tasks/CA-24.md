# CA-24. Подтверждение перед вставкой вывода команды по его цене
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: docs/templates/executor-task.md, internal/infra/github/rest.go
Зависимости: 
Ссылка: docs/research/comp-aider.md
Агент: нет
Время: нет
Цель: Считать токены вывода команды и требовать подтверждения перед добавлением в контекст.
Контекст: Источник: docs/research/comp-aider.md, дополнение к CA-05. `/run` считает токены_OUTPUT всего вывода, спрашивает подтверждение «Add Nk tokens of command output to the chat?» и добавляет сообщение только при согласии; `/test` добавляет вывод автоматически только на ненулевом exit (`aider/commands.py:1013-1053`). В beacon failure excerpt имеет фиксированный лимит 2 КБ (`internal/infra/github/rest.go:30-34`) и не различает успешный и упавший вывод по цене; исполнитель получает отрывок независимо от размера. Baseline: цена вставки не известна.
Шаги: Добавить подсчёт токенов и порог подтверждения для вывода, вставляемого в wake. Для упавших проверок сохранить автоматическую вставку ограниченного фрагмента. Показать число строк и токенов в отчёте. Не менять вердикты.
Проверка: Взять 10 выводов: 5 малых и 5 по 100 КБ. Требовать, что малые вставляются без запроса, большие требуют подтверждения и не вставляются при отказе, а упавшие проверки дают фрагмент не более 2048 байт. Baseline: все 10 вставляются без оценки.
Приёмка: Большие выводы не попадают в контекст без подтверждения, упавшие проверки дают ограниченный фрагмент.
