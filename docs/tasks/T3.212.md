# T3.212. Убрать поля untrusted из buildPromptText
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.210
Ссылка: ADR 0062
Агент: нет
Время: нет
Цель: Оставить в тексте пробуждения только идентификаторы.
Контекст: buildPromptText добавляет untrusted.checkName, untrusted.prTitle и untrusted.branch. ADR 0017 требует указатель на запись, а не содержимое.
Шаги: Удалить три поля. Оставить обёртку <beacon-event> с watchID, obligationID, revision и verdictRef. Ограничить длину 512 символами.
Проверка: Имена проверок и заголовки PR не попадают в код, агента, тип RPC или URI. escapeUntrusted экранирует <, >, &, кавычки и управляющие символы.
Приёмка: Захваченный текст inbox содержит только разрешённые ключи и укладывается в 512 символов.
