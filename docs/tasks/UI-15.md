# UI-15. Действие ack обязательства
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/ui/actions/ack.go
Зависимости: UI-03, UI-08
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Подтвердить obligation с явным решением.
Контекст: Протокол различает approve, reject и пустой ack, который сохраняет plain contract.
Шаги: Диалог с тремя вариантами. Отправить watchID, obligationID, decision и revision.
Проверка: Тест проверяет, что повторный ack с устаревшим revision отклоняется.
Приёмка: ack не меняет delivered и не закрывает Watch.
