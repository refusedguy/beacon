Goal: the sidebar must show the queue on the first render after an OpenCode restart. Manual plugin reload currently fixes it. No Go edits.

Confirmed cause from a read-only investigation:
- ui.js:84 computes root once as deps.root ?? projectRoot(ctx) ?? process.cwd(). ui_model.js:330 repeats the same fallback in createStatusSource.
- location.js:40 projectRoot reads only ctx.location. At first setup ctx.location is often absent, so it returns null and the plugin freezes process.cwd() as the project root.
- ui_model.js:179-187 readCard builds <root>/docs/tasks/<id>.md and returns null when the file is missing. cardIsPending at :208-211 returns false for a null card, and createStatusSource:340 drops every queue item. With the wrong root all six cards vanish.
- The same wrong root is passed to CliStatusSource.#exec at ui_model.js:225-230 and pinned as BEACON_PROJECT_ROOT, so the CLI query also points at the wrong checkout.
- A fake ctx with no location produced queue 0; the same fake ctx with ctx.location.project.canonical set produced queue 6.
- Manual reload reruns setup when ctx.location exists, so projectRoot returns the canonical root and the queue appears. Polling cannot fix it because root and source are captured once at ui.js:84 and ui_model.js:330.
- Storage flags, lastSeenState and bridge.active were checked and are not involved.

Scope: .opencode/plugins/beacon-project/ui.js, ui_model.js, location.js, session_identity.js, ui_model_test.js, ui_setup_test.js.

Steps:
1. Defer root resolution instead of freezing process.cwd(). Resolve root from projectRoot(ctx) inside refresh(), or recreate the status source when ctx.location becomes available.
2. Apply the same rule in createStatusSource. Do not let a missing ctx.location become a cached cwd root.
3. Guard refresh so it does not call setSnapshot(EMPTY_SNAPSHOT) while the root is unresolved. Never cache the empty queue as a baseline.
4. Keep readCard fail closed for genuinely missing cards. Require a verified root before the filter at ui_model.js:340 is allowed to drop every item.
5. Tests: fake ctx without location at setup that gains it later shows the queue without a manual reload; wrong root never filters all cards; genuinely missing cards are still dropped; existing slot, toast and reload tests pass.
6. node --check every plugin JS file and node --test .opencode/plugins/beacon-project/*_test.js. Every file <= 350 lines. Open a PR, call beacon_watch_pr, do not self-merge.

Depends on the check-state card and the narrow-layout card, to keep scopes disjoint while they run.
