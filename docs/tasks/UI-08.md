# UI-08. Экран Watch detail
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/screens/watchdetail.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Видна история вердикта и все обязательства одного Watch.
Контекст: Beacon различает delivered, claimed и read, и storage версии важны для ack.
Шаги: Показать обязательства, ack, claimedAt, continueOf, revision и историю вердиктов.
Проверка: Тест на Watch с двумя обязательствами и пропущенным ack.
Приёмка:  Любая кнопка действия на экране имеет подтверждение.

## Подтверждение
- PR #394 DROPPED: История вердикта и обязательства доступны через beacon_get_result/watch_pr и store; internal/ui/screens/watchdetail.go отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
