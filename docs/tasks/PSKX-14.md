# PSKX-14. Сводка состояния из общего журнала перед продолжением
Статус: todo
Фаза: P8
Тип: doc
Владелец файлов: AGENTS.md
Зависимости: 
Ссылка: https://raw.githubusercontent.com/cursor/plugins/main/pstack/skills/recall/SKILL.md
Агент: нет
Время: 2026-11-22
Цель: Перед продолжением работы восстанавливать контекст не только из своего чата, но и из общего журнала: PR, issue, инциденты, откаты; проверять найденное живым состоянием через git и gh.
Контекст: Источник: `pstack/skills/recall/SKILL.md:20` (Sweep the shared record). `AGENTS.md:117-126` при обрыве требует прочитать `git status` и ключ `beacon/survival-rules`, но не требует просмотреть общий журнал симптомов и откатов. Из-за этого повторная попытка начинается без истории уже испробованных решений. baseline: `git grep -i -E 'общий журнал|сводка состояния' -- AGENTS.md | wc -l` = 0 на `origin/main`. Карточка фиксирует приём в дереве beacon, не создаёт новый глобальный скилл и не меняет протокол Watch. Не дублирует PSK-01 (кандидаты), PSK-02 (адверсарии), PSK-03 (TLA Watch), CP-01..05, CM-01..05 или закрытые дубли HD-099/HD-105/HD-109. Риск: низкий.
Шаги: Дополнить раздел «Перезапуск после смерти» шагом «Общий журнал»: для файла или подсистемы прочитать связанные карточки, PR и issue, выписать, что уже пробовали и что откатили, сверить статус через `git` и `gh`. Ограничить выборку последними семи днями и именем подсистемы. Требовать, чтобы сводка состоянияначинала открытые threads и следующий шаг.
Проверка: `git grep -n -E 'общий журнал|сводка состояния' AGENTS.md` находит шаг и формат сводки.
Приёмка: Продолжение без сводки общего журнала проваливает карточку. Симптом, который уже откатывали, не предлагается повторно без нового доказательства.
