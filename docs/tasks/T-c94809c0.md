Goal: a run must leave running when its agent session is cancelled or deleted, without waiting for an operator to notice.
Evidence: run run-cbc2304e60efbd54d51aca51 for T-4de758ed stayed running for 936 seconds with no live agent. harnesses/opencode/sse.go:85-101 drops every SSE frame except session.idle, and pkg/core/ports.go:84-90 has no death or cancel kind, so no signal reaches Beacon. The orphan sweep does run every tick, but idle.go:182-185 requires IsAlive to return false, and opencode.go:363-375 returns false only on HTTP 404; a cancelled session still answers 200 so closeOrphan at idle.go:189-205 never fires. An idle event alone cannot help because EvIdleNudge is self transition on running at run.go:123, and the nudge posts to a dead session while opencode.go:251-253 treats a 409 as delivery.
Steps: forward a session cancel or delete frame from the SSE reader with a new harness event kind; add the kind to core ports and branch in HandleHarnessEvent to call closeOrphan with a clear reason instead of nudging; keep the 90 second orphan sweep as a backstop and make the liveness probe distinguish an ended session from a busy one using an available API signal; add a test that a death event closes the run and frees its slot, and a test that the backstop still closes a stale running run.
Accept: cancelling an agent session closes the run within one tick and the next dispatch does not report task already has an active run.
