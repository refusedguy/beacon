# T3.22. Цепочка фолбэка агентов при 429 для CLI-менеджера
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/app/taskcli/service.go, internal/app/taskcli/service_test.go, internal/infra/mcp/tool_wake.go, internal/infra/mcp/tool_wake_test.go
Зависимости: T3.19
Ссылка: ADR 0031
Агент: нет
Время: нет
Цель: При 429 CLI-менеджер переводит задачу по цепочке Claude Code → Hermes → Gemini, сохраняя один и тот же идентификатор задачи; смена исполнителя видна в статусе.
Контекст: ADR 0031, раздел 4; отчёт Q 2.3 (cowork). Маршрутизация живёт в CLI-менеджере, не в ядре MCP. Владельцы types.go переданы T3.19, отсюда зависимость.
Шаги: Правило маршрутизации при 429 в service; цепочка исполнителей; отражение текущего исполнителя в wake и статусе.
Проверка: Тесты цепочки и квоты; внешний job id не меняется; статус показывает исполнителя.
Приёмка: При 429 задача доходит до доступного исполнителя без смены внешнего job id.
