# T3.376. Loopback receiver с HMAC-SHA256 и лимитом 25 MB
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/webhook/receiver.go, internal/infra/webhook/receiver_test.go, cmd/beacon/mcp.go
Зависимости: T3.375
Ссылка: ADR 0150
Агент: нет
Время: нет
Цель: Принимать подписанные доставки GitHub без публичного адреса в самом Beacon.
Контекст: go-github v93 даёт ValidatePayload, WebHookType, DeliveryID и ParseWebHook. ValidatePayload сам читает тело, проверяет подпись constant-time и ограничивает размер 25 MB. Контрольный вектор GitHub: секрет 'It's a Secret to Everybody' и тело 'Hello, World!' дают sha256=757107ea0eb2509fc211221cce984b8a37570b6d7586c22c46f4379c8b043e17.
Шаги: Поднять net/http на 127.0.0.1, взять секрет из файла state с правами 0600, отклонить пустой секрет, проверить подпись, разобрать X-GitHub-Event и action, записать доставку в журнал, ответить 2xx до тяжёлой работы. Обработать ping и неизвестные события.
Проверка: Поддельная подпись и отсутствующий заголовок дают 401 без записи; путьше 25 MB отклоняется; правильный контрольный вектор проходит; ответ приходит до фоновой обработки.
Приёмка: Handler не делает запросов к GitHub и не меняет вердикт напрямую.
