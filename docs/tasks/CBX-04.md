# CBX-04. Раздельный набор рёбер для поиска deadlock и для проверки изменений графа

Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/infra/taskstore/edges.go, internal/infra/taskstore/edges_test.go
Зависимости: 
Ссылка: https://github.com/gastownhall/beads (коммит 78624109904655d7a4609f27d34eb0982cd8963f)
Агент: нет
Время: нет
Baseline: beads: internal/storage/issueops/cycles.go:11-14 и :88-92 задают два разных набора рёбер; в beacon AddEdge в internal/infra/taskstore/edges.go:108-137 проверяет цикл по всем пяти типам без разделения.

Цель: Не смешивать граф взаимоблокировок и граф планирования при проверке новых связей.

Контекст: Источник, реальный код beads. DetectCyclesInTx на internal/storage/issueops/cycles.go:11-19 строит граф только из blocks и conditional-blocks и явно обходит обе таблицы. AppendSchedulingGraphInTx на :88-93 добавляет ещё parent-child и используется для валидации мутаций; обычный поиск циклов продолжает пользоваться более узким набором. Внутри appendDependencyGraphInTx на :95-120 фильтр типа живёт в одной точке. Разрыв в beacon: AddEdge на internal/infra/taskstore/edges.go:108-137 вызывает reaches(to, from) для любого типа, включая related и supersedes, поэтому связь «related» может быть отклонена как deadlock, а parent-child не проверяется как scheduling-ребро.

Шаги: Ввести две функции построения набора рёбер: блокирующий и планирующий. Поиск deadlock использовать только блокирующий. Проверку-cycle при добавлении ребра выполнять на планирующем наборе. Сохранить общую реализацию обхода и один фильтр типов. Обновить сообщения об ошибке так, чтобы было видно, какой набор рёбер замкнулся.

Проверка: Измеримая. Граф A blocks B, B parent-child C, C related A: отчёт deadlock содержит ноль циклов, а добавление C blocks A отклоняется планирующей проверкой. Добавление related-ребра, замыкающего путь только через related, принимается. Число рёбер в блокирующем наборе ровно два из пяти типов, в планирующем три. Ошибка валидации содержит имя набора.

Приёмка: CBX-03 отвечает за каноническую форму отчёта; здесь только выбор рёбер. Пять типов рёбер и внешние гейты остаются на месте.
