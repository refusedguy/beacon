# CV-04. Отклонение неизвестного режима плана вместо тихого понижения

Premise: проверено 2026-11-22 по `origin/main` `2d34645b`. Источник: OpenHands `src/hooks/chat/use-plan-mode-interceptor.ts:43-85` не отправляет команду смены режима, если агент RUNNING или нужный сокет закрыт. Неверный переход не превращается в молчаливое действие.

Разрыв: `planModeOf` в `internal/infra/mcp/tool_task_claim.go:542-548` возвращает `full` только для точного значения `full`, а любое другое значение, включая опечатку `ful`, превращает в `fast`. Ошибки и инцидента нет. Агент, который думал, что получил full-режим с отдельной веткой и PR, молча работает в fast-режиме и оставляет PLAN.md в текущем дереве. Существующий тест `TestFileTaskClaimPlanMode` в `tool_task_claim_test.go:311-329` проверяет только корректные значения.

baseline: `rg -n 'func planModeOf' internal/infra/mcp/tool_task_claim.go` = 1, строка 543; `rg -n 'return "fast"' internal/infra/mcp/tool_task_claim.go` = 1, строка 547; вызов `planModeOf("ful")` сегодня возвращает `fast`.
