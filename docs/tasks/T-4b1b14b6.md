Goal: The card panel should answer what task, which PR and how long in one glance.

Evidence: The current card header puts task ID and PR lower in the Technical section. The operator proposal is to show [task ID] [#PR] near the status and push total execution time to the right edge next to OK, ERR or RUN.

Steps: Build a compact header line from run.taskID and run.pr. Compute elapsed time from the first and last known event timestamps in the snapshot; if only updated_at exists, show that value with an explicit label. Keep the detail section unchanged. Preserve right alignment with the existing header layout.

Check: A fixture with task T-0ea563d7, PR 2534 and a 16 minute span renders one header line containing both and a right-aligned duration. Card view tests pass with byte-identical detail rows.

Accept: No wire shape change and no new TUI peer packages.

Open a PR, call beacon_watch_pr, do not self-merge.
