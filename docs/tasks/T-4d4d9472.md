Goal: CI fails when a second Solid or OpenTUI copy appears under the plugin.

Evidence: A local copy of @opentui/solid produces No renderer found because the host renderer context belongs to a different module instance.

Steps: Add a test that walks .opencode/plugins/beacon-project/node_modules recursively and fails if @opentui/solid, @opentui/core or solid-js exists anywhere. The existing CI plugin glob already runs it.

Check: The test passes on a clean tree, fails after creating a placeholder node_modules/@opentui/solid, and passes again after removal.

Accept: No production code change.
