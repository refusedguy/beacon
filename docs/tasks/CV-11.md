# CV-11. Аннотация read-only теряется при регистрации реального обработчика

Premise: проверено 2026-11-22 по `origin/main` `e2f34a060579d452c1ca6ca7845560b78b8b7629`. Источник: OpenHands `src/api/request-secret-client-tool.ts:47-53` и `src/api/launch-child-conversation-client-tool.ts:103-111` объявляют все четыре аннотации инструмента, включая `readOnlyHint`, `destructiveHint`, `idempotentHint` и `openWorldHint`. Клиент получает hints вместе с сигнатурой и строит поведение до вызова.

Разрыв: `annotationsForKind` в `internal/infra/mcp/server.go:284-295` ставит `ReadOnlyHint: true` для stub-регистрации инструментов типа `kindRead`. Реальный обработчик регистрируется поверх неё через Attach-хелпер. `attachToolAnnotations` в `internal/infra/mcp/tool_watch_pr.go:807-814` для всех инструментов возвращает только `DestructiveHint` и `IdempotentHint`. `AttachWaitResult` в `internal/infra/mcp/tool_wait_result.go:1423-1432` и `AttachWatchPR` в `tool_watch_pr.go:818-827` перезаписывают инструмент через `attachToolAnnotations` без `ReadOnlyHint` и `openWorldHint`. Клиент видит read-инструмент как записывающий, а инструмент с внешним эффектом не помечает `openWorldHint`.

baseline: `rg -n 'ReadOnlyHint' internal/infra/mcp/tool_wait_result.go` = 0. `rg -n 'OpenWorldHint' internal/infra/mcp/tool_watch_pr.go` = 0. `rg -n 'ReadOnlyHint' internal/infra/mcp/server.go` = 2, строки 287 и 820. `rg -n 'attachToolAnnotations' internal/infra/mcp/*.go` = 8 вызовов без `_test`.
