# T3.246. Проверка рендера в pane
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/verify_render.go, internal/infra/wake/verify_render_test.go, docs/tasks/T3.246.md
Зависимости: T3.249
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Различать доставку и подтверждение отображения.
Контекст: acknowledgement API подтверждает только приём промпта. Снимок pane до и после доставки показывает, попал ли конверт на экран.
Шаги: Снимать последние 40 строк до и после, убирать ANSI, CRLF, рамки и строку ввода, сравнивать конверт целиком или первые 40 символов.
Проверка: rendered-unconfirmed не считается ошибкой доставки.
Приёмка: Отчёт честно описывает экран, а не acknowledgement.

## Подтверждение

PR #1143: https://github.com/refusedguy/beacon/pull/1143. Добавлен `VerifyRender` в `internal/infra/wake/verify_render.go`. Он читает pane через `CapturePane` и порт `CommandRunner` из `internal/infra/wake/capture.go` (T3.249, PR #1135), поэтому слой захвата не дублируется. Нормализация убирает ANSI-последовательности, CRLF, пустые строки, рамки и приглашение ввода. Сравнение идёт по хвосту capture из 40 строк, полным конвертом и его первыми 40 символами. Исходы: `delivered`, `failed`, `retained`, `rendered-unconfirmed`. Ошибка захвата или пустой pane даёт `rendered-unconfirmed` без ошибки доставки. Тесты в `internal/infra/wake/verify_render_test.go` работают на фейковом runner из `capture_test.go`: совпадение после нормализации, расхождение, три варианта unconfirmed и retained. Живой tmux в этой среде недоступен, поэтому прогон идёт в CI. `gofmt` применён к обоим Go-файлам.
