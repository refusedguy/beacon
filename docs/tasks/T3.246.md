# T3.246. Проверка рендера в pane
Premise: перепроверено 2026-11-21 по свежему origin/main (1fc2baf на момент проверки; с тех пор main получает только docs-коммиты других карточек, OwnerFiles этой карточки не трогают). Функционал проверки рендера в pane в main отсутствует, дубль не создан. Проверил wake delivery и envelope. Доставка wake есть: `OpenCodeDeliverer.Deliver` (`internal/infra/wake/deliver.go:104`) через `PromptFunc` (:36, :174) и CLI fallback (:195); envelope wake это `Envelope` (:274) и `T202Envelope` (:686), они кладут в текст пробуждения только идентификаторы. Но это доставка текста в существующую сессию `ses_` через ACP/API, а не захват экрана. Карточка просит различать доставку и подтверждение отображения по сравнению capture pane до и после: последние строки, удаление input box, сравнение конверта целиком или первых 40 символов. Это механизм OpenRig `--verify` над tmux pane. Baseline: `git grep -inE 'capture-pane|rendered-unconfirmed' origin/main -- internal` пусто; `grep -Eic 'capture-pane|tmux|rendered-unconfirmed|rendered|retained' internal/infra/wake/deliver.go` = 0. Вхождения `verify` в deliver.go это вызов :219 и `verifyAck` (:378, :381); он проверяет, что API admitтил промпт по id в ответе, а не экран. Словарь статусов файла это T206 (started, queued, delivered, duplicate, closed, unsupported, :798-803) и T210 (:859-862), ни один не описывает проверку рендера. Beacon доставляет сообщение в сессию через ACP или API, tmux pane для захвата нет. Сестёрские карточки T3.266, T3.267 и T3.268 сняты в PR #394 по тому же основанию: tmux нет, OwnerFiles заглушка deliver.go. ADR 0062 берёт статус агента из событий жизненного цикла (`agent_start`, `agent_settled`) внутри процесса, а не из скрапинга экрана. Зависимость `docs/tasks/T3.245` в main остаётся todo. Реализующего PR нет: `git log origin/main --oneline --grep=T3.246` даёт docs-коммиты dda3c2a (#940), 6f81b66 (#729); `gh pr list --repo refusedguy/beacon --state all --search T3.246` — #729, #940, #733, #958, #732, все MERGED docs. diff HEAD..origin/main по OwnerFiles пуст. Настоящая проверка требует живого pane и OpenRig `--verify` с capture. Здесь доступны только правка текста и gofmt, живой зонд поднять нельзя. Код не писал, OwnerFiles не менял, gofmt не применял, чужие файлы, wiring и .beacon не трогал. Статус todo сохранён, блокер возвращён оркестратору.

Проверка: rendered-unconfirmed не считается ошибкой доставки.
