Goal: fix the runtime crash in the Beacon sidebar after PR #2362.

Error: "Plugin beacon-project-status crashed in slot sidebar.content: undefined is not an object (evaluating '[marker, name, status]')".

Root cause: .opencode/plugins/beacon-project/ui_nodes.js:42 reads the three text cells from box.children. The node-test stub gives every box a children array, but a real @opentui/solid box does not expose its children that way. box.children is undefined in the host, so destructuring throws.

Steps:
1. In createLineMount in ui_nodes.js, keep the three cell nodes in a local array when the pool is built (for example box.cells = [marker, name, status] or a parallel pool object). In apply(), read the cells from that stored array instead of box.children. Do not call createElement or insert in apply().
2. Add a regression test with a TUI stub whose boxes do NOT define a children array. Render the sidebar and call apply(). It must not throw and must set content on the three cell nodes. Keep all existing tests passing.
3. Check other production plugin files for box.children reads. There should be none.
4. Run node --check on every .opencode/plugins/beacon-project/*.js file and node --test .opencode/plugins/beacon-project/*_test.js.
5. Open a PR against main, call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Accept: only .opencode/plugins/beacon-project/**. No Go changes. No task card edits.
