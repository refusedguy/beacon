## Goal
Carry the daemon's refusal reason through the MCP control tool to the caller.

## Evidence
From T-7c7f30f9: postControlJSON now preserves the daemon's structured 409 reason instead of returning a bare status code, fixed in T-ae45da04. Batch control already marks a call failed when any item fails, fixed in 494e34ff. A caller that does not decode the refusal sees an empty reason.

## Steps
Decode WireControlRefusal and return action, id and reason in the result. Preserve per-id failure marking in batch control. Add tests in internal/infra/mcp/tool_control_test.go for a 409 carrying a reason and for a partially failing batch.

## Accept
Shared with sibling cards: an operator sees the original reason at every boundary, and no tool reports success when its main operation failed.
