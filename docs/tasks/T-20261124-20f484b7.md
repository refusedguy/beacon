Goal: make the sidebar Dispatch button produce runs with the correct parent session and model. No Go edits.

Evidence from the operator clicking the UI Dispatch button:
- It dispatched T-20261124-5875d3a4 as run-c2be9dcf17ec5c0754cf4704 and T-20261124-3af26a25 as run-15539d6c5eaa5a6464e64e14.
- Both runs have an empty parent_session_id. Their OpenCode sessions have parentID null and model null. Both would fail with "Add credits to continue, or switch to a free model". They were cancelled and their cards returned to available.
- A run dispatched through the built-in MCP tool has parentID and model hy4-flash-free and works.
- .opencode/plugins/beacon-project/ui_model.js CliStatusSource.#exec at line 231 sets only BEACON_PROJECT_ROOT in the child environment. dispatch() at line 253 runs "beacon dispatch <n>" with no parent session and no model.
- .opencode/plugins/beacon-project/index.js:173 already shows the supported way to read the current session ID from ctx: ctx.sessionID ?? ctx.session?.id ?? ctx.session?.sessionID.

Steps:
1. Give CliStatusSource an optional sessionID (or a resolver from ctx) and include BEACON_PARENT_SESSION in the environment of every CLI call, especially dispatch(). Use the same session ID that the MCP tools receive from _meta.
2. If the current session's model is available from ctx.session.get, pass BEACON_MODEL as well so a UI-dispatched worker uses the same model as this session. If it is not available, do not invent a value; rely on the Go-side model inheritance fix in card T-20261124-5c531933.
3. Keep status and control calls working with no session ID, so read-only polling does not fail in contexts without one.
4. Tests: dispatch() passes BEACON_PARENT_SESSION with the current session ID; a missing session ID does not break snapshot or control; the value is not printed in any error or toast; existing CLI source tests keep passing.
5. Run node --check on every plugin JS file and node --test .opencode/plugins/beacon-project/*_test.js. Keep every file <= 350 lines.
6. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Accept: only .opencode/plugins/beacon-project/**. No Go changes, no docs, no task card edits.
