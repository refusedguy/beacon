Goal: stop phantom blockers and stale run states. Root causes come from five read-only analyses of the daemon lock, terminal observations, needs_rebase loop, duplicate dispatch and dependency resolution.

Evidence: .beacon/daemon-error.json recorded 'beacon is already running' at 15:14, the MCP process holds beacon.lock but continues tool-only without a reconciler, so 8 runs froze in waiting_ci. GitHub check-runs list all attempts per SHA, so a cancelled lint shadows a later success and produces 'required check failed: lint'. greenButBehind at reconcile_observation.go:121 returns without NoteObservation, freezing observed SHA and looping needs_rebase. Reconciler.go:125-127 only finalizes terminal PRs after unrelated signal fetches succeed. Run.Reason is never cleared on success. SyncTasks at tasks.go:89-127 destructively overwrites Beacon 'done' with a stale working tree 'available'. readyTasksQuery uses JOIN tasks while ListQueueTasks uses LEFT JOIN, so a deleted dependency is dispatchable but shown as waiting_deps.

Steps, grouped by file, all with focused tests:
1. cmd/beacon/lock.go and cmd/beacon/mcp.go: give the lock an owner identity via daemon.json PID and heartbeat; treat a stale holder as free and reacquire; make failed ownership handoff fatal for the daemon role; log clean exits of the reconciler.
2. internal/infra/scm/github.go and pkg/core/verdict.go: group check-runs by name, keep the newest by completion time, map cancelled to skipped, restrict failure invariant to required checks.
3. internal/app/reconcile_observation.go and internal/app/reconciler.go: stamp head and base before the no-op return in greenButBehind using handlePending's ObserveSHA pattern; clear run.Reason on success and pending transitions; do not reuse failure reason on EvAgentFixed; classify terminal PR state before fetching checks and approvals.
4. internal/app/dispatcher.go and internal/infra/sqlite/tasks.go: make SyncTasks merge rather than delete rows so Beacon 'done' survives a stale file; treat a terminal run or closed PR as authoritative guard in candidate selection; include closed PRs, not only merged.
5. internal/infra/tasksource/cardindex.go: detect file removal independent of directory mtime and drop missing entries; TaskDeleter gets a Source so deletion and graph sync happen together.
6. internal/infra/sqlite/store.go and internal/app/status.go: make ListQueueTasks resolve dangling dependency edges the same way readyTasksQuery does, so the monitor stops showing waiting_deps for a deleted card.

Accept: after merging, the daemon survives MCP restarts without losing the reconciler, a cancelled check-run cannot block a merge, needs_rebase does not repeat with a fixed head, a closed PR closes its run and card, and the queue no longer shows phantom blockers.
Protocol: Work in your own worktree off current main. Never push to main. Never run go test, go build, go vet, linters, node tests or benchmarks locally. Open a PR without the perf label so mark-ready sets ready-to-merge. Call beacon_watch_pr. CI supplies every check.
