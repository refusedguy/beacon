# T3.454. Готовность к запуску без native enforcement
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/app/executor_status.go
Зависимости: T3.418
Ссылка: ADR 0223
Агент: нет

Цель: Различать «start finishing» и «агент действительно ориентирован».
Контекст: OpenRig startup status ready не означает oriented; oriented — отдельное значение из startup proof.
Шаги: Статусы startup/oriented/lifecycle/restore в одной проекции; ready отдельно от oriented.
Проверка: Тест: готовый процесс без proof не считается oriented.
Приёмка: Оператор видит, что прочитано, а что только запущено.
