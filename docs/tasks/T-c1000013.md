## Goal
Make the operator plugin report dispatch skips and failures instead of counting only successful runs.

## Evidence
From T-7c7f30f9: the plugin dispatch toast counts only runs.length and ignores skips and failures. ui_actions.js checks only ok false, so a partially failed result can look clean.

## Steps
Read the skipped and failure arrays from the dispatch result. Show their counts and the first reason in the toast. Treat a partially failed batch as a failure even when ok is true. Add tests in ui_actions_test.js for a result with runs, skips and failures.

## Accept
The toast reports skipped and failed counts with a reason, and no partial failure is shown as clean success.
