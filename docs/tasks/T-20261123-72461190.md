Context: run `run-8164ae7d298f6ce4e8c929f6` for task `T-20261123-d58f4151` was closed at dispatch with reason `workspace: conflict: refusing to remove dirty worktree`. The worker kept running, produced PR #2323 with all five checks green, but `beacon_watch_pr` returned `invalid_transition: run ... is already closed`. There is no `bind` control action. The PR had to be merged manually because the reconciler only finalizes PRs attached to active runs. The same class of stall happened with PR #2318.

Goal: a PR produced by a worker whose run was closed early must still be bound and finalized automatically, with no manual merge.

Steps:
1. Trace the workspace cleanup path in `internal/app/dispatcher.go` and `internal/app/finalize.go`. Determine why a run can be closed while its worker session is still alive and capable of opening a PR. Fix the ordering so cleanup does not close a run that still has a live worker.
2. Add a recovery path in `internal/app/control.go` for `watch_pr`: if the run is already closed but the task is not done and the PR is open, record the PR association so `finalizeExternal` can see it. Either reopen the run to `waiting_ci` or persist the binding independently of run state. Choose one and document the choice.
3. If a new control action is needed, add it to the tool catalog in `internal/infra/mcp/registry.go` and regenerate `opencode.json` with `go generate ./...`. Do not hand-edit generated permissions.
4. Tests in `internal/app/control_test.go` and `internal/app/dispatcher_test.go`: a worker that registers a PR after its run was closed by workspace conflict gets the PR bound and the run finalized when the PR merges; a normal active run still binds without change.
5. Run `gofmt -w`, `go generate ./...`, targeted `go test` for changed packages, and `go test ./...`. Open a PR and let the reconciler handle it.

Check: a PR opened by a worker after an early workspace-conflict closure is merged without operator intervention.

Accept: do not change task card rewrite logic or the verdict rules. Keep production files under 350 lines. Do not edit AGENTS.md or another card.
