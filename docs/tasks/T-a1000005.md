Goal: publishing and merging stop when a task card contains conflict markers.

Evidence: publishPath at internal/app/cardpublish.go calls rebaseBase then publishWithNFFRetry, and publishWithNFFRetry calls CommitPath. Reconciler.merge at internal/app/reconciler.go:189 calls commitCard before SCM.Merge at :215. A card with markers can reach either path, land on main, or be silently dropped from the index by a conflict.

Steps: call core.CheckCardMarkers on docs/tasks before CommitPath in publishWithNFFRetry at internal/app/cardpublish.go and before Reconciler.merge at internal/app/reconciler.go. Return an error that names the path and line so the caller stops. Add internal/app/marker_wire_test.go proving that a marked card blocks both the publish path and the merge path before any commit or push.

Accept: no card with a conflict marker is committed or merged, and the error names the offending path and line.
