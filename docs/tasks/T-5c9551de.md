Goal: A PR reaches all green checks in under 60 seconds of workflow start.

Evidence: cicd reports show six PR jobs run in parallel, but test takes 80s because four module suites are sequential. Build, vet and lint each repeat checkout and setup-go. plugin-tui-smoke downloads the CLI on every PR.

Steps: Merge build, vet and lint into one verify job with one checkout. Turn the four module test runs into a matrix on module, keeping -race -shuffle flags. Cache the pinned CLI by supported-cli.json. Keep perf-smoke, perf-nightly and the concurrency group unchanged.

Check: On one PR the slowest job is below 60s and trigger-to-green is below 60s on the Actions page. All module commands and flags remain in the workflow.

Accept: No production Go or plugin change.

Open a PR, call beacon_watch_pr, do not self-merge.
