# T3.209. Lease obligation с release и fail
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.206
Ссылка: ADR 0081
Агент: нет
Время: нет
Цель: Ввести аренду обязательства с окном воскрешения и явным отказом.
Контекст: Cursor claim резервирует запрос, повторный claim при живом lease отклоняется, потерянный ответ требует release, 409 означает чужой workerId или потерянный ответ; fail даёт текст пользователю.
Шаги: Добавить lease с wakeTimeoutMs; при живом claim отклонять повтор; по истечении возвращать obligation в created; реализовать release и fail с текстом, видимым пользователю.
Проверка: Повторный claim при живом lease даёт отказ; release после потери ответа позволяет claim снова; fail публикует причину.
Приёмка: Тихий таймайт исключён: не поднявшийся воркер даёт видимую причину, как fail и Try Again в Slack у Cursor.
