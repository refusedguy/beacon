Зависимости:

Цель: Подменить локальный tracer на экспортёр OTLP, не меняя вызовов Start.
Контекст: Sink получает завершённые спаны, SetTracer меняет процессный tracer. Исследование описывает otlptracehttp как простой вариант по умолчанию и OTEL_EXPORTER_OTLP_PROTOCOL со значениями grpc, http/protobuf и http/json.
Шаги: Прочитать BEACON_OTEL_EXPORTER; добавить Sink, который батчем шлёт спаны по OTLP/HTTP; вызывать Shutdown на выходе; оставить no-op при выключенном флаге.
Проверка: При недоступном коллекторе команда завершается и не теряет Watch; без BEACON_OTEL_ENABLED зависимость не загружается; тесты tracer проходят.
Приёмка: Переход на OTLP не меняет ни один вызов Tracer.Start и не добавляет полей в beacon_stats.
