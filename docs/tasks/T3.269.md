# T3.269. Host registry
Статус: dropped
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.241
Ссылка: ADR 0091
Агент: нет
Время: нет
Цель: Зарегистрировать удалённые хосты и их транспорт.
Контекст: Host registry OpenRig хранит HTTP и SSH записи, host select и selfHostId, а cross-host вызовы идут через daemon forward или CLI direct.
Шаги: Описать запись хоста, type transport, bearer pointer и резолвер адресов.
Проверка: SSH хост не используется для transcript и broadcast, там явная ошибка.
Приёмка: Межхостовые вызовы не требуют ручного URL везде.

## Подтверждение
- PR #394 DROPPED: host registry HTTP/SSH и selfHostId из OpenRig в Beacon нет: MCP только stdio, cross-host transport и resolver адресов отсутствуют; заглушка deliver.go.
