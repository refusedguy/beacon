Goal: an epic branch must exist before any child of that epic is dispatched. The operator asked for this explicitly and it was not done yet.

Evidence:
- internal/app/taskcreate.go childTasks at :462 writes base_branch: beacon/<epic-id> into every child card of an epic plan.
- No code creates that branch. When the ACP epic T-20261124-19651f36 was created, children -01 and -03 were dispatched and both failed with: workspace: git -C ... fetch origin beacon/T-20261124-19651f36: exit status 128: couldn't find remote ref.
- internal/infra/workspace/git_worktree.go:139 fetches the task's base branch before creating the worktree. If the branch does not exist on origin, the run closes immediately and no session starts.
- The epic itself has not opened a PR, so its branch normally would not exist until later.

Steps:
1. When an epic is created with a plan, create the branch beacon/<epic-id> from the current base branch and push it to origin. Make this idempotent: repeating the epic creation must not fail if the branch already exists.
2. Add a safety check on the dispatch path: if a task's base_branch starts with beacon/ and does not exist on origin, create it from the configured base branch and push before workspace.Create. Record one clear log line when this happens. Do not silently switch the child to main.
3. Rollback cleanly if branch creation fails. A failed branch must not leave a half-created epic or child cards.
4. Tests with a fake git workspace: epic creation creates and pushes the branch; repeated creation is a no-op; dispatch of an existing child with a missing branch creates it; a genuine git failure rolls back and reports an error; normal tasks on main are unaffected.
5. Keep funlen <= 80 lines, statements <= 40, complexity <= 20. Run gofmt -w, targeted go test ./internal/app ./internal/infra/workspace ./internal/infra/mcp and root go test . for arch. Open a PR, call beacon_watch_pr with the real run ID and PR number, do not self-merge.
