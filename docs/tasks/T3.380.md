# T3.380. CI-мост: пропуск blocked Watch
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/cibridge/bridge.go, internal/infra/cibridge/bridge_test.go
Зависимости: T3.379
Ссылка: ADR 0155
Агент: нет
Время: нет
Цель: Не пересчитывать вердикт blocked Watch по проверкам и закрывать её по терминальному состоянию PR.
Контекст: ActiveWatches возвращает только watching и notifying, поэтому blocked уже вне опроса. Без отдельного чтения терминальное состояние PR оставит blocked Watch сиротой.
Шаги: Прочитать BlockedWatches() в Refresh. Для blocked не вызывать verdictFromState, не двигать ревизию и не ставить wake. Для MERGED или CLOSED закрыть Watch. Оставить поведение watching и notifying без изменений.
Проверка: Зелёные проверки не снимают blocked и не меняют revision. MERGED закрывает blocked Watch. Число вызовов PRState для blocked равно нулю.
Приёмка: Опрос моста не трогает blocked Watch, кроме терминального закрытия PR.
