# S7.016. Установка фонового сервера
Статус: dropped
Фаза: P6
Тип: task
Владелец файлов: scripts/install-server.sh, deploy/beacon.service
Зависимости: S1.001, S7.014
Ссылка: ADR 0077
Агент: нет
Время: нет
Цель: Сервер поднимается как фоновая служба без ручного терминала.
Контекст: Цель: один общий сервис, а не процесс на задачу.
Шаги: systemd unit, launchd plist, auto start при первом MCP вызове, диагностика.
Проверка: Тест установки в контейнере.
Приёмка: После установки beacon status отвечает без запущенного TUI.

## Подтверждение
- PR #394 DROPPED: scripts/install-server.sh и deploy/beacon.service отсутствуют; ADR 0092 явно запрещает поднимать свой фоновый сервер рядом с работающим сервисом, это дубль уже dropped S1.001 (серверный entry point, pidfile, lease).
