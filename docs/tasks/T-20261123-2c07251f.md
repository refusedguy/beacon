GitHub returns 404 for PUT /repos/{owner}/{repo}/branches/{branch}/update because that endpoint does not exist in the public REST API. Our httptest mocked it, so tests gave false confidence. Fix `GitHub.UpdateBranch` in internal/infra/scm/github.go to call the GraphQL mutation `updatePullRequestBranch(input:{pullRequestId:$id, expectedHeadOid:$sha})` via POST to https://api.github.com/graphql using the existing token. Get the PR node ID from the REST PullRequest Get response (`node_id`). Read the new head SHA from the mutation response `updatePullRequestBranch.pullRequest.headRefOid`. Remove the 12x1s polling loop and the bogus REST URL. Add an httptest for the GraphQL POST that asserts the mutation name and variables, and returns a new head SHA. Keep all files under 350 lines. Run gofmt and targeted tests, open a PR and call beacon_watch_pr.
