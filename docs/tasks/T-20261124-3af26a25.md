Goal: make CI faster and close the missing plugin-test gap. No Go or plugin code edits.

Measured facts from three read-only investigations:
- GitHub Actions API over 100 recent runs: p50 31s, p90 38s, max 45s, zero runs over 60s. The steady-state workflow is not two minutes.
- Locally, warm cache: root go build 3.16s, root go vet 0.55s, root go test 1.71s, golangci-lint 6.96s, advisory 0.47s, all five commands sequentially about 14.5s.
- Locally, cold GOCACHE: root go build 74.35s, root go test 39.93s, golangci-lint 120.91s. That 121-second cold lint matches the operator's "two minutes" and is the real worst case.
- .github/workflows/ci.yml has five parallel jobs with no needs: dependencies. Every job repeats checkout and setup-go. setup-go downloads Go 1.26.0 for about 6-8s per job even though the runner image already has 1.26.11 cached. Each job restores the same 152 MB module cache in about 3.4s.
- 177 plugin tests run in 1.77s locally but no workflow step runs them.
- Merging build, vet and test into one job would serialize about 42s of commands and make the critical path worse than today's roughly 25s. Do not do that.

Steps:
1. In .github/workflows/ci.yml lines 23, 46, 67, 88 and 107, replace go-version-file: go.mod with go-version: '1.26' so setup-go finds the cached 1.26.11 toolchain. Note in the PR body that the exact patch is no longer pinned but go.mod still requires 1.26.0 and 1.26.11 satisfies it.
2. Under cache: true in those same blocks, add cache-dependency-path with go.sum and ui/tui/go.sum so the second module is part of the key. Accept one slower run on the key change.
3. Add paths-ignore for docs/** and **.md under both push and pull_request triggers, because 14 of the last 40 commits touch only docs and task cards. Note the branch is currently unprotected, so skipped checks cannot block merges today.
4. Fold the advisory job into lint: delete lines 99-110 and add "bash scripts/ci-advisory.sh" after the lint command. Accept that advisory annotations stop if an earlier lint step fails.
5. Add a node test step to the lint job: node --test .opencode/plugins/beacon-project/*_test.js. Use the runner's built-in Node, no setup-node and no npm install are needed.
6. Do not merge build, vet and test into one job. Do not change Go code or plugin JS.
7. Run actionlint or at least parse the YAML locally if a checker is available. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.
