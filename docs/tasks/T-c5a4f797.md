Goal: The live TUI uses the new event-delta path instead of always taking the full reload fallback.

Evidence: PR #2531 adds model.applyEvent and refreshMsg carries a wire event, but ui/tui/main.go still sends an empty refreshMsg. The binary therefore never reaches the delta path.

Scope: ui/tui/main.go and main_test.go.

Steps: Decode the SSE frame into the wire Event and pass it through refreshMsg. Keep fallback behavior for events without a run ID. Add a test asserting one event with a known run ID produces no runs GET.

Check: With a fake daemon and one event for a known run, a counting client records zero /api/v1/runs calls. Targeted TUI tests pass.

Accept: No wire shape change and no Beacon import in ui/tui.

Open a PR, call beacon_watch_pr, do not self-merge.
