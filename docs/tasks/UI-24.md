# UI-24. Командная палитра и справка
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/components/palette.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Все действия доступны с клавиатуры без памяти хоткеев.
Контекст: openrig использует command bar, tview позволяет переопределять клавиши через SetInputCapture.
Шаги: Палитра по ctrl+k, справка по ?, список действий текущего экрана.
Проверка: Тест проверяет, что каждое действие из палитры имеет хоткей.
Приёмка: Справка показывает клавиши для экрана, на котором открыта.

## Подтверждение
- PR #394 DROPPED: Командная палитра и справка уже в AGENTS.md, docs/templates и семи инструментах; UI-палитра не создаётся. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
