Цель: Ограничить размер карты в контексте потомка запрошенным бюджетом и адаптировать бюджет под пустой чат.
Контекст: Источник: docs/research/comp-aider.md, карточка CA-02. Для пустого чата aider берёт бюджет `min(map_tokens * 8, context_window - 4096)` (`aider/repomap.py:122-132`). Число тегов подбирается бинарным поиском по длине списка ranked tags (`repomap.py:666-703`), допустимая погрешность 15% от запрошенного бюджета (`repomap.py:689-696`). Подсчёт токенов идёт по выборке: при длине от 200 символов берётся примерно каждая сотая строка, считаются её токены и результат умножается на отношение длин (`repomap.py:89-101`). Перед отправкой `send_message` сверяет полный контекст с `max_input_tokens` (`aider/coders/base_coder.py:1396-1417`). При превышении модель получает ошибку и совет `/drop` или `/clear`. В beacon поле бюджета отсутствует. `ContextSnapshot` хранит строки без размера и без токенизатора (`internal/app/session/delegation.go:33-43`). Baseline: 47 559 байт статического текста на потомка по измерению `wc` для `AGENTS.md` и `docs/templates/executor-task.md`. Число не включает текст карточки, контракты скиллов и историю переписки.
Шаги: Добавить в `ContextSnapshot` поле запрошенного бюджета в токенах. Подбирать число тегов карты из CA-01 бинарным поиском по длине списка, как в `repomap.py:666-703`. Считать токены по выборке строк из `repomap.py:89-101`, а финальный размер проверять полным счётом перед передачей контекста потомку. Для пустого чата применять `min(map_tokens * 8, context_window - 4096)`. При превышении бюджета обрезать младшие по рангу теги, а не произвольную часть текста.
Проверка: Сгенерировать карту с запрошенным бюджетом 1024 токена и посчитать её реальный размер токенайзером модели. Требовать, чтобы отношение реального размера к запрошенному лежало в интервале 0.85..1.15. Повторить с пустым чатом и проверить, что бюджет не превышает `context_window - 4096`.
Приёмка: Карта укладывается в запрошенный бюджет с погрешностью не более 15%. При пустом чате бюджет не больше `context_window - 4096`.
