Context: after PR #2328 the Beacon sidebar TUI plugin fails at startup with No renderer found. Diagnosis: .opencode/plugins/beacon-project/ui.js setup() at lines 340-422 calls createElement eagerly (listBox 363-369, detail 370, mount 379-381). In OpenCode 2.3.2 the renderer context is active only inside slot render callbacks; createElement in setup() reaches the reconciler and throws.
