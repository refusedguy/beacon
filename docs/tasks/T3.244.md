## Блокер

- 2026-11-21. Точный блокер: `internal/infra/wake/deliver.go`. В этом OwnerFile доставка wake построена на PromptFunc HTTP API и CLI fallback. `Envelope(p)` отправляет текст пробуждения целиком, а не по символам в composer с нажатием Enter. В файле нет composer, режима draft-aware, held messages и сравнения ожидаемого текста с реальным перед Enter. Шаги карточки невыполнимы, а приёмку нельзя подтвердить без живого composer-зонда, который сравнивает текст до и после вставки и показывает, что поздний или изменённый человеческий ввод блокирует Enter. Такого зонда нет, как и живого pane или OpenRig; в среде доступны только правка текста и gofmt. PR #831, wake envelope и dedupe из PR #872 и PR #874 не работают с composer и не добавляют draft-aware режим, дубля нет. Для снятия блокера нужны модель composer в Beacon и живой зонд с настоящим pane. Статус todo сохранён, OwnerFiles не менял, код не писал, gofmt не применял.
