# T3.244. Draft-aware доставка
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/draft.go, internal/infra/wake/draft_test.go, docs/tasks/T3.244.md
Зависимости: T3.243
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Не отправлять Enter в чужой черновик.
Контекст: DraftAwareDelivery в OpenRig делает одну попытку и возвращает точную причину отказа вместе с исходными held id.
Шаги: Сравнить ожидаемый текст с реальным composer до и после вставки, требовать совпадения перед Enter.
Проверка: Изменённый или поздний человеческий ввод блокирует Enter.
Приёмка: Сообщение не прилипает к чужому черновику.

## Реализация

- `internal/infra/wake/draft.go`: порт `Composer`, адаптер `DraftAwareDeliverer` и типизированный отказ `DraftRefusal` с точной причиной (`foreign_draft`, `text_changed`, `composer_unavailable`, `commit_failed`) и исходными held ids. Одна попытка: читает composer до вставки (непустой текст означает чужой черновик), вставляет `Envelope(p)`, читает composer после вставки, требует точного совпадения и только потом вызывает `Commit` (Enter).
- `internal/infra/wake/deliver.go`: опциональное поле `OpenCodeDeliverer.DraftAware`. При non-nil доставка идёт через адаптер; отказ возвращается вызывающему без пометки obligation delivered, то есть остаётся повторяемым. При nil дефолтный путь `PromptFunc`/`deliverCLI` не изменён.
- Режим включается хост-слоем, который реализует порт `Composer` на реальном composer. Живого pane/composer/OpenRig в этой среде нет, поэтому адаптер проверен на фейковом `Composer`; точная причина отсутствия продакшен-подключения записана в TODO в `draft.go`.
