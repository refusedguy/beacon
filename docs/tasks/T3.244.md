# T3.244. Draft-aware доставка
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.243
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Не отправлять Enter в чужой черновик.
Контекст: DraftAwareDelivery в OpenRig делает одну попытку и возвращает точную причину отказа вместе с исходными held id.
Шаги: Сравнить ожидаемый текст с реальным composer до и после вставки, требовать совпадения перед Enter.
Проверка: Изменённый или поздний человеческий ввод блокирует Enter.
Приёмка: Сообщение не прилипает к чужому черновику.
