# T3.438. Считать повторные wake на один ключ
Premise: проверено 2026-11-21 по origin/main (2d5d771). Дубля нет: счётчика wake_duplicate_total и его вызовов нет, `grep -c 'wake_duplicate'` по обоим OwnerFiles дал 0. Дедупликация уже живёт в deliver.go: строка 120 гасит повтор по in-memory seen, строка 143 гасит повтор по зафиксированному в SQLite факту. Оба пути молча возвращают nil, поэтому дубли не видны в метриках. Карточка просит сделать их наблюдаемыми. Живой зонд не нужен: проверка сводится к наличию счётчика и двух точек вызова, весь код лежит в OwnerFiles. Реализовано: в observe.go добавлены константа CounterWakeDuplicate и функция WakeDuplicate, в deliver.go оба пути дедупликации вызывают её до возврата. Счётчик попадает в общий экспорт метрик через Inc, который записывает неизвестные имена как plain total. Зависимость T3.414 ещё не закрыта, но метрика не меняет логику доставки. Чужие файлы не тронуты, gofmt применён к двум .go.
