# UI-11. Экран сессий и адаптеров
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/ui/screens/sessions.go
Зависимости: UI-05
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Видно, какой adapter и target получит wake.
Контекст: Адаптер opencode будит сессию через prompt с delivery=steer.
Шаги: Список пар adapter и target с привязкой к Watch и последней доставке.
Проверка: Тест на двух адаптерах с одинаковым target.
Приёмка: Экран не показывает секреты из конфигурации адаптера.

## Подтверждение
- PR #394 DROPPED: Адаптер и target видны в подписчиках Watch через beacon_list_running и в реестре wake (internal/infra/wake); секреты в UI не exposeются, экран отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
