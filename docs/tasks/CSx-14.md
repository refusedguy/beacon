Цель: Передавать текст и рассуждения сабзагента вместе с идентификатором родительского вызова по запросу вызывающего.
Контекст: SDK по умолчанию пересылает только блоки `tool_use` и `tool_result` сабзагента как сообщения с `parent_tool_use_id` (`src/claude_agent_sdk/types.py:2669-2679`, `:1429-1435`). Опция `forward_subagent_text` включает полный вложенный текст и рассуждения с той же атрибуцией (`types.py:2669-2679`). История сессии несёт `parent_agent_id` для вложенных агентов (`types.py:2248-2258`). В beacon `WakePayload` содержит четыре идентификатора (`internal/domain/types.go:546-551`), а `Envelope` сериализует пять ключей без вложенного текста (`internal/infra/wake/deliver.go:479-495`). CS-03 добавляет атрибуцию `agent_id`, но не включает пересылку текста.
baseline: `rg -n 'forward_subagent_text|parent_agent_id|parent_tool_use_id' internal cmd` на `origin/main` 7244e15b даёт 0 строк; `rg -n 'prompt = d.Prompt' internal/infra/wake/deliver.go` даёт 1 строку.
Шаги: Добавить опцию пересылки текста сабзагента в конфигурацию доставки. Нести вложенное сообщение с `parent_tool_use_id` и `parent_agent_id`. Оставить текущий режим без вложенного текста как значение по умолчанию. Ограничить длину вложенного текста, чтобы wake не разрастался.
Проверка: Тест запускает сабзагент с текстовым блоком. При включённой опции вызывающий получает одно вложенное сообщение с родительским идентификатором. При выключенной опции вложенных сообщений нет. Измеримая проверка: число вложенных сообщений равно 1 и 0 в двух режимах; `rg -n 'forwardSubagentText|parentAgentID' <ветка> -- internal` даёт не менее 2 строк.
Приёмка: Вызывающий получает ход рассуждения сабзагента, когда он включён, и не получает его по умолчанию.
