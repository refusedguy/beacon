# UI-10. Экран Event log
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/screens/eventlog.go
Зависимости: UI-04
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: История wake, ack, claim и cancel доступна по одному Watch.
Контекст: Повторные доставки несут указатель на задачу, а не содержимое.
Шаги: Хронологический список с фильтром по watchID и типу события. Переход в Watch detail.
Проверка: Тест проверяет порядок событий и фильтр.
Приёмка: Текст события содержит watchID иRevision, но не полный результат.

## Подтверждение
- PR #394 DROPPED: Журнал событий уже в курсоре beacon_list_running (ADR 0025, WatchEvent) и в store; отдельный eventlog-экран не создаётся. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
