# T3.1. Плагин beacon-bridge.js одним файлом

Статус: done
Фаза: P3
Тип: task
Владелец файлов: .opencode/plugins/beacon-bridge.js
Зависимости: T0.3, T1.4
Ссылка: ADR 0006
Агент: нет
Время: 2026-11-19T20:30:00Z

Цель: Создать плагин V2 CLI 2.3.0 одним JS-файлом, который загружается без package.json и без импорта SDK хоста.

Контекст: ADR 0006 помещает адаптер вне Go-ядра: плагин это один JS-файл `.opencode/plugins/beacon-bridge.js`, ядро не содержит ни одного упоминания OpenCode. Отчёт E §1 и §2 показывает, что один JS-файл загружается без package.json и без импорта SDK хоста. WORKER-PROMPT §4.4 задаёт целевую версию V2 CLI 2.3.0, fail-open и запрет automation-пути, потому что `experimental.automations` это этап 2. WORKER-PROMPT §2 запрещает до G2 любые изменения `~/.config/opencode`; сниппет установки выдаётся владельцу текстом. T0.3 зафиксировал id плагина без префикса `opencode.` и место загрузки в V2 2.3.0. Поведение T3.2, T3.3, T3.4, T3.5 и T3.6 добавляется в этот же файл через цепочку зависимостей, каждая из этих карточек владеет своим тестом.

Шаги:
1. Создать `.opencode/plugins/beacon-bridge.js` с id плагина без префикса `opencode.`, без package.json и без импортов `@opencode/*`. Разрешить только встроенные модули Node, такие как `node:fs` и `node:path`.
2. Зарегистрировать минимальную точку входа плагина с `ctx.event.subscribe`, которая ничего не делает и не бросает исключение.
3. Проверить загрузку в изолированном `opencode serve` 2.3.0 с конфигом только в tmp. Плагин появляется в `/api/plugin` после создания сессии, до этого загрузка ленивая.
4. Добавить table-driven адаптер-тест, который проверяет один JS-файл, ноль совпадений с `from "@opencode/` в исходнике и ноль записей вне каталога состояния `$XDG_STATE_HOME/beacon`.

Проверка: `node --check .opencode/plugins/beacon-bridge.js` проходит. `grep -c '@opencode/'` по файлу плагина возвращает 0. Изолированный `opencode serve` 2.3.0 с tmp-конфигом показывает плагин в `/api/plugin` после создания сессии. Адаптер-тест проходит.

Приёмка: Один JS-файл без package.json, без SDK хоста, без упоминаний OpenCode в Go-ядре. Плагин загружается в V2 2.3.0. В чужие конфиги ноль записей.

Гейт: G2. Плагин готов к установке владельцем на canary, но воркер конфиг не применяет.
