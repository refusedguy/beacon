## Goal
Stop a transient read failure from turning an existing card into a new card.

## Evidence
From T-a697580c: taskcreate_batch.go swallows a task source read error and treats every card as new, so a transient failure can overwrite existing cards.

## Steps
Propagate the read error from existingBatchCards. Fail the batch before writing any card. Add tests in the new internal/app/taskcreate_batch_readerr_test.go that a read error leaves existing cards untouched.

## Accept
No card is written after a failed read of existing cards.
