# S2.002. Транзакционный notify envelope
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/infra/server/eventbus/bus.go
Зависимости: S2.001
Ссылка: ADR 0079
Агент: нет
Время: нет
Цель: События, проекции, receipt и outbox фиксируются одной транзакцией.
Контекст: Подписчик не должен видеть событие до коммита.
Шаги: Envelope с наборами persisted и registered токенов, сверка перед коммитом, доставка после.
Проверка: Тест прерванной транзакции.
Приёмка: Ни одного события от откатившейся транзакции.

## Подтверждение
- PR #394 DROPPED: транзакционный envelope противоречит отсутствию второго протокола (ADR 0086); обязательства уже в store (ADR 0028); eventbus/bus.go отсутствует, ADR 0094.
