Goal: close the state machine traps that leave a run active after its PR is terminal or fail to rebind a PR.
Evidence from read-only audit: pkg/core/run.go:121-124 gives needs_rebase and blocked no EvMerged and no EvChecksPassed edge, so both depend on the single finality check at internal/app/reconciler.go:125; if finalizeExternal fails before save there is no local path to terminal. Retry at run.go:284-299 keeps SessionID and WorkspacePath when PRNumber is nonzero, so a retried run can wake a dead session. RetryBlocked at :334-342 and unblockWithRebase at base_red.go:289 leave BlockedIncidentID set on runs that are no longer blocked. WatchPR at control.go:185 applies EvPRRegistered, which waiting_ci, needs_rebase and needs_agent_fix reject. A second active run sharing a PR masks the first because FindByPR at store.go:232-235 takes the newest updated row. ObservedSHA dedup at reconcile_observation.go:13-15 keeps needs_agent_fix and needs_rebase loops when check conclusions change on the same SHA.
Steps: add explicit terminal handling inside needs_rebase and blocked handlers that re-observes PR state and finalizes when terminal; clear session and workspace on every Retry path; clear BlockedIncidentID in RetryBlocked and when leaving blocked by any route; let WatchPR bind with MarkExternal from every non-terminal state and signal reconciliation; enforce one active run per PR at dispatch and detect duplicates on reconcile; include check conclusions and conflict state in the observation identity used by sameObservation.
Accept: no active run has a terminal PR, a retried run has no stale session or worktree, and beacon_watch_pr succeeds from any non-terminal state.
