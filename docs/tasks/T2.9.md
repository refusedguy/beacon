# T2.9. Контрактный тест семи инструментов и байт-бюджет tools/list
Статус: done
Фаза: P2
Тип: task
Владелец файлов: internal/infra/mcp/contract_test.go
Зависимости: T2.1, T2.2
Ссылка: ADR 0003
Агент: нет
Время: 2026-11-19T14:45:00Z
Цель: Зафиксировать контракт MCP: ровно 7 инструментов, выходные схемы, честные аннотации и реальный байт-бюджет ответа tools/list.
Контекст: WORKER-PROMPT §4.1 требует ровно 7 инструментов, обязательные output schemas и честные аннотации. WORKER-PROMPT §6, задача T1.1, задаёт байт-бюджет тест tools/list по методу Tirith: считать реальные байты, а не наличие полей. WORKER-PROMPT §7 относит это к уровню Contract.
Шаги: 1. Вызвать tools/list на тестовом сервере и собрать имена инструментов. 2. Проверить точное совпадение с ожидаемым списком из семи имён и наличие output schema у каждого. 3. Сериализовать ответ в JSON, посчитать число байт и сравнить с порогом.
Проверка: contract_test.go считает реальные байты сериализованного ответа и сравнивает с порогом. Тест обязан упасть при появлении восьмого инструмента или исчезновении output schema у любого из семи.
Приёмка: ровно 7 инструментов, байт-бюджет выдержан, у каждого инструмента есть output schema и честная аннотация.
