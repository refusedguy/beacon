Статус: todo
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. В `internal/infra/wake/acp.go` есть только клиентская часть ACP: `ACPAdapter`, `ACPStdioTransport`, `ACPHTTPTransport` и `PersistentACPClient` подключаются к внешним агентам opencode, claude, codex и pi. Записи registry, fallback-получателя через `acp.to` и запуска команды как custom agent без аргументов в main нет. `git grep` по `acp.to`, `agent.json`, `custom agent`, `ACP registry` даёт совпадения только в самой карточке, в .go-файлах ноль. ADR 0089, указанный в карточке, описывает производный индекс возможностей и два источника указателей SpoolSource и McpPullSource. Он не задаёт registry entry и `acp.to`. Без него регистрировать команду как агента нечего. Проверка «приложение без аргументов попадает к настроенному get receiver» и приёмка «установка сводится к добавлению custom agent в настройках приложения» требуют живого ACP-приложения OpenRig.
