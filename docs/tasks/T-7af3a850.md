Goal: The duration and reason column is right-aligned, and an hour-long wait keeps minute precision.

Evidence: The operator sees 'CI wait 1h' for a run that has waited 91 minutes and cannot tell how long beyond the hour it is. elapsed() in time_format.js picks the largest unit and floors, so 5467 seconds becomes '1h'. In ui_nodes.js the status cell follows the name cell in a row with no flex-grow or right anchor, so '1h' and the reason sit in the middle of the line.

Steps: Change elapsed so values of at least one hour render as '1h 31m' while short values stay '31s' and '12m'. Right-anchor the status cell in the line row using the host layout props available in ui_nodes.js. Keep the marker and title cells left. Preserve markerSpace alignment for second lines.

Check: A fixture with a 5467 second wait renders 'CI wait 1h 31m' with the status cell ending at the panel right edge. Existing duration tests are updated to the new precision and pass. Plugin UI tests pass.

Accept: No wire shape change. Do not change state colours or the header summary.
