# S2.009. Outbox и EffectWorker
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/infra/server/effects/outbox.go, internal/infra/server/effects/worker.go
Зависимости: S2.002
Ссылка: ADR 0079
Агент: нет
Время: нет
Цель: Побочные эффекты выполняются после записи намерения.
Контекст: Внешний I/O не может быть внутри транзакции решения.
Шаги: Outbox row, worker с retry, возврат результата в CommandProcessor, retirement при потере исполнителя.
Проверка: Тест повтора после сбоя воркера.
Приёмка: Effect не запускается до коммита и не дублируется после повтора.

## Подтверждение
- PR #394 DROPPED: outbox и EffectWorker дублируют obligation journal (ADR 0028) и авто-мерж (ADR 0072); effects/outbox.go и worker.go отсутствуют, ADR 0086/0094.
