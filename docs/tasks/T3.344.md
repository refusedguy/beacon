# T3.344. Internal leak scanner
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. Карточка просит leak scanner с терминами, allowed_context_lines и проверками на границах экспорта context packs, skill mirror, build-package и release substance gate OpenRig. В Beacon таких границ экспорта нет, как нет и самого OpenRig. `git grep -i -E 'allowed_context_lines|leak.?scanner|term.?check'` по всем refs находит только саму карточку T3.344.md и ни одного совпадения в Go-коде. `internal/infra/registry/secretguard.go`, который ROADMAP_STATUS:87 ошибочно называет OwnerFiles этой карточки, проверяет только конфиг автора реестра на token, key, password и auth.json; это guard конфига, а не сканер с терминами и списком разрешённых строк контекста. `observe.Redact` в internal/infra/observe/log.go и `sanitizeExcerpt` в internal/infra/mcp/tool_get_result.go маскируют секреты в логах и аннотациях, но не работают с навыками и бандлами и не имеют term check. OwnerFiles карточки internal/infra/wake/deliver.go и deliver_test.go содержат доставку wake: конверт, prompt, lease, дедупликацию; grep по ним для allowed_context_lines, term check, leak scan, context pack и skill mirror даёт 0. Карточка-сестра T3.240 уже зафиксировала, что deliver.go/deliver_test.go заглушка для этой серии OpenRig-карточек, PR #394 был снят по той же причине. Проверка «без локальных правил term check пропускается, но остальные проверки работают» требует настоящего конвейера экспорта и локальных правил; приёмка «секреты и приватные пути не попадают в навыки и бандлы» требует самих навыков и бандлов. Фейковый Runner в deliver.go подменяет только вызов `opencode api` и не моделирует границы экспорта, поэтому локально задачу не воспроизвести. Здесь доступны только текст и gofmt на слабом ПК, живого зонда и pane с OpenRig нет. Статус todo сохранён, блокер возвращён оркестратору: нужны границы экспорта OpenRig, локальные правила term check и живой зонд, либо пересмотр OwnerFiles. Код не писал, gofmt не применял, дубль не создал, OwnerFiles не менял, правка только текстовая.
baseline: `grep -Ec 'allowed_context_lines|term.?check|leak.?scan|context.?pack|skill.?mirror' internal/infra/wake/deliver.go` = 0, тот же grep по deliver_test.go = 0; wc -l = 1628 и 1100 после fast-forward до origin/main; `git log origin/main --grep='T3\.344'` = 0 коммитов; `gh pr list --repo refusedguy/beacon --state all --search 'T3.344'` = 0 PR; `git diff HEAD..origin/main` по OwnerFiles пуст после fast-forward.
