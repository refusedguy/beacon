# ARDH-17. Подключить ToErrorShape или удалить мёртвый конвертер
Статус: done
Фаза: P1
Тип: task
Владелец файлов: internal/infra/mcp/schema.go, internal/infra/mcp/tool_wake.go, internal/infra/mcp/tool_ack.go, internal/domain/types.go
Зависимости: 
Ссылка: ADR 0009
Агент: нет
Время: нет
baseline: Замер 21 ноября 2026 года, `rg` по нетестовым файлам в `internal/`. Вызовов `ToErrorShape` на живом пути 0. Вне тестов он вызывается только внутри `ToRepairableErrorShape`, у которого тоже 0 живых вызовов. Вызовов в тестах 13. Сырых возвратов `error` в хендлерах MCP 77. Источник: docs/research/error-handling-audit.md, находка 4.
Цель: Сделать ADR 0009 исполнимым: либо направить ошибки хендлеров через ToErrorShape, либо удалить неиспользуемый конвертер и честно описать сырые ошибки SDK.
Контекст: Источник: docs/research/error-handling-audit.md, находка 4 и рекомендация 1. ToErrorShape в schema.go:393 нет продуктивных вызовов, ToRepairableErrorShape в tool_wake.go:443 тоже живёт только в тестах. Риск: средний. Нужен owner-decision: какой путь выбрать, чтобы не изменить контракт MCP для агентов.
Шаги: Зафиксировать решение владельца. Если подключать, добавить общий адаптер хендлеров и тест формы ошибки. Если удалять, убрать конвертер и обновить ADR 0009.
Проверка: tools/list contract test проходит. Тестыerror формы зелёные в CI.
Приёмка: Контракт ошибок MCP описан и совпадает с кодом. Исключение для живого пути зафиксировано в ADR 0009.

## Решение

Выбрано явное исключение. Подключение `ToErrorShape` к живому пути заменит текстовую ошибку структурированной формой и изменит контракт MCP для агентов. Такой шаг требует отдельного решения владельца, поэтому в этой задаче он не выполняется. Формат ответов сохранён. В ADR 0009 добавлен раздел «Исключение: живой путь MCP». В `schema.go` обновлён комментарий к `ToErrorShape`. Конвертеры оставлены в коде и покрыты тестами.
