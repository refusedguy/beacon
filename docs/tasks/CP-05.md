# CP-05. Находка ревью выживает только с доказанным прогоном

Статус: todo
Фаза: P1
Тип: task
Владелец файлов: кандидаты `docs/adrs/0022-ci-only-verification.md`, `.opencode/skills/red-verdict-triage/SKILL.md`, `docs/RULES-CHECK-CONTRACT.md`

Цель: добавить правило, что комментарий ревью блокирует только при воспроизводимой команде и наблюдаемом выводе. Ревью без доказательства уходит в follow-up.

Контекст: `pstack/skills/arena/SKILL.md:9` открывает todolist из шести фаз до запуска. Rubric из трёх-шести критериев готовится до fan-out и скрыт от кандидатов (`:16`). Каждый кандидат работает в своём worktree (`:18`). Судья из другого вендора оценивает по критериям (`:28`, `:32`), лучшие части прошиваются вручную (`:38`), результат проверяется заново (`:44`). `interrogate/SKILL.md:9` устанавливает главное правило: находка выживает, только если прогон её доказал. Бриф в `:19` требует команду, её вывод и ожидаемый вывод. Проверка в `:23` перезапускает команду, отбрасывает неподтверждённое и соединяет находки по корневой причине. В beacon проверка идёт только в CI (`docs/adrs/0022-ci-only-verification.md:7-11`), а `red-verdict-triage/SKILL.md:12-18` классифицирует `failedChecks` по трём причинам. Правила для находок ревью такого вида нет.

Шаги: Добавить в `red-verdict-triage` поле доказательства для находки: команда, вывод, ожидаемый вывод, ссылка на head. Записать, что находка без команды не блокирует и переносится в follow-up. В `RULES-CHECK-CONTRACT.md` или правилах проверки документации отразить, что ревью требует того же доказательства. Оставить кросс-вендорного судью вне обязательных проверок.

Проверка: Каждый блокирующий комментарий содержит команду и наблюдаемый вывод. Тест document gate проходит без локальных сборок. `failedChecks` продолжает разбираться по трём причинам из `red-verdict-triage/SKILL.md:14-18`.

Приёмка: Правило не отменяет ADR 0022 и не добавляет локальных запусков. Docs-only PR. Судья из другого вендора не становится обязательным гейтом.

baseline: У pstack шесть фаз arena (`arena/SKILL.md:9`), четыре требования к ссылкам на фазы (`arena/SKILL.md:16`, `:18`, `:28`, `:38`, `:44`) и три шага проверки находки (`interrogate/SKILL.md:19`, `:23`, `:25`). У beacon одно правило CI-only (`ADR 0022:7-11`) и три причины красного вердикта (`red-verdict-triage/SKILL.md:14-18`). Тесты и гейты не запускались.
