# UI-20. Открытие внешней ссылки
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/ui/actions/open.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Перейти к PR или карточке из выбранной строки.
Контекст: Watch хранит PR и карточки хранят ID, но TUI не должен встраивать браузер.
Шаги: Клавиша открытия вызывает системную команду по ссылке. Ошибка показывается в статусной строке.
Проверка: Тест с подставным opener без реального вызова браузера.
Приёмка: Нет вызова внешней программы без нажатия клавиши.
