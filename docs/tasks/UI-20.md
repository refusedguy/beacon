# UI-20. Открытие внешней ссылки
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/ui/actions/open.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Перейти к PR или карточке из выбранной строки.
Контекст: Watch хранит PR и карточки хранят ID, но TUI не должен встраивать браузер.
Шаги: Клавиша открытия вызывает системную команду по ссылке. Ошибка показывается в статусной строке.
Проверка: Тест с подставным opener без реального вызова браузера.
Приёмка: Нет вызова внешней программы без нажатия клавиши.

## Подтверждение
- PR #394 DROPPED: Открытие PR/карточки внешней командой противоречит budget ADR 0060 п6 и отсутствующему UI; переход в сессию идёт через beacon attach. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
