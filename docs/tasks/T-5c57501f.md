Goal: Claim, Complete and MarkInWorkspace must not read and parse every card.

Evidence: opt-tasksource.md shows CardStore.find scans and parses the whole card directory on each state change.

Steps: Build a path-to-card index once per store lifetime and refresh it from file mtime or an explicit change signal. Keep aliases and format unchanged.

Check: A benchmark with 20,000 cards and 500 state changes reports one full scan, not 500, with identical returned cards and zero errors.

Accept: No card format change.

Open a PR, call beacon_watch_pr, do not self-merge.
