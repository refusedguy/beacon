Goal: CI catches TUI plugin load failures before the operator does.

Evidence: Cannot find package and No renderer found only appeared at TUI startup and were invisible to unit tests.

Steps: Run the OpenCode CLI version from supported-cli.json under a pseudo-terminal with the repository as cwd. Wait for the Beacon sidebar panel, then exit on a bounded timeout. Fail on No renderer found, Cannot find package, different core runtime module, or any plugin load error. Skip with an explicit log only when no PTY helper exists.

Check: The test passes on main and fails when a local @opentui/solid copy is injected or the peer is removed. It finishes within 30 seconds.

Accept: No production Go code and no wire change.

Open a PR, call beacon_watch_pr, do not self-merge.
