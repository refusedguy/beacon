# T3.204. Негативный контроль для теста wake
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: 
Зависимости: T3.200, T3.201
Ссылка: ADR 0076
Агент: нет
Время: нет
Цель: Доказать, что session.execution.started вызван именно steer-вызовом, а не совпавшей активностью.
Контекст: Нужен control, исключающий ложное срабатывание проверки wake.
Шаги: Отправить prompt с queue без PATCH; убедиться в отсутствии execution.started; затем PATCH в steer и убедиться в появлении.
Проверка: На idle-сессии interrupt возвращает interrupted false; GET /api/session/active не показывает сессию.
Приёмка: Без steer сессия остаётся idle; с steer появляется session.execution.started и затем session.idle.
