Restructure `.github/workflows/ci.yml`. Remove the single `verify` job and create five separate jobs: `build` (`go build ./...` for root, harnesses/opencode and ui/tui), `vet` (same three modules), `test` (same three modules, with `go test ./...`), `lint` and `advisory`. Use golangci/golangci-lint-action@v9.3.0 with `version: v2.15` in the `lint` job. Migrate `.golangci.yml` to `version: "2"` format and keep only errcheck, govet, depguard and funlen; configure funlen with lines 80, statements 40, ignore-comments true and exclude `*_test.go` from funlen. Do not enable gocognit, gocyclo or dupl. The `advisory` job must run `go test -run TestProductionFileSize -v .`, turn each `ADVISORY:` line from that test into a GitHub `::warning` annotation, exit 0, and keep its status green. Preserve least-privilege permissions, concurrency by ref and the three-module working directories from the current workflow. Verify the workflow YAML parses and that `golangci-lint run ./...` succeeds locally with the new config. Update AGENTS.md only if the CI check names changed. Keep production files under 350 lines. Open a PR and call beacon_watch_pr.
