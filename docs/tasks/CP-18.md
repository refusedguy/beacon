Цель: добавить шесть проверок манифеста и объявленных компонентов, чтобы отсутствующий файл или выход за каталог плагина ловился до PR.

Контекст: Правило `create-plugin/rules/plugin-quality-gates.mdc:10-14` задаёт шесть проверок: манифест существует и содержит имя, пути относительные и без `..`, объявленные пути компонентов совпадают с реальными файлами, у правил, скиллов, агентов и команд есть frontmatter с обязательными полями, область плагина узкая и установка описана в README, новые плагины сохраняются в каталог по умолчанию, если пользователь не попросил иначе. У beacon есть проверка индекса карточек: `README.md:126` говорит, что CI сверяет индекс побайтово с деревом карточек, а прекоммит блокирует устаревший индекс. Для плагинов и их манифестов такой проверки нет. В `AGENTS.md:21-25` описан хук `execute.before`, который отклоняет опасные команды, но не проверяет объявленные пути.

Шаги: Добавить в `AGENTS.md` раздел «Проверки манифеста» с шестью пунктами из `plugin-quality-gates.mdc:10-14`. В `docs/templates/executor-task.md` добавить шаг сверки объявленных компонентов с реальными файлами перед открытием PR. Оставить устройство индекса карточек из `README.md:126` без изменений.

Проверка: `git grep -n -E 'проверки манифеста|относительные пути|объявленные пути компонентов|frontmatter' AGENTS.md docs/templates/executor-task.md` находит все четыре строки. Число пронумерованных проверок в новом разделе равно шести. Индекс карточек по-прежнему собирается командой `beacon index build`.

Приёмка: Docs-only PR. Хук `execute.before` и число MCP-инструментов не меняются. Локальные тесты не запускались.
