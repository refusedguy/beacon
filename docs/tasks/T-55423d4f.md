Goal: An unchanged observation must not produce a store read and write on every tick.

Evidence: opt-app.md shows every reconcile decision calls LastDecision then RecordDecision. decisionSignature allocates on each comparison. At 500 runs this is 1000 store operations per tick.

Steps: Cache the last signature per run in memory and short-circuit before the store read. Preserve all Decision fields and sink output.

Check: With 500 Reconcile calls over ten ticks and unchanged observations, duplicate writes drop to zero after the first tick. Targeted app tests pass.

Accept: No verdict or wire change.
