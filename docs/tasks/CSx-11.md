Цель: Передавать промпт агенту дословно, чтобы тексты из карточек не раскрывали локальные файлы и не запускали команды.
Контекст: SDK включает опцию `verbatim_prompts` и помечает сообщения как `client_composed`. Документация прямо указывает, что это нужно для текста, собранного не пользователем: ссылка вида `@/absolute/path` не должна заставлять CLI читать файл (`src/claude_agent_sdk/types.py:2681-2709`). В beacon `spawnPrompt` вставляет заголовок карточки в строку приказа (`cmd/beacon/spawn.go:137-141`). Тип `UntrustedBody` уже отделяет тело wake от доверенных данных (`internal/infra/mcp/meta.go:398-419`), но в промпте нет отметки о его происхождении. CS-03 описывает сабзагентов как данные, а не безопасность текста.
baseline: `rg -n 'client_composed|verbatim|verbatim_prompts' internal cmd` на `origin/main` 7244e15b даёт 0 строк; `rg -n 'spawnPrompt' cmd/beacon/spawn.go` даёт 4 строки.
Шаги: Добавить флаг дословной доставки в конфигурацию спавна. Помечать промпт из карточки отметкой, которая запрещает раскрытие `@path` и запуск slash-команд. Передавать отметку через существующий порт доставки, не меняя текст приказа. Оставить текущий путь как поведение по умолчанию до переключения конфигурации.
Проверка: Тест передаёт заголовок карточки со строкой `@/etc/passwd`. Промпт содержит эту строку дословно, а счётчик обращений к файловой системе равен нулю. Измеримая проверка: `rg -n 'client_composed|verbatimPrompt' <ветка> -- cmd internal` даёт не менее 2 строк, число прочитанных файлов в тесте равно 0.
Приёмка: Текст из карточки не может заставить хост прочитать локальный файл или выполнить slash-команду.
