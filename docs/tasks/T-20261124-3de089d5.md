PART 1, PORTABILITY:
1. context.js: remove the hardcoded gofmt and go test wording from SURVIVAL_RULES. Use a universal rule: format changed files with the project formatter and run targeted tests for changed packages only; leave full builds, full test suites and repo-wide linters to CI on weak machines.
2. Remove the unconditional "bash scripts/build-beacon.sh" rule from ORCHESTRATOR_RULES. Change sessionInstructions to accept a fourth argument root. Only include the build-beacon reminder when existsSync(join(root, "scripts", "build-beacon.sh")) is true. Update every caller, including index.js, to pass the project root. Keep all other universal rules: rg -n, narrow Scope, beacon_watch_pr, beacon_status, beacon_recent, beacon_wait, beacon_control, beacon_task_create/delete/update, beacon_reconcile, and no blind dispatch.
3. index.js: confirm custom shellGuardRules extend the built-in rules for any project and do not assume a Go stack. mcp.js: confirm beaconCommand resolves a global beacon from PATH when neither .opencode/bin/beacon nor cmd/beacon/main.go exists. Add tests with a fake PATH-only environment.

PART 2, FOLD IN THE PENDING UI FIXES FROM CANCELLED CARD T-20261124-a274a702:
4. Fix the false RED banner. Go returns a stable zero-value BaseIncident object when there is no incident. ui_alerts.js baseIncidentItem must return null unless at least one of id, baseBranch, fixerRunID or failedChecks is non-empty. A real incident still produces the clickable RED banner opening fixerRunID.
5. Make Queue rows inspectable. queueLineItems adds cardID and action card:<id>. ui_sidebar.js routes that action to onCard(id). ui.js opens a read-only card view in session.panel with a distinct name such as beacon.card. Use a new readCard helper in ui_model.js reading docs/tasks/<id>.md with existing fs deps. Show full title, ID, priority, status, depends_on, path and the first 80 body lines with wrapMode word and no hard truncation. Give it a native-looking bordered card, padding, and buttons Copy ID, Copy path, and Copy fix prompt. The fix prompt text should be: "Fix <id>: <title> in <path>. Scope: <scope>. Depends: <depends>." Copy it to clipboard and show a toast so the operator can paste it into the current session. If a verified API exists to insert into the current session composer, offer that instead as an additional button; otherwise document that clipboard is the supported path.

7. Keep the friendly card formatting: aligned labels, calm muted body text, no bold brick, clear separation between metadata and body.
