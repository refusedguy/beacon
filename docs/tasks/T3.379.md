# T3.379. Локальный туннель и polling fallback
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: docs/runbooks/webhook-local.md, internal/infra/webhook/config.go, internal/infra/cibridge/bridge.go
Зависимости: T3.376
Ссылка: ADR 0151
Агент: нет
Время: нет
Цель: Дать оператору рабочий локальный приём webhook и гарантированный fallback без туннеля.
Контекст: smee.io рекомендован GitHub для локального теста, но не для production. ngrok даёт HTTPS и verify-webhook, cloudflared Quick Tunnel работает без аккаунта, но без SSE и со сменой hostname. Автоматического redelivery у GitHub нет.
Шаги: Описать три варианта туннеля в runbook, явно указать ограничения. Добавить конфиг receiver с адресом loopback и путём к файлу секрета. Оставить Refresh с интервалами 15/60/300 секунд и backoff по Response.Rate и RetryAfter.
Проверка: При выключенном туннеле вердикт приходит не позже 60 секунд; при включённом за 1-3 секунды; число запросов к GitHub при рассылке подписчикам равно нулю.
Приёмка: Beacon не открывает публичный порт, секрет лежит в файле 0600, второй credential store не введён.
