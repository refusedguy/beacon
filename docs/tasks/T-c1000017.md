## Goal
Give a timed-out wait caller the run ID, last state, reason and next action.

## Evidence
From T-7c7f30f9: beacon_wait timeout loses state and reason. From T-a697580c: tool_wait.go returns bare context deadline exceeded with no run ID or state.

## Steps
Return run_id, last_state, reason, timed_out and next when the deadline fires. Distinguish a deadline from a store error. Add tests in internal/infra/mcp/tool_wait_test.go for a timeout and for an ordinary store failure.

## Accept
A timed-out wait names the run and its last state instead of returning a bare error.
