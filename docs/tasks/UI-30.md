# UI-30. Нулевой этап: CLI с fzf
Статус: dropped
Фаза: P0
Тип: task
Владелец файлов: cmd/beacon-ui/select.go
Зависимости: UI-29
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Быстрый выбор Watch и выполнение ack или cancel без постоянного TUI.
Контекст: gum и fzf подходят для точечных диалогов, но не для живого дашборда.
Шаги: Печатать список в stdout, передавать выбор в fzf, вызывать действие через сокет.
Проверка: Тест на пустом вводе и на отмене выбора.
Приёмка: Команда не запускает фоновый процесс.

## Подтверждение
- PR #394 DROPPED: Выбор через fzf потребует второго процесса cmd/beacon-ui/select.go, запрещённого ADR 0060; точечные действия уже одноразовые CLI-команды (list/task/ack). Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
