Goal: make the queue readable by grouping tasks that share the same blocker and removing repeated dependency lines. No Go or docs edits.

Evidence: the live queue repeats the same blocked dependency in three rows and packs child, state, priority and dep count into one dense line. The queue and epic blocks touch Recent with no separation. PR #2395 fixed collapse and the child cap but not this.

Scope: .opencode/plugins/beacon-project/ui_view.js, ui_alerts.js, ui.js, ui_view_test.js, ui_alerts_test.js, ui_setup_test.js.

Steps:
1. Group queue items by unresolved dependency id. Render one header such as "blocked by 19651f36-01 · 3 tasks" and list titles under it. Never repeat the full blocker id per row.
2. For an epic show "epic · N children" in the summary. Expanded children stay under one blocker header.
3. Simplify rows: state as icon, priority in right column, dep count only when nonzero. Remove the literal child prefix from the name.
4. Add spacing between groups and before Recent. Keep Recent clickable and visible.
5. Tests: three tasks sharing a blocker yield one header and three title rows; different blockers yield different headers; epic expansion yields one blocker header; Recent stays present; existing queue and slot tests pass.
6. node --check every plugin JS file and node --test .opencode/plugins/beacon-project/*_test.js. Every file <= 350 lines. Open a PR, call beacon_watch_pr, do not self-merge.
