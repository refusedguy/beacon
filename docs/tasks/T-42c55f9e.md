Goal: One tool result must not marshal, copy to string and allocate three wrappers.

Evidence: opt-mcp.md shows jsonResult does all three on every mutation, status, dispatch and reconcile call.

Steps: Build the content slice directly and avoid the intermediate string copy where the SDK permits it. Keep wire bytes identical.

Check: A benchmark with 200 WireRun values reports lower allocs/op and B/op with byte-identical JSON and zero errors.

Accept: No tool schema or wire change.
