# T5.61. E2E регистрация на живом сервисе
Premise: проверено 2026-11-21, в origin/main функционал присутствует не в полном объёме, дубль не создан. Карточка просит E2E-проверку регистрации исполнителя на реальном opencode serve: спавнить сеанс, вызвать watch_pr с role=executor, проверить, что запись реестра содержит sessionID и config_id, и что sync работает; приёмка требует, чтобы вызовы без executor продолжали работать. По ADR 0088 (docs/adrs/0088-watch-registration.md) registration point это сам вызов beacon_watch_pr до фразы `waiting, watchID`, и он уже реализован: internal/mcp/tool_watch_pr.go принимает role и notify и берёт sessionID из `_meta["ai.opencode/sessionID"]`, а биндинг Watch к сеансу с config_id+sessionID пишется в store (T5.33, store/watch_bindings.go). Карточка-зависимость T5.57 ('spawn регистрирует исполнителя') снята в PR #394 именно потому, что привязка config_id+sessionID уже пишется watch bindings и second registration point давал бы тихий успех при ошибке записи; вторая зависимость T5.55 (registry sync) в origin/main всё ещё todo. OwnerFiles карточки tests/e2e/e2e_test.go (1223 строки) содержит сценарий runLiveMCPCycle, который поднимает реальный opencode с reference-плагином, вызывает beacon_watch_pr с role=executor и проверяет Watch (watchID, status, verdict, obligation, ack), но не делает assert на запись реестра с config_id и не вызывает/проверяет sync: `grep -Ec 'config_id|ConfigID' tests/e2e/e2e_test.go` = 0, `git grep -En 'config_id|ConfigID' origin/main -- 'tests/e2e/*.go'` = 0. Полноценная проверка требует живой пары opencode serve + reference plugin (её поднимает сценарий) и рабочего sync из T5.55. Здесь доступны только текст и gofmt на слабом ПК, живой зонд и прогон e2e-сценария недоступны, поэтому приёмку prove-it-works выполнить нельзя. Статус todo сохранён, блокер возвращён оркестратору: нужны живой зонд с opencode serve и закрытый или явно снятый T5.55, либо пересмотр зависимостей карточки. Код не писал, gofmt не применял, дубль не создал, OwnerFiles не менял, правка только текстовая.
