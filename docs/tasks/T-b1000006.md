Goal: connect the reconciler Dispatch port to the existing Dispatcher instance so the daemon can refill slots without an external loop.

Evidence: wireServices in cmd/beacon/main.go is the composition root for the daemon and MCP process. Dispatcher.Dispatch has two callers today, cmd/beacon/commands.go and internal/infra/mcp/tool_dispatch.go, so the reconciler has no dispatch path until it is wired here. No new table or store is needed.

Steps:
1. In wireServices, pass the existing Dispatcher instance as the Reconciler Dispatch port added by T-b1000005.
2. Keep the notifier and DecisionLogger wiring that the state-age watchdog in T-b1000005 uses. Do not add a new MCP tool or wire vocabulary.
3. Add a test in cmd/beacon/autodispatch_wire_test.go that a wired reconciler starts runs on a tick when auto_dispatch is enabled and starts none when dispatch_open is false.

Accept: the daemon serves with the Dispatch port connected, and manual dispatch and automatic dispatch share the same brake.
