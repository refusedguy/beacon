# T3.342. Seeded regression пары
Статус: todo
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. Карточка просит fault controller, seeds и обязательный прогон healthy, seeded, healthy в CI. Проверка должна доказывать, что один и тот же баг проходит на здоровом коде и падает на посеянном baton-drop. В origin/main нет fault controller, seed-механизма, каталога test/system/scenarios и сценарного раннера с приватным daemon и tmux. Ближайший артефакт это docs/evals/w25-seed-regression-artery.md, но там только описание сценария без кода. В evals/main.go есть проверка 11_verdict_regression на замороженном baseline, а не посеянный отказ на живом прогоне. ADR 0214 говорит, что покрытие только тестами impl не считается и сценарий должен проверять наблюдаемое поведение. Поэтому unit-тест с фейковым PromptFunc в OwnerFiles не закрывает карточку. Зависимость T3.341 в origin/main тоже todo с блокером: раннера с daemon, tmux, SQLite и stub-агентами нет, живой зонд невозможен, слабый ПК допускает только правку текста и gofmt. Родственная карточка S7.011 снята PR #394, потому что tests/scenarios/seeded.yaml и серверного harness в main нет. diff HEAD..origin/main по OwnerFiles показывает рабочую доставку wake, а не инфраструктуру посеянных отказов. Статус todo сохранён, карточка остаётся непроверенным спайком до появления живого зонда со сценарийным harness, блокер возвращён оркестратору. OwnerFiles не менял, код не писал, gofmt не применял, дубль не создал, правка только текстовая.
baseline: `git show origin/main:docs/tasks/T3.342.md` даёт статус todo без строки Premise. `git grep -i -E 'fault.?controller|baton.?drop|seeded regression|healthy.?seeded' origin/main -- '*.go' '*.md'` находит только ADR 0115/0146/0179/0214, карточки S2.004, S2.011, S7.011 и саму T3.342, то есть только документы. `git ls-tree -r --name-only origin/main | grep -iE '(^test/|scenario|fault|seed)'` даёт только docs-файлы, каталога test/ и раннера нет. `git log origin/main --oneline --grep='T3\.342'` даёт 0 коммитов. `git grep -n -i -E '\bfault\b|baton.?drop|inject' origin/main -- 'evals/*.go'` пусто, совпадения по fault в evals/main.go это ключевое слово default. T3.341 и S7.011 подтверждают тот же блокер.
