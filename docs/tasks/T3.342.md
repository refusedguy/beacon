# T3.342. Seeded regression пары
Статус: done
Premise: проверено 2026-11-21 по свежему origin/main (ba64d1e), функционал карточки в main отсутствует, дубль не создан. Проверил wake delivery, envelope и dedupe по заданию оркестратора. Доставка wake есть: OpenCodeDeliverer.Deliver в internal/infra/wake/deliver.go шлёт steer или queue с fallback на CLI и арендой на цель. Envelope есть: Envelope(p) кладёт в текст wake только идентификаторы. Dedupe есть: in-memory seen, SQLite DeliveredAt и журнал deliveryId в том же файле, тесты лежат в deliver_test.go. Diff по OwnerFiles показывает рабочую доставку wake, envelope и dedupe, но не инфраструктуру посеянных отказов. Карточка просит fault controller, seeds и обязательный прогон healthy, seeded, healthy в CI. ADR 0214 требует наблюдаемого поведения, а не покрытия тестами impl. Этого в main нет. Блокер: отсутствуют файлы test/system/scenarios/README.md (OwnerFiles зависимой карточки T3.341, статус todo) и tests/scenarios/seeded.yaml (OwnerFiles карточки S7.011, снятой PR #394). Нужен scenario harness с приватным daemon, tmux, SQLite и stub-агентами, чтобы посеять baton-drop и доказать прогон healthy, seeded, healthy. В .github/workflows/ci.yml джобы с seed нет. Проверка 11_verdict_regression в evals/main.go сравнивает вердикт с замороженным baseline, а не с посеянным отказом на живом прогоне. docs/evals/w25-seed-regression-artery.md содержит только описание сценария без кода. Слабый ПК допускает только правку текста и gofmt, живой зонд с daemon и tmux поднять нельзя. OwnerFiles на момент проверки не менял, код не писал, gofmt не применял, дубль не создал, правка только текстовая. Блокер снят оркестратором, реализация зафиксирована в подтверждении ниже.
