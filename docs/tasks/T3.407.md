Агент: нет

Цель: Вычислять идентификатор конфигурации сервером.
Контекст: Configuration ID в OpenRig это отсортированный список pod.member=runtime.
Шаги: Сортировать role=runtime, отбрасывать псевдонимы, класть digest и version в результат.
Проверка: Перестановка member'ов не меняет ID; смена runtime меняет ID.
Приёмка: Один и тот же конфиг даёт один ID на всех клиентах.
