Add an orchestrator-only MCP tool `beacon_task_delete` that accepts `ids: string[]` and deletes several task cards in one git commit and push. Put the use case in a new `internal/app/taskdelete.go` with a `TaskDeleter` service: for each id, remove `docs/tasks/<id>.md`, return per-id status (`deleted` or `not_found`), and keep the operation idempotent. Refuse the whole batch if any task has an active run according to the store, returning the offending ids and leaving the tree untouched. Reuse the existing base rebase and push helper from taskcreate rather than duplicating git logic. Wire the tool in `internal/infra/mcp/server.go` next to `beacon_task_create` and restrict it in `opencode.json` with the same deny-by-default and allow-only-for-orchestrator/build permissions. Add MCP in-memory tests for success, batch, not_found, active-run refusal and rollback, plus app tests. Update AGENTS.md only for the new tool signature. Keep production files under 350 lines. Run gofmt and targeted tests, open a PR and call beacon_watch_pr.
