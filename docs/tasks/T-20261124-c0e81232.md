Goal: restore merge notifications into the orchestrator session when runs are dispatched from the CLI. No JS or docs edits.

Evidence:
- Current OpenCode session: ses_df8826282ffePOV721qcP709CV. This is exactly the session my own process runs in.
- /mnt/projects/beacon-handoff/beacon-impl/.beacon/config.yaml has no harness.parent_session_id. The live daemon process has no BEACON_PARENT_SESSION in its environment. Every recent run in .beacon/state.db has an empty parent_session_id, so internal/app/finalize.go:23-24 returns before Harness.NotifyParent and no message lands in the chat.
- Older runs in the same DB do carry ses_df8826282ffePOV721qcP709CV in parent_session_id, and merge notifications worked then. Those runs were started through the beacon_dispatch MCP tool, which reads the session from _meta in internal/infra/mcp/tool_dispatch.go:41-52.
- cmd/beacon/mcp.go:27 and cmd/beacon/serve.go:23 read BEACON_PARENT_SESSION from the environment. cmd/beacon/commands.go:66 (dispatch) and :264 (control fallback) hardcode an empty parent. Any run started from the CLI therefore loses the parent session.
- cmd/beacon/main.go:180 gives the Dispatcher firstNonEmpty(parentSession, cfg.Harness.ParentSessionID), but line 190 passes the raw parentSession to newReconciler, so fixer runs lose the config fallback too.

Steps:
1. In cmd/beacon/commands.go, replace both wire(configPath, "") calls with wire(configPath, os.Getenv("BEACON_PARENT_SESSION")), matching serve and mcp.
2. In cmd/beacon/main.go:190, pass firstNonEmpty(parentSession, cfg.Harness.ParentSessionID) to newReconciler so the config fallback reaches fixer runs as well.
3. Export or keep a small helper parentSessionFromEnv() so tests can exercise it without touching the real environment. Add tests in cmd/beacon/commands_test.go and cmd/beacon/main_test.go proving that dispatch and control wire with the environment value, that an empty environment still works, and that the reconciler receives the config fallback when the environment is empty.
4. Keep funlen <= 80 lines, statements <= 40, complexity <= 20. Run gofmt -w, targeted go test ./cmd/beacon and go test . for arch. Leave full go test ./... and golangci-lint to CI.
5. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.
