# S3.009. Надзор за арендой executor
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/infra/server/registry/lease.go
Зависимости: S3.002
Ссылка: ADR 0080
Агент: нет
Время: нет
Цель: Мёртвые исполнители не получают wake.
Контекст: Процесс может исчезнуть без deregister.
Шаги: Периодический обход, marking unavailable, retirement эффектов, событие executor_lost.
Проверка: Тест с истёкшим lease.
Приёмка: Wake на мёртвого исполнителя возвращает executor_unavailable.

## Подтверждение
- PR #394 DROPPED: надзор за арендой дублирует registry stale/stopped (ADR 0090); registry/lease.go отсутствует, ADR 0094.
