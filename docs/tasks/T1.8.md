# T1.8. Атомарная запись вердикта, обязательства и wake-intent
Статус: done
Фаза: P1
Тип: task
Владелец файлов: internal/infra/store/atomic_write.go, internal/infra/store/atomic_write_test.go
Зависимости: T1.3, T1.4, T1.7, T1.12
Ссылка: ADR 0015
Агент: нет
Время: 2026-11-19T20:30:00Z
Цель: Записать вердикт, обязательство и намерение разбудить в одной транзакции, чтобы не оставалось половины состояния.
Контекст: ADR 0015: вердикт, обязательство и позиция лестницы пишутся в одной транзакции, идемпотентность через UNIQUE(watch_id, revision, subscriber_id). WORKER-PROMPT §4.2 невариант 7 требует мутации на диске до ответа клиенту и wake-intent в той же записи; §4.3 определяет staged как wake-intent в той же записи, что и вердикт. C §1.G и §4.4 требуют синхронной атомарной записи без await, ADR-0031.
Шаги: 1. Реализовать CommitVerdict(tx) с вставкой вердикта, обязательства по ключу T1.3 и wake-intent. 2. Сделать повтор той же тройки no-op через UNIQUE и ON CONFLICT. 3. Добавить тест отката посреди транзакции и тест порядка фиксация раньше ответа.
Проверка: Тест с принудительным откатом: нет вердикта без обязательства и wake-intent; повторный вызов не создаёт вторую строку; фиксация предшествует ответу.
Приёмка: Любая видимая клиенту мутация содержит все три компонента, повтор ключа не удваивает эффект.
