Сейчас новое решение владельца и результат выборки идут в чат одной строкой без структуры. baseline: `git grep -i -E 'ждут решения владельца' -- AGENTS.md | wc -l` = 0 на `origin/main`. Шаги: Дополнить тихий режим правилом: если работа уперлась в решение владельца, напечатать короткий список «ждет решения владельца», по строке на решение, со ссылкой на артефакт, вариантом и рекомендацией. Не включать в список работу, которую агент может сделать сам. Если решений нет, строку не печатать.
Проверка: `git grep -n -E 'ждут решения владельца' AGENTS.md` находит правило и признак пустого списка.
Приёмка: Каждая строка списка содержит ссылку и рекомендацию. Статусные строки «PR влит» по-прежнему запрещены.
