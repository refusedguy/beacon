# UI-27. Оптимистичное обновление и откат
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/actions/optimistic.go
Зависимости: UI-03, UI-04
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Действие отражается сразу и откатывается при конфликте revision.
Контекст: Библиотека Liquid Glass не нужна, достаточно сравнения revision из ответа.
Шаги: Применить изменение к модели, отправить запрос, при ошибке вернуть прежний снимок и показать причину.
Проверка: Тест с подставным ответом stale revision.
Приёмка: После отката экран показывает состояние сервера, а не локальную мечту.

## Подтверждение
- PR #394 DROPPED: Оптимистичное обновление с откатом по revision уже в обязательствах store и ack-контракте (ADR 0028); UI-слой не создаётся. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
