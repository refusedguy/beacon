# UI-13. Экран карточек задач
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/ui/screens/tasks.go
Зависимости: UI-01
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Карточки docs/tasks видны рядом с Watch.
Контекст: Формат карточки и поля описаны в beacon-task-cli-spec.md.
Шаги: Читать карточки через тот же парсер, что beacon task list. Показывать ID, статус, фазу, агента.
Проверка: Тест на карточке с нарушенным форматом.
Приёмка: UI не пропускает бракованную карточку молча.

## Подтверждение
- PR #394 DROPPED: Карточки уже читает beacon task list через общий парсер internal/app/taskcli; дублирующий UI-парсер не нужен. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
