# UI-03. Локальный control socket для действий
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/ui/transport/control.go
Зависимости: 
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Кнопки TUI вызывают MCP-инструменты через один локальный канал.
Контекст: stdio MCP рассчитан на одного клиента, поэтому второй процесс не может просто подключиться к тому же pipe.
Шаги: Поднять loopback HTTP или unix socket. Проксировать ack, cancel_watch, claim, release. Задать таймаут и число повторов.
Проверка: Тест вызывает действие через сокет и проверяет ответ при таймауте.
Приёмка: Действие с тем же watchID и revision повторно не создает второе состояние.
