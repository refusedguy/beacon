# UI-03. Локальный control socket для действий
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/transport/control.go
Зависимости: 
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Кнопки TUI вызывают MCP-инструменты через один локальный канал.
Контекст: stdio MCP рассчитан на одного клиента, поэтому второй процесс не может просто подключиться к тому же pipe.
Шаги: Поднять loopback HTTP или unix socket. Проксировать ack, cancel_watch, claim, release. Задать таймаут и число повторов.
Проверка: Тест вызывает действие через сокет и проверяет ответ при таймауте.
Приёмка: Действие с тем же watchID и revision повторно не создает второе состояние.

## Подтверждение
- PR #394 DROPPED: Control socket для кнопок TUI брошен: управление идёт через семь MCP-инструментов, lock по watchID+revision уже в обязательствах store (ADR 0028). Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
