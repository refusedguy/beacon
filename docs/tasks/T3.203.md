# T3.203. Побуждение через CLI opencode api
Статус: todo

Тип: task
Владелец файлов: 
Зависимости: 
Ссылка: ADR 0075

Цель: Будить сессию через CLI без написания плагина и без отдельного HTTP-клиента.
Контекст: orchestrator работает в shell; opencode api использует тот же сервер и авторизацию, что и TUI.
Шаги: opencode api GET /openapi.json; opencode api session.prompt --param sessionID=... --data ...; либо post path; подписаться на GET /api/event с types.
Проверка: Оба синтаксиса дают одинаковый результат; --server работает с указанным URL; SSE начинается с server.connected.
Приёмка: Команда будит сессию без плагина; подписка не показывает прошедшие события до подключения.
