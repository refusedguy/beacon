Goal: Make task deletion and update atomic in one commit.

Evidence: beacon_task_delete and beacon_task_update already commit batches, but each calls source operations separately and rollback discards os.WriteFile errors.

Scope: internal/app/taskdelete.go, internal/app/taskupdate.go, internal/app/taskdelete_test.go, internal/app/taskupdate_test.go.

Steps: Apply one transaction across all card files, sync SQLite once, and publish once. Join rollback failures with the original error. Add tests for a failed delete and a failed update restore.

Accept: A batch mutation ends in one push and a failed rollback is reported with affected paths.

Open a PR, call beacon_watch_pr, do not self-merge.
