# HD-014. Режим исследования
Статус: done
Premise: проверено 2026-11-20, дубль. Режим только для чтения перед реализацией уже в main. HD-013 (PR #534) добавил фазу explore в docs/templates/executor-task.md и docs/templates/orchestrator-task.md с владельцем «исследователь» и артефактом research-файл, фаза без артефакта проваливает карточку. Read-only research-агент .opencode/agents/issue-scout.md запрещает действия edit, write и shell, поэтому правка кода в explore ловится. Отдельный read-only gate `beacon gates rules` (HD-023, PR #537) проверяет изменённые файлы по каноническим правилам и возвращает exit 1 при нарушении. Eval docs/evals/hd08-explore-readonly.md фиксирует проверку «изменение запрещено, research записан» и негативный контроль «Код изменён: FAIL». OwnerFiles batch-apply уже имеют флаги --dry-run и --check, которые не пишут файлы. Новый explore-флаг там создал бы вторую копию режима только для чтения. Дубль не создан.
