# T3.250. Поиск по истории
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. В `internal/infra/wake/deliver.go` нет поиска по transcript или chat, нет выбора backend и нет снятия ANSI. `git grep HistorySearch origin/main -- '*.go'` дал 0 совпадений, `git log origin/main --grep=T3.250` дал 0 коммитов, `gh pr list --search T3.250` дал 0 PR, diff HEAD..origin/main по OwnerFiles пуст. Проверка карточки требует отсутствия rg и видимости выбранного backend. Оба условия воспроизводятся локально через внедряемый HistorySearchRunner: фейк возвращает exec.ErrNotFound для rg, и код переходит на grep -E. Живой зонд или внешний раннер не нужны. Реализовано в OwnerFiles: HistorySearch выбирает rg, при отсутствии переходит на grep -E, снимает ANSI и ограничивает выдачу по строкам и байтам. Тесты на фейковом раннере покрывают фолбэк, видимость backend, снятие ANSI, ограничения и отсутствие совпадений.
baseline: rg установлен в /usr/bin/rg, grep в /usr/bin/grep. На образце из трёх строк `grep -E` выдал 87 байт, после снятия ANSI 69 байт, то есть 18 байт (26%) приходятся на escape-последовательности. Сгенерированный файл на 50 строк занял 1341 байт без ограничения, реальный transcript крупнее. Замер подтверждает необходимость снятия ANSI и ограничения выдачи; поиск с явным backend и фолбэком на grep -E реализован в HistorySearch.
