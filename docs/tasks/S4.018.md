# S4.018. Фоновые задачи удерживают thread
Статус: dropped
Фаза: P3
Тип: task
Владелец файлов: internal/infra/server/wait/background.go
Зависимости: S4.008, S4.012
Ссылка: ADR 0089
Агент: нет
Время: нет
Цель: Thread показывает ожидание, пока фоновая работа не уляжется.
Контекст: t3code отличает awaited command от обычного фонового сервера.
Шаги: Флаг awaited, pendingBackgroundTasks, blockedOnThreadWait в проекции.
Проверка: Тест с awaited и не awaited задачей.
Приёмка: Только awaited задача удерживает thread в состоянии Waiting.

- PR #394 DROPPED: internal/infra/server/wait/background.go отсутствует; серверный wait/проекция thread брошены, long-poll уже beacon_wait_result (ADR 0094), фоновые задачи через адаптер (ADR 0086).
