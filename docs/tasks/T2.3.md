# T2.3. Чтение _meta ai.opencode/sessionID
Статус: done
Фаза: P2
Тип: task
Владелец файлов: internal/infra/mcp/meta.go, internal/infra/mcp/meta_test.go
Зависимости: T2.1
Ссылка: ADR 0001
Агент: нет
Время: 2026-11-19T14:45:00Z
Цель: Читать sessionID из `_meta["ai.opencode/sessionID"]` как nullable непрозрачную строку и не использовать его как авторизацию.
Контекст: WORKER-PROMPT §4.1 говорит, что sessionID берётся из `_meta`, может отсутствовать, и тогда обязателен notify.target. WORKER-PROMPT §2 запрещает ядру знать формат sessionID и использовать его как авторизацию. RESEARCH_SUMMARY фиксирует, что `_meta.ai.opencode/sessionID` приходит в каждом вызове MCP. ADR 0001 запрещает ядру упоминать OpenCode. Невариант 6 из WORKER-PROMPT §4.2 требует, чтобы ядро не интерпретировало sessionID и target.
Шаги: 1. Написать функцию чтения ключа из _meta запроса. 2. Вернуть nil, если ключа нет или значение пустое. 3. Передавать найденное значение дальше как строку без разбора и проверок.
Проверка: meta_test.go проверяет три входа: ключ есть, ключа нет, значение пустое. В двух последних случаях функция возвращает nil без ошибки. Значение не разбирается и не проверяется на формат.
Приёмка: отсутствие _meta не ломает вызов, sessionID не валидируется и не влияет на доступ, fallback на notify.target остаётся в T2.4.
