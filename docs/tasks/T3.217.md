# T3.217. Адаптер Pi RPC
Статус: todo
Premise: проверено 2026-11-21, функционал в origin/main отсутствует. В internal/infra/wake/registry.go AdapterPi по-прежнему зарегистрирован как unsupportedDeliverer: builtinDeliverer(AdapterPi) возвращает заглушку, Deliver отдаёт ErrUnsupported; в cmd/beacon/deliver.go нет Pi RPC-канала, а docs/evals/w05-pi-rpc-wake.md остаётся непроверенным спайком («живого wake через Pi в отчётах нет»). Проверил diff HEAD..origin/main по трём OwnerFiles: пустой, за время после снятия PR функциональность не появилась. Приёмка карточки требует живого probe через --mode rpc/--mode json/SDK createAgentSession (get_state idle -> processing, steer и followUp различаются в отчёте, доставка по умолчанию queue через followUp), который нельзя выполнить в этой среде: живого Pi-процесса нет, доступны только правка текста и gofmt на слабом ПК, а существующий internal/infra/wake/registry_test.go прямо требует ErrUnsupported для AdapterPi и не входит в OwnerFiles. Ранее PR был dropped именно по этой причине: «нужен живой probe с реальными OwnerFiles, иначе карточка останется незакрытым спайком». Не стал писать спекулятивный RPC-код без живой проверки: это повторило бы снятый PR, сломало бы registry_test.go и нарушило бы честность ADR 0026. Статус todo сохранён, карточка остаётся непроверенным спайком до появления живого Pi probe; блокер возвращён оркестратору. OwnerFiles не менял, код не писал, дубль не создал, правка только текстовая.

Контекст: НЕ ПРОВЕРЕНО: живой wake через Pi в наших отчётах нет. Overstory прямо говорит, что RPC-подключение connect() ещё не подключено к адаптеру. Это цель, а не доказанный канал (спайк W05).
Шаги: Проверить команды prompt, steer, followUp, abort, get_state, waitForIdle. Выяснить, пишет ли steer в спящую сессию или требует активного rpc-процесса.
Проверка: get_state показывает переход idle -> processing или растёт JSONL сессии. Guard extension не должен блокировать RPC-доставку.
Приёмка: steer и followUp различаются в отчёте, delivery по умолчанию queue через followUp.
