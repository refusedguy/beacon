# T3.182. Вызов wake-адаптера из CI-моста по терминальному вердикту
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/cibridge/bridge.go, internal/infra/cibridge/bridge_test.go
Зависимости: T3.179, T3.180, T3.181
Ссылка: ADR 0070
Агент: нет
Время: нет
Цель: Доставлять wake в том же цикле, где CI-мост зафиксировал терминальный вердикт
Контекст: ADR 0070 п3. Сейчас publish в internal/infra/cibridge/bridge.go сохраняет ревизию и обязательства, а wake доставляется отдельно. ADR 0017 разрешает повтор только для transport-failed и запрещает его для неопределённого исхода. Мост не мержит PR и не запускает проверки.
Шаги: Передать Deliverer в New или в отдельный конструктор моста без изменений MCP-инструментов; после успешного publish для вердикта, отличного от watching, вызывать Deliverer один раз на каждое новое обязательство; ключевать доставку парой obligationID и attempt и не слать второй prompt при повторном Refresh; при ошибке транспорта писать журнал и исход transport-failed, не меняя вердикт и не запуская повтор; написать тесты на терминальный вердикт, повтор Refresh, transport-failed и неопределённый исход
Проверка: go test ./internal/infra/cibridge
Приёмка: Терминальный вердикт вызывает адаптер один раз; watching не вызывает адаптер; ошибка доставки не меняет вердикт и не создаёт повтор; мост по-прежнему не мержит и не запускает проверки
