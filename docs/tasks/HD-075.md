# HD-075. Красный PR агенту
Статус: done
Premise: проверено 2026-11-20, дубль. Правило «красный PR принадлежит агенту, оператор не чинит за него» уже в main. ADR 0022 (коммит c1463d1) предписывает менеджеру при красном CI не чинить код локально, а возвращать PR агенту с причиной. Это совпадает с проверкой карточки. Направление мержа адресовано агенту и содержит причину. AGENTS.md в разделе «Блокеры main» требует от executor ответа beacon_ack с decision blocked:not_mine, а от оркестратора спавна FIX-агента и запрета чинить main. ADR 0258 закрепляет, что слот оркестратора не даёт права чинить чужой PR. README.md, GLOSSARY.md и шаблоны executor-task.md и orchestrator-task.md повторяют то же правило. OwnerFiles evals/main.go и evals/README.md содержат eval-движок и не владеют маршрутизацией красного PR, поэтому дубль в них писать не нужно. Статус done выставлен коммитом af0ac2e (PR #398) при триаже карточек. Код не писал, OwnerFiles не менял.
