Goal: let the daemon refill slots on each tick and alert once when a run stalls, before its rebase or fix budget is exhausted.

Evidence: Reconciler.Run calls only PromotePending, so a queue that empties stays empty while agent slots idle. The only wall-clock health check is the orphan sweep in internal/app/idle.go:106, which acts on running runs with PRNumber zero after 90 seconds. A run in waiting_ci, needs_rebase, needs_agent_fix or blocked can keep a fresh UpdatedAt from observations and never alert. Card history records runs stuck in these states. The operator currently finds them by reading snapshot timelines.

Steps:
1. Add a Dispatch port to Reconciler and call it from Reconciler.Run after PromotePending only when auto_dispatch.enabled and dispatch_open are true. Pass a budget from Dispatcher.Available so no cap is exceeded. Emit a decision row on each auto dispatch with the count of started runs and skips.
2. Add checkStateAges(runs) and call it from the ListActive branch of Reconciler.Run. For each non-terminal run whose time in state exceeds its configured age, send one notification containing run ID, task, state, age and last reason, and record a decision row.
3. Use ClaimDelivery with a key per run and state, the same mechanism idle nudges use, so repeated ticks do not repeat the alert. Call ReleaseDelivery when the run leaves the state so the alert can fire again on a later stall.
4. Reuse the existing notifier and DecisionLogger. Do not add a new wire vocabulary or MCP tool.
5. Add tests in internal/app/reconciler_guard_test.go for disabled by default, enabled starting up to budget, no double start of a task that promotion already selected, no alert under the default age, one alert after the threshold, no duplicate alert on the next tick, and a fresh alert after the run returns to the state.

Accept: with auto_dispatch enabled the daemon keeps slots occupied without an external loop, dispatch_open false freezes intake while active runs keep reconciling, and a quiet daemon produces no repeated alerts.
