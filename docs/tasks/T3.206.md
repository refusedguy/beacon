# T3.206. Ввести deliveryId и журнал доставок
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: 
Зависимости: T3.205
Ссылка: ADR 0078
Агент: нет
Время: нет
Цель: Исключить двойную доставку wake-сигнала при повторах webhook и сетевых ошибках steer.
Контекст: Cursor: X-Webhook-ID уникален, Idempotency-Key даёт 422 при том же ключе с другим телом, steer после сетевой ошибки может дойти дважды. Pi: requestId и signal key.
Шаги: Добавить deliveryId в WakeRequest; для входящих webhook брать X-Webhook-ID; проверять Idempotency-Key; писать журнал и пропускать повтор по тому же ID.
Проверка: Повтор с тем же deliveryId и телом не создаёт вторую работу; результат совпадает с duplicate в Pi и pendingWake в Kilo.
Приёмка: Повтор steer с тем же ID не запускает второй turn; ключ зафиксирован до внешнего вызова, как api.memo в Pi.
