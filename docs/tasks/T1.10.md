# T1.10. Импорт квитанций из receipts.jsonl в базу
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/infra/store/receipts.go, internal/infra/store/receipts_test.go
Зависимости: T1.7, T1.12
Ссылка: ADR 0015
Агент: нет
Время: нет
Цель: Перенести факты доставки из файла плагина в базу идемпотентно по паре (obligationID, attempt).
Контекст: ADR 0015: квитанции остаются отдельным receipts.jsonl, плагин дописывает строку, Beacon одной транзакцией переносит факт в базу. ADR 0014: одна квитанция на событие и попытку, файл создаётся атомарно через флаг wx, Beacon читает только целые строки, состояния posted и transport-failed. WORKER-PROMPT §4.4: идемпотентно по (obligationID, attempt), отсутствие квитанции это indeterminate.
Шаги: 1. Читать файл по полным строкам, игнорируя хвост без перевода строки. 2. Вставлять квитанции с UNIQUE(obligation_id, attempt) в одной транзакции с обновлением обязательства. 3. Мапить posted в deliveredAt, transport-failed оставлять без deliveredAt.
Проверка: Тест повторного импорта того же файла не меняет число строк; тест с обрезанной последней строкой; тест, что posted и transport-failed дают разные состояния обязательства.
Приёмка: Повторный импорт не дублирует квитанции, неполная строка не импортируется, indeterminate не превращается в posted.
