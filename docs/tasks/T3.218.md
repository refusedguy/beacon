# T3.218. Адаптер Kilo локальный и облачный
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.210
Ссылка: ADR 0065
Агент: нет
Время: нет
Цель: Доставлять wake в Kilo через session/prompt по ACP или HTTP kilo serve, либо через kilo cloud send.
Контекст: НЕ ПРОВЕРЕНО: совместимость HTTP-маршрутов kilo serve с OpenCode V2 не проверена (спайк W06). Практический вывод из отчёта: до проверки адаптер обязан возвращать queue, а не steer.
Шаги: Проверить kilo acp и kilo serve. Для облака использовать kilo cloud send --session-id. Автономный kilo run несовместим с --continue.
Проверка: Подтверждать через kilo cloud status|result или transcript локальной сессии.
Приёмка: Адаптер честно пишет unsupported или queue, успех не имитируется. Сообщение в облаке ограничено 15 минутами.
