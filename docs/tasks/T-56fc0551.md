Goal: make Available match live worker sessions and stop a failed run from blocking its own fix.
Evidence: ActiveAgent counts only running and needs_agent_fix, so a woken run that moved to waiting_ci releases its slot while its session is still active. hasAgentSlot in wake reads Available which includes the run being woken, so with the limit at 1 one failed run can never wake. The orphan sweep only inspects running runs with PRNumber zero, so a dead session on a PR-bound run holds a slot forever. Wake and nudge reserve nothing, so two forced reconciles can pass the same free slot. ensureFixer and spawnEpicReviewer spawn without a reservation and the reviewer creates no run row. handleStartFailure leaves a live session with no run row when the final save fails. Retry on a closed run with a PR keeps a stopped SessionID.
Steps: add AvailableFor(runID) that excludes the calling run and use it in wake; persist an AgentHeld or SessionLive flag set on spawn and wake and cleared when the session is confirmed gone, and count it in availableFrom instead of the bare state; widen the orphan sweep to every nonterminal run with a SessionID; add ReserveForWake that checks and reserves in one slotsMu section; acquire a reservation before fixer and reviewer spawns and persist a run row for the reviewer; stop the session and force-remove the worktree when the final save after spawn fails; clear SessionID in Retry when the PR branch is taken.
Accept: wake cannot deadlock on its own slot, Available tracks live sessions, and no live session exists without a run row.
