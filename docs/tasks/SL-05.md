Цель: Не допускать запуска, если OwnerFiles двух карточек в одной волне пересекаются, и сообщать об уже существующем пересечении активных карточек.
Контекст: Источник: docs/research/research-parallel-slots.md, раздел «Concrete race: two agents, overlapping files». `AdmitLaunch` получает только активные карточки и одного кандидата (internal/app/taskcli/service.go:640-659). `checkAdmissionConflicts` пропускает пересечение, если обе стороны уже в `in_progress` (:661-691), поэтому существующий конфликт остаётся скрытым. `CheckLaunch` и `PlanLaunch` умеют сравнивать все пары (:597-613, :693-727), но автоспавнер их не вызывает. baseline: замер 2026-11-22 показал отсутствие теста на пересечение двух кандидатов в одном проходе автоспавна; в main checkout в этой сессии параллельно правились несколько карточек ATX.
Шаги: Добавить причину отказа для пересечения двух активных карточек. Вызывать попарную проверку всех переданных назначений, включая кандидатов. Дать гейту отдельный метод для проверки всей волны и подключить его к `PlanLaunch`. Сохранить текущие причины отказов для квоты и для пересечения кандидата с активной карточкой. Добавить тесты на два кандидата, на два активных назначения и на смешанный случай.
Проверка: CI зелёный. Тест с двумя пересекающимися кандидатами получает отказ. Тест с двумя активными карточками получает отдельную причину. Тест с непересекающимися карточками проходит.
Приёмка: Ни одна волна не стартует с пересекающимися OwnerFiles, а уже существующее пересечение видно в причине отказа.
