Goal: automation must not immediately redispatch a task cancelled by the operator.
Evidence: StartOne and Dispatch check only ListActive. A closed run with reason cancelled by operator is invisible to the guard, so the next automation tick started the card again. The operator had to close the card through beacon_task_close.
Steps: add a second guard over ListRecent for the same task with state closed, reason cancelled by operator, and UpdatedAt inside a bounded cooldown; return a coded StartRecentlyClosed result with run ID and reason; keep beacon_control retry as the explicit way out; add a test that StartOne refuses and retry succeeds.
Accept: a cancelled card is not started again until an operator retries it.
