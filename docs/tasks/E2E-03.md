The controller currently rewrites a markdown task card only in the orchestrator main worktree. That edit is not part of the worker PR, so after auto-merge somebody must commit the card status by hand. Fix the architecture so the card status travels inside the worker PR before it is merged.

Implement exactly this:

1. Add `MarkInWorkspace(ctx context.Context, id TaskID, workspacePath, status string) error` to `core.TaskSource`.
2. Add `CommitPath(ctx context.Context, ws Workspace, pathspec, message string) error` to `core.WorkspaceManager`.
3. In `internal/infra/tasksource/markdown.go` implement `MarkInWorkspace` by constructing `NewMarkdown(filepath.Join(workspacePath, "docs", "tasks"))` and calling the existing `rewriteStatus`.
4. In GitHub and GitLab task sources implement `MarkInWorkspace` as a no-op returning nil, because those trackers are already updated through API.
5. In `internal/infra/workspace/git_worktree.go` implement `CommitPath`. Use `runInDir` with `status --porcelain -- <pathspec>`. Return nil when there is no diff. Otherwise run `git add -- <pathspec>`, `git commit -m <message> -- <pathspec>` and `git push origin <ws.Branch>`. Only the given pathspec is staged, never agent code.
6. In `Dispatcher.startOne`, right after `Workspace.Create`, call `Source.MarkInWorkspace(ctx, task.ID, ws.Path, "in_progress")`.
7. In `Reconciler.merge`, before `SCM.Merge` and only when `!run.IsFixer`, call `Source.MarkInWorkspace(ctx, run.TaskID, run.WorkspacePath, "done")`, then `Workspace.CommitPath(ctx, ws, "docs/tasks", "beacon: complete task <id>")`, then re-observe the PR with `SCM.Observe` and use the fresh `HeadSHA` for merge and idempotency key.
8. Keep every production file at or below 350 lines. Run `gofmt -w` on changed Go files and targeted `go test` for the changed packages. Do not run full `go test ./...` locally, CI does that.
9. Add or extend tests: markdown `MarkInWorkspace`, worktree `CommitPath` with a real temporary git repo, and the reconciler merge path proving both calls happen before `SCM.Merge`.

Open a pull request against main and call `beacon_watch_pr` with your run ID and PR number. The card status must end as `done` inside the merge commit, so no extra commit on main is needed after merge.
