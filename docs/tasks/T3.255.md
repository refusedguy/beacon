# T3.255. Per-rig delivery drain
Статус: dropped
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.242
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Позволить администрировать очередь доставки рига.
Контекст: В server.ts OpenRig монтирует /api/rigs/:rigId/delivery-drain как отдельный route family.
Шаги: Спроектировать read и control endpoint для drain с аудитом действия.
Проверка: Drain не меняет обязательства, только доставку.
Приёмка: Оператор может stops delivery потока без очень сильных прав.

## Подтверждение
- PR #394 DROPPED: /api/rigs/:rigId/delivery-drain из OpenRig: HTTP-слоя в Beacon нет, доставка управляется beacon_ack/beacon_cancel_watch; конфликт с контрактом ровно 7 инструментов; заглушка deliver.go.
