## Goal
Stop a monitor from refilling the runs cache with bytes from before a reconciler save.

## Evidence
From T-5115e3a5: runsCache is invalidated on PR broadcast before the reconciler saves, so a monitor can refill it with stale bytes. cmd/beacon/http.go is a hot singleton and stays in this card alone.

## Steps
Move invalidation after the save commits, or key the cache to a store-backed revision that advances only on commit. Add tests in the new cmd/beacon/http_runs_invalidate_test.go that a broadcast plus a save yields the saved run state on the next GET.

## Accept
A monitor reading after an event never sees a pre-save snapshot.
