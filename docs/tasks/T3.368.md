# T3.368. Обязательные и игнорируемые проверки в мосте
Статус: dropped
Фаза: P3
Тип: task
Владелец файлов: internal/infra/cibridge/bridge.go, internal/infra/cibridge/bridge_test.go
Зависимости: T3.366
Ссылка: ADR 0117
Агент: нет
Время: нет
Цель: Применить requiredChecks и ignoreChecks перед вычислением вердикта.
Контекст: verdictFromChecks в bridge.go:113-133 сейчас перебирает все проверки. Список build, test, gates, gates-binary живёт только в PR.
Шаги: Передать в Bridge фильтр проверок из конфига. Отсутствие обязательной проверки считать блокирующим. Игнорируемую проверку не учитывать ни при зелёном, ни при красном результате.
Проверка: go test ./internal/infra/cibridge. FAILURE обязательной даёт retry, FAILURE только в ignoreChecks вердикт не меняет.
Приёмка: Поведение без конфига совпадает с текущим. Имена проверок не появляются в коде, логах как команды и в сообщениях агенту.

## Подтверждение
- PR #394 DROPPED: requiredChecks/ignoreChecks из несуществующего JSON-конфига: verdictFromChecks в internal/infra/cibridge/bridge.go считает вердикт из всех проверок, а ADR 0072 запрещает тулзе угадывать причину по имени проверки; список имён в PR не поддерживается по дизайну.
