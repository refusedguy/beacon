Goal: make json-control stable enough that its drift stays under the noise floor at -benchtime=1x.

Evidence: PR #2786 advisory comment, run 45973256317. json-control drifted 5.50%, 22.71%, 4.32%, 10.91%, 15.15% on base passes and 9.17%, 11.32% on head passes, all on unchanged code. The benchmark times one json.Marshal call, about 500 ns, so timer resolution dominates.

Steps:
1. Add `const controlInnerIters = 2000` and a package-level `var controlSink []byte` in internal/bench/control_bench_test.go.
2. Inside the existing `for i := 0; i < b.N; i++` loop, add an inner loop `for j := 0; j < controlInnerIters; j++` that marshals controlFixture into controlSink and calls b.Fatal on error. The sink prevents dead-code elimination.
3. Set `controlWork = controlInnerIters` so the canonical row reports a constant work count. Keep controlErrs at 0.
4. Keep controlKey, controlLimiter, all eight canonical fields, and TestJSONControlCanonicalRow unchanged in shape. The registry cross-check reads only the key and limiter, so no registry edit is needed.

Accept: one benchmark invocation takes roughly 1 to 2 ms at -benchtime=1x in both PR and nightly jobs. Work stays a fixed constant. No ci.yml change and no local execution.
