# T3.181. Адаптер OpenCode для доставки wake
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/opencode.go, internal/infra/wake/opencode_test.go
Зависимости: T3.179
Ссылка: ADR 0070
Агент: нет
Время: нет
Цель: Доставлять wake в живой сессии OpenCode через HTTP API с честным исходом
Контекст: ADR 0070 п2. ADR 0060 п3 и п4 задают адрес из $XDG_STATE_HOME/opencode/service.json, Basic-авторизацию и вызов POST /api/session/:sessionID/prompt с delivery=steer. ADR 0006 оставляет JS-плагин в .opencode/plugins/beacon-bridge.js и не переносит его код в Go-ядро.
Шаги: Реализовать Deliverer, который шлёт POST /api/session/{id}/prompt на адрес из service.json с паролем из того же файла; не хардкодить порт; не передавать agent в теле prompt; передавать в тексте только указатель с полями watchID, obligationID и revision; возвращать steer при подтверждённой доставке в текущий ход, queue при очереди и unsupported, если маршрут недоступен; писать transport-failed при ошибке без повтора; написать unit-тесты на подставном HTTP-транспорте, включая отказ сервера и повтор пары obligationID и attempt
Проверка: go test ./internal/infra/wake
Приёмка: Адаптер реализует интерфейс из T3.179; плагин beacon-bridge.js не меняется; ядро не содержит адресов OpenCode; ошибка транспорта не превращается в posted
