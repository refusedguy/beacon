Goal: an automatic rebase with unresolved paths must abort and never commit conflict markers.

Evidence: GitWorktree.RebaseBase at internal/infra/workspace/git_worktree.go:471-474 treats exit status 0 from `git rebase --autostash` as success. A probe showed the command exits 0 when the stash apply conflicts, leaves UU docs/tasks/T-1.md with conflict markers in frontmatter, and keeps stash@{0}. CommitPath at :515-520 stages and commits those markers with exit 0, and :527 pushes them. abortRebase at :480-490 already exists.

Steps: check `git ls-files --unmerged` immediately after the rebase call in RebaseBase. On a nonempty result call abortRebase and return core.Errorf(core.CodeConflict, ...) naming the unmerged paths. Do not reach CommitPath. Add internal/infra/workspace/git_worktree_conflict_test.go proving that a conflicting autostash returns CodeConflict, leaves no unmerged paths in the index, and writes no markers to the worktree.

Accept: a rebase with unresolved paths aborts, and no conflict marker from a stash apply reaches main.
