# UI-22. Фильтры
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/components/filters.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Сузить список по вердикту, роли, адаптеру, проекту и возрасту.
Контекст: 15 и более агентов дают смешанный список, который нужно быстро разделить.
Шаги: Панель фильтров с сохранением состояния между экранами. Пустой результат показывает заголовок без строк.
Проверка: Тест на комбинации двух фильтров.
Приёмка: Сброс фильтров возвращает полный список одним нажатием.

## Подтверждение
- PR #394 DROPPED: Фильтры по вердикту/роли уже в данных beacon_list_running и в CLI, отдельный UI-компонент отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
