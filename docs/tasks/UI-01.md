# UI-01. Чтение state SQLite только на чтение
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: cmd/beacon-ui/main.go, internal/ui/state/reader.go
Зависимости: 
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: UI видит активные Watch, обязательства и вердикты без изменения state.
Контекст: Beacon хранит состояние в SQLite под XDG_STATE_HOME или BEACON_STATE_DIR. Путь зависит от проекта, если cwd содержит .git.
Шаги: Открыть базу флагом только для чтения. Прочитать таблицы Watch и obligation. Отдавать снимок в UI через канал.
Проверка: reader не открывает базу на запись и не создает файлы. Тест на временной базе.
Приёмка: Снимок содержит watchID, role, PR, headSHA, verdict, revision и adapter.

## Подтверждение
- PR #394 DROPPED: Чтение state SQLite только на чтение уже живёт в mcp.SnapshotReader и также в beacon_list_running/beacon_stats (ADR 0094). Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
