# T3.414. Подпись Standard Webhooks
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/infra/wake/signature.go, internal/infra/wake/signature_test.go
Зависимости: T3.413
Ссылка: ADR 0194
Агент: нет
Время: нет
Цель: Подписывать кольцо и хранить секреты только по именам.
Контекст: webhook-signature = v1, + base64 HMAC-SHA256 от <webhook-id>.<timestamp>.<body>.
Шаги: Генерировать webhook-id на каждое кольцо, читать secret из env или env-файла 0600.
Проверка: Невалидный base64 означает отказ отправки, а не unsigned ring; тест проверяет вектора.
Приёмка: Ни один секрет не попадает в payload или логи.
