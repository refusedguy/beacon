# T3.414. Исключить две параллельные доставки

Premise: проверено 2026-11-21 по origin/main (c687a10). Два процесс-доставщика пишут wake_delivered для одного watchID и revision: мост через bridge.WithWaker в cmd/beacon/mcp.go:1676 и демон через wake.T210Deliver в internal/app/orchestrator/daemon.go:375. Зависимость T3.411 остаётся dropped, её in-memory дедупликация не покрывала доставку моста. Карта не называла поставщика, которого оставить, поэтому выбран общий слой, а не удаление одного пути. Оба поставщика теперь консультируют один журнал wake identity. Приёмка: ровно одна доставка на ревизию.

baseline: `git rev-parse --short origin/main` = c687a10; `rg -n 'WithWaker' cmd/beacon/mcp.go` = 1676; `rg -n 'T210Deliver(ctx, pointer' internal/app/orchestrator/daemon.go` = 375; `rg -n 'WakeDeliveredSource' internal/infra/wake/deliver.go` = 1051; `git show origin/main:docs/tasks/T3.411.md | grep '^Статус:'` = dropped; число новых тестов дедупликации = 3; `gofmt -w` применён к четырём .go; `go test` и `go build` запускает CI.

Цель: Исключить две параллельные доставки.
Контекст: MCP и демон доставляют один и тот же watchID и revision.
Шаги: Ввести общий журнал wake identity по obligation id. Мост оборачивает waker в AdapterDedupDeliverer, демон проверяет тот же журнал в Wake. Повторная доставка гасится, неудачная снимает метку и остаётся доступной для повтора.
Проверка: Eval: ровно одна доставка на ревизию.
Приёмка: В логе одно wake_delivered на обязательство.

## Подтверждение

- 2026-11-21. Реализован общий слой дедупликации в internal/infra/wake/deliver.go: DeliveryDedup хранит obligation id под mutex, SharedDeliveryDedup даёт общий экземпляр процесса, AdapterDedupDeliverer гасит повтор до вызова внутреннего deliverer. cmd/beacon/mcp.go:1676 оборачивает waker моста этим слоем. internal/app/orchestrator/daemon.go проверяет Seen в Wake и записывает Claim после успешной доставки. Неудачная доставка снимает метку через Release. Три теста в internal/infra/wake/deliver_test.go покрывают оба порядка поставщиков, повтор того же обязательства, новую ревизию и повтор после ошибки. PR https://github.com/refusedguy/beacon/pull/1129. Блокеров и дублей нет, чужие файлы, wiring и .beacon не тронуты.
