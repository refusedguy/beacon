# UI-18. Управление арендой worktree
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/ui/actions/lease.go
Зависимости: UI-03, UI-12
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Продлить или принудительно освободить аренду.
Контекст: Есть инструменты extend_holder_lease и release_worktree.
Шаги: Вызов продления и освобождения с подтверждением для принудительного варианта.
Проверка: Тест на продление уже просроченной аренды.
Приёмка: Результат действия виден на экране аренд без перезапуска.

## Подтверждение
- PR #394 DROPPED: Продление и освобождение аренды уже командами/портами Orchestrator и store; отдельный UI-экран отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
