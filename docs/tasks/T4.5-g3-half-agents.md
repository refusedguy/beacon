# T4.5. G3: пятьдесят процентов агентов на вердиктном цикле

Статус: todo
Фаза: P4
Тип: task
Владелец файлов: docs/gates/G3-half.md
Зависимости: T4.4, T4.7
Ссылка: ADR 0018
Агент: нет
Время: нет

Цель: Перевести половину агентов на цикл ожидания вердикта и подтвердить, что лестница и эскалации работают без неразобранных инцидентов.

Контекст: ADR 0018 задаёт G3: пятьдесят процентов агентов, выход без инцидентов лестницы. BEACON-AUDIT уточняет критерий: неделя активности без инцидентов лестницы и эскалаций или все эскалации разобраны (§11). ADR 0017 требует метрик по доставкам, подтверждениям, прочтениям, повторам и эскалациям отдельно, значит инцидент проверяется по `beacon_stats` и `ESCALATIONS.md`. ADR 0019 добавляет orphan-эскалацию как отдельный случай, который тоже должен быть разобран. ADR 0018 запрещает проходить гейт без решения владельца и требует измерять SLO до перехода.

Шаги:
1. Перевести половину агентов на цикл T3.7 и T3.8, оставив остальных на `gh --watch`.
2. Ежедневно собирать список инцидентов лестницы и эскалаций из `beacon_stats` и `ESCALATIONS.md`.
3. Разобрать каждый инцидент вместе с владельцем и записать решение.
4. Записать в `docs/gates/G3-half.md` долю агентов, список инцидентов, статус каждого и решение владельца.

Проверка: В отчёте нет неразобранных эскалаций. Число строк в `ESCALATIONS.md` совпадает со `stats.escalated`. SLO из T4.2 остаются в норме на половине агентов.

Приёмка: 50 процентов агентов работают по вердиктному циклу. Инцидентов лестницы нет или все разобраны. SLO в норме. Переход на G4 подтверждён владельцем.

Гейт: G3. Учебный откат T4.7 должен быть выполнен до расширения доли.
