# T3.370. Политика мержа из конфига при регистрации Watch
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/mcp/server.go, internal/infra/mcp/server_test.go
Зависимости: T3.366, T3.367
Ссылка: ADR 0117
Агент: нет
Время: нет
Цель: Записать MergePolicy и Policy из снимка конфига в новый Watch.
Контекст: ADR 0072 задаёт requireApproval, waitFor и waitForMain как условия Watch. Хеш снимка фиксирует политику на момент регистрации.
Шаги: В beacon_watch_pr получать загруженный конфиг проекта, копировать MergePolicy и Policy в Watch, сохранять хеш снимка. Не перечитывать файл при последующих опросах.
Проверка: go test ./internal/infra/mcp. Два Watch одного проекта получают один хеш политики.
Приёмка: Правка конфига в worktree после регистрации не меняет решение. Регистрация без конфига сохраняет DefaultMergePolicy.
