## Goal
Keep a refusal's action, id and reason intact as the MCP server hands it to the caller.

## Evidence
From T-7c7f30f9: postControlJSON preserves the daemon's structured 409 reason, but the server result must not flatten or drop action, id and reason on the way out. Tests must not depend on internal/infra/mcp/server_test.go, which is a hot singleton owned by an active run.

## Steps
Map server-level control errors into a result carrying action, id and reason. Keep the structured 409 path from regressing to a bare status code. Add tests in the new internal/infra/mcp/server_reason_test.go.

## Accept
A refusal crossing the server boundary still carries the producer's reason and action.
