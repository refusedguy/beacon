Цель: Будить сессию через POST /api/session/{id}/prompt с delivery steer.
Контекст: Путь описан в спецификации и не требует плагина. Доказательная база есть в tmp/p0-wake/Results.md. Prompt-хук может один раз заменить steer на queue при admission.
Шаги: Вызвать POST /api/session/{id}/prompt. Подтверждать через session.inbox.delivered и session.execution.started в GET /api/event.
Проверка: resume:false даёт только session.inbox.enqueued, без delivered и без execution.started.
Приёмка: При steer есть execution.started, при queue и resume:false его нет.
