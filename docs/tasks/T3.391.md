# T3.391. Цикл Run на едином решении Decide
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/app/orchestrator/orchestrator.go, internal/app/orchestrator/orchestrator_test.go
Зависимости: T3.390
Ссылка: docs/adrs/0158-blocked-and-dependencies.md
Агент: executor
Время: нет
Цель: Заменить разрозненные ветвления в Run на Dispatch по исходам Decide без изменения контракта Store, Merger и Waker.
Контекст: Сейчас Run сам проверяет isReady, autoMergeAllowed и needsWake. Decide уже фиксирует приоритет blocked, зависимостей и готовности, но цикл его не вызывает.
Шаги: Построить CIState и DependencyResolver на границе цикла, вызвать Decide для каждого Watch и развести пять исходов: MERGE идёт в существующий mergeOne с журналом по (watchID, revision), BLOCKED_FIX_AGENT и RETRY_EXECUTOR идут в wake с тем же ключом, WAIT_DEPENDENCY удерживает Watch без записи в журнал, NOTIFY_ORCHESTRATOR попадает в отчёт. Сохранить dry-run и сбор ошибок по Watch.
Проверка: go test ./internal/app/orchestrator/... в CI. Негативный контроль: blocked Watch с verdict=ready не вызывает Merger, а Watch с unsatisfied ref не меняет журнал.
Приёмка: MERGE выполняется не более одного раза на пару (watchID, revision). BLOCKED_FIX_AGENT и RETRY_EXECUTOR не мержат. WAIT_DEPENDENCY и NOTIFY_ORCHESTRATOR оставляют Watch активным.
