# T3.248. Broadcast по адресам
Статус: todo
Premise: проверено 2026-11-21, функционал в origin/main отсутствует, дубль не создан. Карточка описывает competitor-фичу OpenRig: broadcast по адресам pod, rig, global и список с резолвером адресов и частичными ошибками с указанием отказавшего адреса. В `internal/infra/wake/deliver.go` origin/main нет типа адреса, парсера или резолвера: `git grep -n 'resolveSessions' origin/main` находит только саму карточку T3.248.md. `SubscriberTarget` принимает лишь точный `ses_...` подписчика Watch с ролью executor, orchestrator или fixer и прямо запрещает подмену сессии ролью или широкой рассылкой; `ValidateT210Target` и `T210Deliver` проводят ту же проверку и пропускают указатель, если адаптер связал другую сессию. Терминов pod, rig, member@, seat, global в deliver.go ноль, единственное упоминание broadcast это comment о запрете role-wide broadcast. Зависимость T3.241 (стабильный адрес роли) сама остаётся todo: модели seat и типа адреса в main нет, владелец обязательства это `ObligationKey(watchID, revision, subscriberID)`, привязанный к сессии, а не к адресу, и смена сессии меняет владельца. ADR 0084, на который ссылается карточка, в main описывает lease на obligation с release и fail, а не broadcast по адресам; ADR с форматом адресации pod/rig/global/list в main отсутствует. diff HEAD..origin/main по OwnerFiles даёт 296 строк, но все они из T3.242-T3.245 `DeliveryLeaseGuard` (per-target lease), а не из адресного резолвера. Реализация в OwnerFiles потребовала бы доменных изменений вне OwnerFiles (тип адреса, модель seat, резолвер, результат с частичными ошибками) и отмены запрета на role-wide broadcast, зафиксированного в SubscriberTarget. Без ADR с форматом адресов написанный код был бы спекулятивным, повторил бы снятый PR #394 и нарушил бы честность ADR 0026; живой зонд OpenRig в Beacon недоступен, на слабом ПК доступны только текст и gofmt. OwnerFiles не менял, код не писал, gofmt не применял, дубль не создал, правка только текстовая. Статус todo сохранён, карточка остаётся неподтверждённым спайком до появления модели адресов в Beacon и ADR с форматом адресации, блокер возвращён оркестратору.
baseline: `git grep -n 'resolveSessions' origin/main` находит только `docs/tasks/T3.248.md:11`; `git show origin/main:internal/infra/wake/deliver.go | grep -icE 'pod|rig|member@|seat|global'` = 0; `grep -ic 'broadcast'` = 1 (comment про запрет); `git log origin/main --grep='T3\.248' --oneline | wc -l` = 0; `gh pr list --repo refusedguy/beacon --state all --search T3.248` = 0; `git diff --stat HEAD..origin/main -- internal/infra/wake/deliver.go internal/infra/wake/deliver_test.go` = 296 insertions, все из T3.242-T3.245 DeliveryLeaseGuard.
