Goal: Stop five matrix legs from racing to write one immutable cache key.

Evidence: ciopt-03. All five legs share one setup-go key; GitHub keeps only the first save, so four legs discard their compiled artifacts.

Steps: Add a per-leg key suffix such as the module name while keeping the common dependency hash.

Check: On a second run each leg restores a cache it wrote itself.

Accept: Extra storage against the repo cache limit is acceptable.
