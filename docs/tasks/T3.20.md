# T3.20. Совместимость с тремя диалектами MCP Tasks

Тип: task
Владелец файлов: internal/infra/mcp/server.go, internal/infra/mcp/server_test.go, internal/infra/mcp/schema.go, internal/infra/mcp/schema_test.go, internal/infra/mcp/tool_get_result.go, internal/infra/mcp/tool_get_result_test.go
Зависимости: T3.19
Ссылка: ADR 0031
Агент: нет
Время: 2026-11-20T01:30:00Z
Цель: Определять диалект клиента: настоящая задача для ревизии 2025-11-25, resultType task после --after для 2026-07-28, обычный job id с инструментами результата, статуса и отмены для клиента без Tasks.
Контекст: ADR 0031, раздел 2; отчёт Q 1.1 (mcp-coatcheck). Переговоры о диалекте живут на границе MCP, ядро не знает версии протокола. Владельцы meta.go переданы T3.19, отсюда зависимость.
Шаги: Детектор диалекта на границе MCP; выбор формы ответа; схема resultType; форма ответа get_result для двух диалектов.
Проверка: Контрактные тесты на три диалекта; --after переключает форму ответа; ядро не содержит ветвлений по версии протокола.
Приёмка: Клиент каждого диалекта получает совместимый ответ, версии протокола не просачиваются в ядро.
