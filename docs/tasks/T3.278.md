# T3.278. ACP exec connector
Premise: перепроверено 2026-11-21 по свежему origin/main @ c716b61, включая ACP адаптер. Функционал отсутствует, дубль не создан. В `internal/infra/wake/acp.go` нет постоянной записи о run, машины состояний requested, started, finished, interrupted и повторного чтения результата после рестарта. Файл содержит клиентскую часть ACP: `ACPAdapter`, `ACPStdioTransport`, `ACPHTTPTransport` и `PersistentACPClient` с методами Start, Initialize, Capabilities, DeliveryPlan, DeliverWake, NewSession, LoadSession, Prompt, Cancel, Updates, Done и Close. Поле `c.started` описывает состояние клиента, а не run. `ResolveACPRuntimeCommand` и `DeliverWake` работают с живым ACP-раннером и не сохраняют результат на диске. `beacon spawn --runtime acp` в `cmd/beacon/spawn.go:348` держит раннер через `defer func() { _ = rt.Close() }()` в строке 360 и ждёт в `streamACPSession` до `ctx.Done()`, поэтому закрытие терминала обрывает run. `recordSpawnSession` в строке 94 пишет сессию через `reg.Start(id, active, metadata)`, но не ищет прежний run по строке задачи и не читает результат после рестарта. `internal/infra/store/sessions.go` хранит статусы active, idle, closed, а не состояния из карточки. `SessionRegistry.Resume` в `internal/app/session/registry.go:82` ищет по sessionID, а не по строке задачи. ADR 0086 предписывает хранить состояние рядом с beacon.db в каталоге проекта и не задаёт `$OPENRIG_HOME/acp/runs`; каталог `$OPENRIG_HOME` Beacon отклонил в PR #394 по карточке T3.297. Проверка «повторный run той же строки возвращает существующий» в main не проходит, потому что `runSpawnACP` создаёт новую сессию при каждом вызове. Постоянная запись о run и её подключение к команде живут в `cmd/beacon/spawn.go`, `internal/app/session` и `internal/infra/store`, то есть вне OwnerFiles карточки. Подтверждение требует живого ACP-раннера, закрытия терминала, рестарта и go test; здесь доступны только gofmt и текст. Код не писал, OwnerFiles не менял. Блокер возвращён оркестратору: нужна модель run с состояниями и живой зонд, либо расширение OwnerFiles и разрешение на тесты.
