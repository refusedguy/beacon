# UI-32. SSH-транспорт на wish
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: cmd/beacon-ui/ssh.go
Зависимости: UI-07
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Открыть тот же менеджер по SSH без OpenSSH на сервере.
Контекст: wish middleware создает tea.Program на сессию и передает размер окна, требует PTY и activeterm.
Шаги: Поднять wish-сервер с bubbletea middleware и activeterm. Передать текущую модель в handler.
Проверка: Тест подключения с PTY и без него.
Приёмка: Нет дублирования кода экранов между локальным и SSH-режимом.

## Подтверждение
- PR #394 DROPPED: SSH-транспорт на wish требует отдельного beacon-ui и внешних модулей вне ядра, прямо отклонено ADR 0060; cmd/beacon-ui/ssh.go отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
