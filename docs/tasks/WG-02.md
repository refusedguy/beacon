Функция возвращает ID живого Watch и причину защищённого worktree. Проверки идут по порядку: точное совпадение HEAD, ветка Watch из PR, путь из реестра привязок, затем родство HEAD через git merge-base. Родство закрывает случай локального коммита: записанный в Watch SHA является предком текущего HEAD, а точное совпадение уже не работает. Результат детерминирован сортировкой якорей по ID. Пустой список Watch и короткий SHA не вызывают git. Добавить табличный тест на три обязательных случая: HEAD совпадает, HEAD ушёл вперёд, Watch отсутствует. Дополнительно покрыть совпадение по ветке, по реестру привязок и чужую историю без общего предка. Не трогать cmd/beacon/gc.go и internal/infra/worktree/gc.go.

Приёмка: Локальный коммит и смена HEAD PR не превращают worktree в кандидата на удаление, пока жив связанный Watch. Чистый worktree без Watch остаётся кандидатом.
