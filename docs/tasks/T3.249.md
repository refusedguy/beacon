# T3.249. Transcript rotation
Premise: pane-слой добавлен в PR #1135. До правки в main не было tmux и capture-pane, а доставка wake шла только через PromptFunc, CLI и ACP. Патч добавляет tmux `Runner`, порт `CommandRunner` в wake, `CapturePane` через `capture-pane -p` и двухшаговую вставку `PasteTwoStep` с отдельным `SubmitOnly`. Тесты работают на фейковом runner, живой tmux не нужен. Ротация по 24 pane, atomic temp plus rename и замер потока 1000 строк за 2 с остаются отдельной работой. Этот PR закрывает pane-слой и двухшаговую вставку.

baseline: до правки `git grep -n -i -E 'pipe-pane|capture-pane' origin/main` давал совпадения только в docs/tasks/T3.246.md и docs/tasks/T3.249.md, в '*.go' ноль; `git grep -li tmux origin/main -- '*.go'` = 0 файлов; `git cat-file -e origin/main:internal/infra/tmux/pane.go` и `.../wake/capture.go` давали ABSENT. Теперь оба файла существуют и покрыты тестом `internal/infra/wake/capture_test.go`.
