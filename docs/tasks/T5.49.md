# T5.49. Heartbeat и stale в wake
Premise: задача закрыта реализацией в PR #1112. Раньше в origin/main была только половина работы: PR #353 (T5.30) добавил cmd/beacon/registry_sync.go с classifyStale, reconcileStale, syncRegistry и registryWakeAllowed, но функция оставалась без вызовов вне теста, а internal/infra/mcp/tool_wake.go не читал статус registry. Блокер был в границе пакетов: нужен был порт статуса в tool_wake.go и вызов guard в обработчике wake, расширение OwnerFiles и живой зонд с receipt. PR #1112 снимает все три пункта: добавляет узкий порт RegistryWakeGuard, подключает его к wake-обработчику и ватку в cmd/beacon/mcp.go, пишет отказ в receipt и покрывает поведение тестом. Дубля нет: до #1112 реализационного PR с кодом wake не было.
