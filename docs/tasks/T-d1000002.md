# T-d1000002. Nightly gate: live per-key thresholds and poisoned-baseline self-heal

## Goal
Make the nightly gate test the registry thresholds it claims to enforce and stop one spike from wedging future nights.

## Evidence
The gate only processes metrics named sec/op or ending in -median-sec, while every emitter uses -median-ns, so all 24 per-key 15 percent thresholds are dead and only aggregate sec/op of two benchmarks is gated. The 2 percent floor only suppresses output; the real limits are hardcoded 15 and 20. Recorded baseline medians vary 1.62 to 3.17 seconds on the perf runner, so 15 percent sits inside machine spread, and the advisory already rejected a single fixed floor. Poisoned-baseline handling fails the compare and skips publish, so the next night downloads the same poisoned artifact forever. The script route is chosen, so the emitter files need no rename.

## Steps
1. Teach the script to read -median-ns and convert to seconds so every per-key registry threshold applies, not only aggregate sec/op.
2. Move the hardcoded 15 and 20 limits out of the script into docs/perf/bench-registry.json as aggregate sec/op keys; keep the 2 percent value as a noise floor rather than the real limit.
3. Enforce work and error equality against canonical rows in the gate.
4. Replace or supplement the fixed limits with a calibrated floor and a spread rule driven by the nightly control row. The 1.62 to 3.17 second spread puts 15 percent inside machine noise and a single fixed floor was already rejected.
5. Break the wedge: on a poisoned baseline keep the last known good baseline and mark the night inconclusive instead of failing the compare and skipping publish, so the next night self-heals rather than re-downloading the poisoned artifact.
6. Work in your own worktree off current main. Never push to main. Never run go test, go build, go vet, linters or benchmarks locally. Call beacon_watch_pr. CI supplies every check.

## Accept
A 5 percent per-key regression fails the gate, a poisoned baseline self-heals on the next night, and every threshold in the registry is live.
