## Premise, проверенная 2026-11-21

Исходная premise верна только отчасти. Карточки с live probe и чужими OwnerFiles остались, но главная причина устаревшего todo другая. Двенадцать карточек уже имеют влитый PR с кодом, а статус до сих пор todo. Проверка прошла по свежему origin/main в режиме read-only. Код, PR и статусы сверены, чужие карточки в этом PR не менялись. Карточки WIRING обязаны оставаться todo по правилу гейта, поэтому их нельзя отправлять в card_closures.

## Рекомендация

Применить card_closures для двенадцати карточек из таблицы с указанными номерами PR. Статус done поставит Beacon при вердикте merged, вручную карточки не трогать. После закрытия число todo карточек относительно этого baseline упадёт на двенадцать.

Не добавлять в closures карточки WIRING. Гейт проверяет их статус и отвергнет done. Двенадцать таких карточек остаются todo по контракту.

Оставить в todo четыре карточки с частичной реализацией. IDX-13 не считает чтение через os.ReadFile в LoadCards. T3.284 ждёт учётных данных внешнего приложения. T3.440 не имеет поля blocked в StatsOutput и теста ответа. T5.61 не пишет config_id и не подключает registry sync. У остальных todo карточек сохраняются прежние владельцы и названные причины, в том числе живые probe-блокеры серий T3 и T5.
