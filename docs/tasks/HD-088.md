Premise: проверено 2026-11-21 по origin/main (be6cdc8), дубль. Карточка просит назначить владельца каждому числу в документах и создавать docs/FACTS.md со ссылками на файл-владелец. В cmd/batch-apply/main.go появился флаг --facts, который печатает индекс без записи и передаёт значение в batchapply.Options. В internal/infra/batchapply/apply.go появились тип fact с полями Value и Source, функция declaredFactProblems для чисел без источника, функция collectFacts для пары число и путь артефакта и функция renderFacts для таблицы «Число | Владелец». Число без источника печатает строку «число без владельца» и возвращает код 1 до записи файлов, поэтому приёмка «число без владельца проваливает карточку» выполнена.
