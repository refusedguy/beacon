# CC-05. Revision fence при возобновлении сессии
Статус: todo
Фаза: P1
Тип: task

Зависимости: нет

Агент: нет

Цель: Не открывать сессию, если её состояние изменилось между выбором id и подключением.
Контекст: Источник: docs/research/comp-codex.md, раздел CC-05. Codex снимает подпись rollout до и после чтения и сбрасывает revision при расхождении (`codex-rs/thread-store/src/local/history_revision.rs:9-30`, `codex-rs/thread-store/src/local/model_context.rs:59-94`). Beacon при рестарте читает `git status` и ключ `beacon/survival-rules` (`AGENTS.md:103-111`). `attach --resume` берёт сохранённый sessionID из реестра и сразу открывает его (`cmd/beacon/attach.go:225-261`). Baseline: 0 проверок состояния между `savedAttachSession` и вызовом `opencode` в `runAttach`.
Шаги: Определить подпись сессии в реестре. Снимать её до и после чтения записи. При расхождении не открывать сессию, а вернуть ошибку с указанием перечитать список. Добавить тест на изменение записи между двумя чтениями.
Проверка: CI зелёный. Тест показывает 1 отказ и 0 открытых сессий при записи, изменённой между чтениями, и 1 успешное подключение при неизменной записи.
Приёмка: Изменения только в OwnerFiles карточки. Формат `attach --resume` и имена флагов не менять.
