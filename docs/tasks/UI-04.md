# UI-04. Подписка на изменения или опрос
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/transport/events.go
Зависимости: UI-01, UI-03
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Экран обновляется при смене вердикта без ручного перезапуска.
Контекст: openrig подписывается на /api/activity/events. Если подписки нет, Beacon может опрашивать state раз в секунду.
Шаги: Реализовать интерфейс источника событий. Сделать две реализации: подписку и опрос. Отправлять сообщение в event loop Bubble Tea.
Проверка: Подставной источник меняет вердикт, экран показывает новое значение в течение одного интервала.
Приёмка: Опрос работает только пока TUI в фокусе.

## Подтверждение
- PR #394 DROPPED: Живое обновление идёт по курсору WatchEvent в beacon_list_running (ADR 0025) и SSE /api/event в beacon watch --live (ADR 0060 п2), отдельный event loop TUI не создаётся. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
