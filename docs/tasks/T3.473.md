# T3.473. Режим inbox-only для_EXECUTOR'а
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/infra/guard/inbox.go
Зависимости: T3.416
Ссылка: ADR 0202
Агент: нет
Время: нет
Цель: Позволить полностью отказаться от ввода в pane.
Контекст: issue #48 просит inbox-only: никакой вставки и Enter для асинхронных сообщений; durable записи остаются доступны.
Шаги: Per-executor delivery mode; все producers проходят через guard; режим не наследуется lifecycle-записями.
Проверка: Для inbox-only нет вызовов pane-write; другой executor получает обычную доставку.
Приёмка: Политика не обходится новым producer'ом.
