# UI-17. Claim и release обязательства
Статус: dropped
Фаза: P2
Тип: task
Владелец файлов: internal/ui/actions/claim.go
Зависимости: UI-03, UI-08
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Оператор может взять и отпустить обязательство из UI.
Контекст: beacon_claim и beacon_release меняют намерение и не дают verdict.
Шаги: Кнопки claim и release с передачей watchID и obligationID.
Проверка: Тест на уже заявленном обязательстве.
Приёмка: UI показывает claimedAt после успешного claim.

## Подтверждение
- PR #394 DROPPED: claim/release уже в leak-портах MCP (beacon_claim/beacon_release в реестре инструментов) и меняют намерение без вердикта; UI-дубль не нужен. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
