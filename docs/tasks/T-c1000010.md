## Goal
Report dispatch skips, failures and next actions in the tool result without inventing reasons.

## Evidence
From T-7c7f30f9: beacon_dispatch returns cap_full with no skip when all slots are busy, and failures and skips carry no next action. From T-a697580c: tool_dispatch.go invents reason running from state when the run has none.

## Steps
Format the dispatcher's cap_full skip with requested n, active count and a next action. Add a next field to every dispatch outcome. Leave reason empty when the run has none. Add tests in internal/infra/mcp/tool_dispatch_test.go for a skip, a failure and a reason-less run.

## Accept
A dispatch result never claims a reason the run did not give, and every non-success outcome tells the caller what to do next.
