Goal: Fewer allocations on the render and event hot paths.

Evidence: final-15. truncate converts TaskID and Reason to []rune each frame, the header builds a padding string per frame, each row uses fmt.Sprintf plus two concatenations, and applyEvent copies the whole runs slice.

Steps: Add an ASCII fast path to truncate, use cached padding, write rows into a reusable buffer and replace the slice copy with a pending update.

Check: A five-run alternating benchmark shows lower allocs with identical output and work counts.

Accept: Rendered text stays byte-identical.
