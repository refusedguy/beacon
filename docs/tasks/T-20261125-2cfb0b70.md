Goal: Do not log a missing PR as an idle lookup failure.

Evidence: internal/infra/scm/github_base.go:40-43 and gitlab_mr.go:264-267 return CodeNotFound for no open PR. internal/app/idle.go:27 logs every bindOpenPR error.

Scope: internal/app/idle.go, internal/infra/scm/github_base.go, internal/infra/scm/gitlab_mr.go.

Steps: Treat CodeNotFound as (false,nil) in bindOpenPR and keep real transport errors visible. Add a test with no PR.

Accept: The expected no-PR state is silent while outages surface.

Open a PR, call beacon_watch_pr, do not self-merge.
