Goal: make epics and dependencies readable and navigable in the Beacon sidebar and card panel. No Go or docs edits.

Evidence from live screenshots on main f080ab43:
- The Queue shows repeated lines such as "blocked by T-20261124-68b0c24a ... P9". ui_alerts.js:62-76 renders one line per card with an ellipsized title and the full blocked-by text in the same row. The operator cannot see the title, the kind, or the dependency chain.
- An epic created with kind epic looks like an ordinary card. The card panel shows ID, Title, Priority, Status, Depends, Path and the body, but no kind, no children, no back button, and no way to jump to a dependency. ui.js:166 showCard simply replaces currentCard and opens the panel.
- The card itself now scrolls and has ctrl+g and ✕, so keep those controls.

Steps:
1. Give queue items two lines: the card title first, then a muted status line with a compact state, priority and dependency count. Replace full blocked-by ID strings with a short form. Show kind epic with a clear marker and indent children under their parent epic when both are in the queue.
2. Make dependency IDs in both the queue and card panel clickable. Clicking a dependency opens that card in the same panel and pushes the current card onto a history stack.
3. Add a back control and a keyboard shortcut for going back. Keep ctrl+g and ✕ working. Pressing back with an empty history returns to the run detail or closes the panel.
4. Show kind and children in the card model. For an epic, list child IDs with their titles and status when available. For a child, show the parent epic and make it clickable.
5. Tests: blocked queue item keeps its title visible and shortens the dependency text; epic and child rows are distinguishable; clicking a dependency opens the target card; back returns to the previous card; ctrl+g and ✕ still work; existing queue and slot-rebuild tests pass.
6. Run node --check on every plugin JS file and node --test .opencode/plugins/beacon-project/*_test.js. Every JS file stays at or under 350 lines.
7. Open a PR against main and call beacon_watch_pr with the real run ID and PR number. Do not self-merge.

Accept: only .opencode/plugins/beacon-project/**. No Go changes, no docs, no task card edits.
