# T3.441. Разделить метрики wake по инициатору
Premise: метрика wake_delivered_total различает путь доставки. До правки счётчик хранил только метку adapter, а source оставался полем журнала. Реализация использует один счётчик и не добавляет второй экспортер.
baseline: `git rev-parse --short origin/main` = c21bb3d; до правки `counterLabels` в `internal/infra/observe/metrics.go` связывал wake_delivered_total с единственной меткой LabelAdapter, а `Metrics.Inc` принимал одно значение метки.

## Подтверждение
- 2026-11-21. Реализация в PR [#1123](https://github.com/refusedguy/beacon/pull/1123). `wake_delivered_total` exports метки adapter и source через `IncSource`. `Inc` сохраняет прежний ряд только с adapter. `WakeDeliveredSource` передаёт source через дополнительный интерфейс Sink, поэтому старые Sink продолжают работать. Тесты проверяют JSON, Prometheus, круговой проход снапшота и запись через Recorder. gofmt применён, go test и go build оставлены CI.
