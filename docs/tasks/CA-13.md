# CA-13. Сообщение коммита из diff с цепочкой моделей
Статус: todo
Фаза: P2
Тип: task
Владелец файлов: internal/app/prcreate/cards.go, internal/app/prcreate/service.go
Зависимости: 
Ссылка: docs/research/comp-aider.md
Агент: нет
Время: нет
Цель: Генерировать заголовок и тело PR из diff с переходом к другой модели при переполнении окна.
Контекст: Источник: docs/research/comp-aider.md, дополнение к CA-04. aider строит сообщение коммита из diff и контекста, считает токены и пропускает модель, если запрос не влезает в её окно, затем берёт первый успешный ответ из списка моделей (`aider/repo.py:326-373`). В beacon заголовок PR это первый заголовок карточки, тело остальные её строки (`internal/app/prcreate/cards.go:18-21`), а сервис лишь подставляет карточку при неполных флагах (`internal/app/prcreate/service.go:46-55`). Diff в генерации текста не участвует, цепочки моделей нет. Baseline: описание PR не отражает фактические изменения, если карточка устарела.
Шаги: Добавить источник diff в `prcreate` с подсчётом токенов до вызова модели. При превышении окна переходить к следующей модели из списка. Сохранить текущий источник карточки как fallback. Не менять форму создаваемого PR при пустом diff.
Проверка: Взять 10 PR: пять с малым diff и пять с diff на 100 KB. Требовать, что для малых заголовок содержит символ из diff в 5 из 5 случаев, для больших ни одна модель не получила запрос сверх своего окна и ни один PR не остался без текста. Baseline 0 из 5 по первому признаку.
Приёмка: Заголовок PR отражает diff в не менее 5 из 5 малых случаев, большие diff не вызывают переполнение окна.
