# UI-02. Проверка версии схемы state
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/state/reader.go
Зависимости: UI-01
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: UI не показывает неверные данные после смены схемы.
Контекст: Ручное чтение чужой схемы молча дает пустой экран и ложные вердикты.
Шаги: Читать версию схемы при старте и после переподключения. При несовместимости печатать понятную ошибку и не запускать TUI.
Проверка: Тест с подмененной версией схемы возвращает ошибку до первого рендера.
Приёмка: Сообщение называет ожидаемую и найденную версию.

## Подтверждение
- PR #394 DROPPED: Проверка версии схемы уже есть в миграциях store и в снимке StatsOutput.Version; отдельный UI reader отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
