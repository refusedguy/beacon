# UI-02. Проверка версии схемы state
Статус: todo
Фаза: P1
Тип: task
Владелец файлов: internal/ui/state/reader.go
Зависимости: UI-01
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: UI не показывает неверные данные после смены схемы.
Контекст: Ручное чтение чужой схемы молча дает пустой экран и ложные вердикты.
Шаги: Читать версию схемы при старте и после переподключения. При несовместимости печатать понятную ошибку и не запускать TUI.
Проверка: Тест с подмененной версией схемы возвращает ошибку до первого рендера.
Приёмка: Сообщение называет ожидаемую и найденную версию.
