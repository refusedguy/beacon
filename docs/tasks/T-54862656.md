Goal: An empty queue must not render both 'No tasks ready' and an expandable Queue 0 row.

Evidence: sidebarModel pushes a 'No tasks ready' item and still emits the Queue section with count 0. The operator sees the same fact twice.

Steps: When ready is empty, omit the separate row and render a single non-expandable Queue header whose status is 'no tasks ready'. Keep the normal expandable Queue section when ready is non-empty.

Check: A snapshot with zero ready tasks produces one queue-related line. A snapshot with ready tasks still shows the expandable section with the correct count. Plugin UI tests pass.

Accept: No wire shape change and no new TUI peer packages.

Open a PR, call beacon_watch_pr, do not self-merge.
