Goal: highest priority. Stop false FIX states and frozen queues caused by cancelled duplicate check-runs, sticky Reason, stale observation and destructive task sync. Five read-only analyses produced exact file and line evidence; this card consolidates them into one fix with tests.

Evidence: PR #2842 head d2693118 had 16 success, 7 skipped and 9 cancelled check-runs. GitHub lists newest first, so a success vet is index 1 and a cancelled vet is index 20. internal/infra/scm/github.go:248-263 maps cancelled to CheckFailure, pkg/core/verdict.go:139-147 returns the first failure, and :313-318 emits 'required check failed: vet' before the policy rule that would pass. internal/app/reconcile_observation.go:97-122 greenButBehind returns without stamping observation; internal/app/reconciler.go:265 EvAgentFixed carries no HeadSHA, so wire head_stays empty; internal/app/control.go:174-211 watchPR rejects needs_agent_fix; pkg/core/run.go:389-391 never clears Reason, so the TUI prints the old failure. Duplicate runs come from pull_request.types opened/synchronize/reopened/labeled at ci.yml:11 plus user-token labels at PR creation; GITHUB_TOKEN label writes from mark-ready do not trigger runs. daemon lock at cmd/beacon/lock.go:93-106 has no owner identity, and cmd/beacon/mcp.go:39-41 continues tool-only after lock contention without a reconciler.

Steps with required tests, grouped by file:
1. internal/infra/scm/github.go:221-263 group check-runs by Name, keep newest by CompletedAt, map cancelled and timed_out to CheckSkipped, return one result per name. Mirror the GitLab mapping at internal/infra/scm/gitlab_checks.go:116-117.
2. pkg/core/verdict.go:139-147 and :313-318 restrict the failure invariant to required checks; :161-190 AllRequiredPass picks one result per name. internal/infra/policy/configurable.go:108-137 and :161-190 apply the same one-result rule.
3. .github/workflows/ci.yml:11 remove labeled from pull_request.types, or gate verify, test-modules, build, vet, lint, test and plugin-tui-smoke on github.event.action != 'labeled'. Keep mark-ready and perf-pr-advisory on labeled. Note that labels attached at creation still emit labeled events, so the trigger or job gate is what removes the duplicate.
4. internal/app/reconcile_observation.go:97-122 and :163-179 stamp head and base before the no-op greenButBehind return using handlePending's ObserveSHA pattern; clear run.Reason on success and pending transitions; do not write 'base green' as a stale label. internal/app/reconciler.go:120-133 clear run.Reason on a healthy observation before the existing save; :265 pass HeadSHA in EvAgentFixed.
5. internal/app/control.go:174-211 let watchPR mark external from needs_agent_fix using MarkExternal, which accepts any non-terminal state, then signal reconciliation. pkg/core/run.go ClearReason method if needed; do not change Run.Apply globally because empty event reason means keep existing reason.
6. cmd/beacon/lock.go and cmd/beacon/mcp.go add owner PID and heartbeat staleness rule from daemon.json, treat a stale holder as free, make failed ownership handoff fatal for the daemon role, and log clean reconciler exits.
7. internal/app/dispatcher.go and internal/infra/sqlite/tasks.go make SyncTasks merge rather than delete rows so a Beacon done status survives a stale working tree; treat a terminal run or closed PR as an authoritative guard in candidate selection.
8. internal/infra/tasksource/cardindex.go detect file removal independent of directory mtime and drop missing entries; TaskDeleter gets a Source so deletion and graph sync happen together.
9. internal/infra/sqlite/store.go and internal/app/status.go make ListQueueTasks resolve dangling dependency edges the same way readyTasksQuery does, so the monitor stops showing waiting_deps for a card that is done but absent from tasks.

Accept: a cancelled check-run cannot block a merge, PR #2842 and #2843 stop showing FIX with green checks, needs_rebase does not repeat with a fixed head, a closed PR closes its run and card, and a stale or deleted dependency no longer appears in the queue as blocked.
Protocol: Work in your own worktree off current main. Never push to main. Never run go test, go build, go vet, linters, node tests or benchmarks locally. Open a PR without the perf label so mark-ready sets ready-to-merge. Call beacon_watch_pr. CI supplies every check.
