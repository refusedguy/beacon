Статус: done

Зависимости: BS.34
Ссылка: ADR 0203

Цель: Единый список фоновых задач и карточек.
Контекст: Сервер расширяет спектр задач за пределы PR.
Шаги: Проекции jobs, cards и их связей, фильтры по типу и статусу.
Проверка: Карточка с замерженным PR видна как кандидат на закрытие.
Приёмка: Проекции не содержат секретов.

## Подтверждение
- Premise проверен 2026-11-20, дубль не создан. Функциональность уже в origin/main: PR #462 (commit bf40b09) добавил `internal/infra/server/api_tasks.go`, ровно OwnerFiles этой карточки. `TaskProjection.List` читает три проекции через порт `TaskSource` (Jobs, Cards, Links), собирает единый список `Entry` и сохраняет `Link` только когда обе конечные точки прошли фильтр. `TaskFilter` фильтрует по типу и статусу после trim, пустое поле означает отсутствие ограничения. Связь job с card через `Link` показывает карточку с замерженным PR в общей выдаче как кандидата на закрытие. Приёмка соблюдена: `Entry` содержит только поля kind, id, type, status, title и phase, а `Secret` и `Payload` из `JobRow` и `CardRow` в ответ не попадают. Статус done зафиксирован коммитом 5574278. Этот PR добавляет только строку обоснования, код в OwnerFiles не меняется.
