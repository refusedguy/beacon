# CO-03. Общая папка handoff для агентов на разных машинах

Тип: task

baseline: `git grep -n -i -E 'shared folder|sharedfolder' origin/main -- docs internal cmd` дал 0 совпадений на коммите `2d34645b`. Handoff сейчас живёт в ответе `beacon_task_claim` и в тексте wake, а карточки лежат в git.

Цель: Дать всем агентам оркестра общее место для планов, находок, заметок и handoff, которое не зависит от их worktree.

Контекст: Источник: Factory Workstreams, страницы Shared folder и CVE Remediation, <https://docs.factory.com/workstreams/shared-folder.md>, <https://docs.factory.com/automations/cve-remediation.md>. Оркестратор и каждый агент читают и пишут одни и те же документы на всех машинах workstream. Туда кладутся планы, заметки, находки, handoff, отчёты и результаты. Код остаётся в репозитории и уходит PR. В CVE-потоке в общей папке лежат настройки listener, инструкции fix droid и список задач. Документ предупреждает, что запись в папку равносильна изменению поведения агентов, поэтому доступ к записи нужно ограничивать.

Шаги: Описать порт `SharedFolder` с операциями Put, Get и List по ключу `(workstreamID, kind, name)`. Ограничить kind значениями `plan`, `note`, `finding`, `handoff`, `deliverable`. Реализовать файловую реализацию в каталоге состояния вне worktree агентов с атомарной записью через временный файл и переименование. Отвергать имена с переходом в родительский каталог и абсолютные пути. Добавить манифест с версией и временем записи, чтобы другой агент видел, что документ обновился. Покрыть тестами: два агента с разными worktree читают одну запись, небезопасный путь отвергается, прерванная запись не портит прежнее содержимое. Описать в `docs/runbooks/shared-handoff.md`, кто имеет право писать инструкции и как отличить handoff от результата.

Проверка: CI зелёный. Тест показывает, что запись агента A видна агенту B без копирования через PR и что переход в другой каталог отклоняется. Ни один тест не требует сети.

Приёмка: Изменения только в OwnerFiles карточки. Карточки в `docs/tasks/` остаются источником истины. Общая папка не заменяет handoff в claim и не пишет в worktree агентов.
