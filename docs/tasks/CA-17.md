# CA-17. Выбор разделителя блоков по содержимому файла
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/app/prcreate/cards.go, docs/templates/executor-task.md
Зависимости: 
Ссылка: docs/research/comp-aider.md
Агент: нет
Время: нет
Цель: Подбирать длину backtick-забора под содержимое, чтобы не ломать markdown.
Контекст: Источник: docs/research/comp-aider.md, дополнение к CA-03. aider перебирает кандидаты заборов и берёт первый, который не встречается в начале строк всех файлов контекста; при отсутствии such варианта он предупреждает и возвращает первый (`aider/coders/base_coder.py:609-635`). В beacon текст PR строится из заголовка и строк карточки без проверки разделителей (`internal/app/prcreate/cards.go:18-21`), а документы в PR должны обновляться в той же ветке (`docs/templates/executor-task.md:155-170`). Файл с тремя backticks ломает такой блок. Baseline: один сломанный PR-блок на каждыйтакой файл.
Шаги: Добавить функцию выбора забора по содержимому и применять её при рендере карточек, PR-тел и сгенерированных документов. При отсутствии безопасного забора предупреждать. Не менять уже опубликованные PR.
Проверка: Взять 10 файлов: 5 с последовательностью из трёх backticks и 5 без неё. Требовать, что для всех 10 выбранный забор не встречается в начале строк, а сгенерированный markdown парсится обратно в исходный текст. Baseline 5 сломанных.
Приёмка: Все 10 блоков рендерятся без потери содержимого, предупреждение появляется только при отсутствии безопасного забора.
