# PSK-01. Протокол кандидатов для спорных проектных решений
Статус: todo
Фаза: P8
Тип: task
Владелец файлов: AGENTS.md, docs/templates/orchestrator-task.md
Зависимости: 
Ссылка: https://raw.githubusercontent.com/cursor/plugins/main/pstack/skills/arena/SKILL.md
Агент: нет
Время: 2026-11-22
Цель: Добавить в Beacon протокол, в котором несколько кандидатов решают одну задачу, независимый судья оценивает их по рубрике, а финальный вариант собирается из лучших частей.
Контекст: Источник: docs/research/research-pstack-skills.md, строка таблицы arena и доказательство 1. В `AGENTS.md:121-123` записано правило «один сигнал равен одному spawn»: оркестратор запускает одного сабента на свободный слот. Каждому агенту принадлежит своя карточка, поэтому один и тот же вопрос не получает нескольких независимых решений. `git grep -i -E 'cross-judge|прививка' origin/main -- docs README.md AGENTS.md` не дал строк. В `docs/templates/` лежат три файла: executor-task.md, orchestrator-task.md, wiring-card.md. Рубрики, кросс-судьи из другого вендора и переноса лучших частей в отобранную основу в Beacon нет. Риск: средний. Протокол меняет только документы агента, не меняет протокол Watch и число MCP-инструментов.
Шаги: Описать в `docs/templates/orchestrator-task.md` шесть фаз: рамка, разведение кандидатов, кросс-оценка, выбор основы, прививка, проверка. Для рамки потребовать артефакт и 3-6 проверяемых критериев, которые видит только судья. Для разведения потребовать отдельный worktree каждому кандидату и одинаковый текст задачи. Для кросс-оценки потребовать судью из вендора, отличного от вендора исполнителя. Для прививки потребовать ручное перенесение одной или двух идей от каждого проигравшего с указанием источника. Добавить в `AGENTS.md` отсылку к протоколу и правило применять его только для спорного проекта. Не менять `beacon_watch_pr` и число инструментов.
Проверка: `git grep -n -E 'рамка|кросс-оценка|прививка' docs/templates/orchestrator-task.md` находит все шесть фаз. `git grep -n 'PSK-01' AGENTS.md` находит отсылку. В протоколе указано, что при согласии кандидатов прививка не нужна, а при расхождении рамка пересматривается.
Приёмка: Протокол описывает спорный дизайн без изменения протокола Watch и без новых зависимостей. Любая карточка, которая ссылается на PSK-01, содержит рубрику и решение судьи. Для механической работы протокол не применяется.
