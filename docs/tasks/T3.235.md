# T3.235. Scope-токены и privilege ceiling для adapter
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/opencode/server.go
Зависимости: T3.228
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Ограничить wake и управление обязательствовами по environment, потоку и сессии провайдера.
Контекст: T3 выдаёт токен на environment, parent thread, provider instance и provider session с TTL и idle expiry; raw token не пишется в состояние.
Шаги: Описать выдачу, проверку capability в handler, отзыв при освобождении сессии и разделение прав на wake, read status и stop.
Проверка: Токен от другой сессии не может изменить obligation; после истечения вызов отклонён.
Приёмка: Сырой токен отсутствует в store и в диагностике.
