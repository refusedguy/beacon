Create all children in one operation, set each child's `DependsOn` from the plan, make the epic depend on every child, and set each child's `BaseBranch` to the epic branch `beacon/<epic-id>`. Add idempotency keyed by epic ID plus sorted child titles: a repeated create returns the existing IDs instead of duplicating cards. Roll back files already written if any step fails. Persist the graph with SyncTasks. Add tests for expansion, idempotency and rollback. Do not change ScmGateway yet. Run gofmt and targeted tests, open a PR and call beacon_watch_pr.
