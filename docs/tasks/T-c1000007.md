## Goal
Stop decision signature memory from growing with run count in a long-running daemon.

## Evidence
From T-baadf270: decisionCache.sigs stores one signature per run forever, about 80 KB now and 15 to 20 MB at 100,000 runs. The live db holds 12,566 decisions after four days.

## Steps
Add LRU eviction to decisionCache.sigs capped at a few thousand entries. Keep a cache hit returning the same verdict as today. Add tests in internal/app/decisionlog_test.go for the cap and eviction order.

## Accept
Signature memory stops growing with run count, and snapshot latency is unchanged.
