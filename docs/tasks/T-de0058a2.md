Goal: cut synchronous disk reads and repeated queue grouping in the plugin sidebar.

Evidence: ui_model.js:238 readCard calls existsSync, readFileSync and frontmatter parsing on every card and every run during each five second poll. ui_alerts.js:258 calls queueGroups and queueLineItems calls it again on the same array. ui_model.js:392 RpcStatusSource normalizes an already normalized snapshot.

Variants: V1 pass the queueGroups result into queueLineItems through an optional argument and remove the second pass. V2 add a bounded Map cache in readCard keyed by path with statSync mtimeMs and size, bypassing the cache when deps lacks statSync so existing tests stay green; add a readFileSync counter test. V3 skip normalizeSnapshot at the RpcStatusSource boundary without changing field order.

CI commands: node docs/perf/plugin_grouping_bench.mjs, node internal/bench/ui_bench.js, node --test '.opencode/plugins/beacon-project/**/*_test.js'. Limiter: synchronous fs.readFileSync and repeated queueGroups.
