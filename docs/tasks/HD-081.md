## Подтверждение
- Дубль: сверка PR с формулировкой issue уже в main. `verifyIssueEvidence` и `evidenceCheckStep` в `cmd/beacon/orchestrate.go` (HD-009, ADR 0292) сверяют ссылки issue `file:line` с текущим кодом. `EvidenceNoRef` с `clearsForWork=false` не принимает утверждение без доказательства до работы, то есть PR без связи с issue не проходит. `EvidenceOutdated` помечает изменившуюся или исчезнувшую ссылку устаревшим до работы; слепое принятие проваливает карточку. Покрыто `TestVerifyIssueEvidence` и `TestVerifyIssueEvidenceReportsActual`.
