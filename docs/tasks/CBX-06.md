Разрыв в beacon: internal/infra/batchapply/apply.go:1-4 создаёт ADR, карточки и eval-документы одним проходом, Options на :96-116 не имеет ни размера куска, ни паузы, ни прогресса; package init не различает читателей и писателей во время записи.

Шаги: Добавить настраиваемый размер куска и паузу в Options batchapply. Разбить запись артефактов на куски с фиксацией после каждого. Ввести швы для часов и для writer прогресса. Сделать размер и паузу переменными, чтобы тесты могли их уменьшать. Добавить отчёт о числе кусков и времени удержания замка.

При нулевой паузе в тестовом стенде читатель не получает замка, что воспроизводит исходный дефект. Прогресс содержит 20 строк.
