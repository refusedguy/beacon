# T3.8. Шаблон задания оркестратора: не мержить без get_result verdict ready

Статус: in_progress
Фаза: P3
Тип: task
Владелец файлов: docs/templates/orchestrator-task.md
Зависимости: T2.6, T3.7
Ссылка: ADR 0001
Агент: нет
Время: 2026-11-19T16:30:00Z

Цель: Запретить оркестратору мержить PR без `beacon_get_result` с verdict=ready и обязать его проверять вердикт перед каждым мержем.

Контекст: WORKER-PROMPT §4.7 указывает, что idle-отчёт ребёнка не означает готово, потому что V2 шлёт `<subagent>`-отчёт родителю при каждом завершении раунда. Мерж разрешён только после `get_result` с verdict=ready, идемпотентность мержа ведётся по `(watchID, revision)`, возврат исполнителя на доработку это решение оркестратора. D2 убирает авто-мерж Beacon из скоупа. ADR 0001 требует от оркестратора чека перед мержем: критерии приёмки, скоуп, ревью, branch protection. BEACON-AUDIT в приёмке P3 описывает тест «преждевременный idle-отчёт» и проверку, что двойной prompt даёт один мерж (§13, T3.2).

Шаги:
1. Создать `docs/templates/orchestrator-task.md` с правилом: мерж только после `beacon_get_result` и только при verdict=ready.
2. Включить чек перед мержем по четырём пунктам ADR 0001: критерии приёмки, скоуп, ревью, branch protection.
3. Записать ключ идемпотентности мержа `(watchID, revision)` и правило, что повторный prompt с тем же ключом не создаёт второй мерж.
4. Явно указать, что `<subagent>`-отчёт о завершении раунда не является вердиктом и что возврат исполнителя на доработку решает оркестратор.
5. Добавить тест: симулировать idle-отчёт ребёнка и двойной prompt с одним watchID и revision.

Проверка: Тест подтверждает, что после idle-отчёта мерж заблокирован, после ready с пройденным чеком мерж разрешён, а повторный prompt с тем же `(watchID, revision)` не создаёт второй мерж. В шаблоне нет авто-мержа со стороны Beacon.

Приёмка: Оркестратор не мержит без ready из get_result. Чек перед мержем описан. Двойной prompt даёт один мерж. Возврат исполнителя остаётся решением оркестратора.

Гейт: G2. Шаблон применяется владельцем вместе с конфигом.
