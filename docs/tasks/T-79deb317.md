Goal: A missing or poisoned baseline must not produce a green nightly run.

Evidence: ciopt-09 item 3. A baseline captured during a load spike hides regressions, and a regressed passing run publishes slower numbers as the new baseline. continue-on-error on download plus an if guard make a missing baseline green by omission.

Steps: Fail or report an explicit warning when the baseline download fails. Add a sanity bound so a baseline far above the recorded median cannot become the new reference.

Check: A deliberately missing baseline and an inflated baseline both fail or warn visibly.

Accept: Keep the 2 percent noise floor and the 15/20 percent regression limits unchanged.
