## Подтверждение
- PR #394 DROPPED: MCP-native обзор уже описан в README и AGENTS.md: beacon_list_running и beacon_stats читают состояние, пробуждение приходит в TUI агента через плагин; docs/ui-mcp-native.md в main отсутствует, новый процесс не создаётся. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
