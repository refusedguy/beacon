Цель: Упорядочить Watch по времени, вердикту и приоритету.
Контекст: Стабильный порядок важен, чтобы обновление не прыгало по экрану.

## Подтверждение
- PR #394 DROPPED: Стабильная сортировка уже в watch.go (sort по watchID) и вв store; UI-компонент sort.go отсутствует. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
