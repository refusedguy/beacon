# BS.31. Cron-проверки карточек и дедлайнов
Статус: done
Фаза: P2
Тип: task
Владелец файлов: internal/app/scheduler/card_check.go
Зависимости: BS.24
Ссылка: ADR 0203
Агент: нет
Время: нет
Цель: Карточка проверяется по расписанию без агента.
Контекст: Спектр задач сервера включает мониторинг карточек.
Шаги: Задача по id карточки, проверка статуса и дедлайна, событие при изменении.
Проверка: Просроченная карточка produces wake ровно один раз.
Приёмка: Повтор запуска не дублирует уведомление.

## Подтверждение
- Premise проверен: функциональность уже в main. `internal/app/scheduler/schedule.go` задаёт cron-расписание через `KindCron`, `internal/app/scheduler/card_check.go` проверяет статус, OwnerFiles и зависимости через `CanSchedule`, `internal/app/tasks/card_monitor.go` выдаёт событие при смене статуса карточки по её id. Дедлайн и защита от повтора есть в `internal/app/tasks/reminders.go`: `Plan` возвращает напоминание для просроченной задачи, а `ReminderLedger` отбрасывает вторую отправку для той же пары задача и дедлайн. Это закрывает проверку и приёмку BS.31. PR #456 с реализацией уже влит в main, дубль в OwnerFiles не писал.
