# BS.31. Cron-проверки карточек и дедлайнов
Статус: done
Фаза: P2
Тип: task
Владелец файлов: internal/app/scheduler/card_check.go
Зависимости: BS.24
Ссылка: ADR 0203
Агент: нет
Время: нет
Цель: Карточка проверяется по расписанию без агента.
Контекст: Спектр задач сервера включает мониторинг карточек.
Шаги: Задача по id карточки, проверка статуса и дедлайна, событие при изменении.
Проверка: Просроченная карточка produces wake ровно один раз.
Приёмка: Повтор запуска не дублирует уведомление.
