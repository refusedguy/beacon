Goal: stop real secrets from reaching stored reasons, worker prompts and loopback responses while logs stay clean.
Evidence: github.go:163 and github_base.go:24 copy raw CI output into FailureExcerpt while the GitLab adapter redacts its equivalent; that excerpt reaches MergeDecision.Reason, run.Reason, sqlite rows, GET /api/v1/runs and MCP results. ACP sends WakeTextLimited verbatim while OpenCode redacts. beacon_reconcile puts raw decision.Reason and err.Error into a tool result after only redacting the slog line. telegram.go:50 returns a URL error containing the token. The redaction rules miss the opencode:HEX token shape. Doctor and root Execute print raw errors that can embed config scalars.
Steps: redact at the SCM adapter boundary for both providers; redact at prompt assembly for WakeTextLimited, fixerPrompt and spawnPrompt or in the ACP prompt to match OpenCode; build a redacted copy of ReconcileResult before jsonResult; wrap the Telegram Do error with redact.Redact; add a rule for the opencode token shape; redact doctor and root Execute output; redact before sqlite writes as a second boundary. Add tests that a failing check containing a token produces a redacted reason in sqlite, loopback and tool result.
Accept: a synthetic secret in CI output, an SCM error or a Telegram URL cannot be read from any stored row, prompt, tool result or HTTP response.
