# CV-13. Красный фильтр для записи карточек в markdown

Premise: проверено 2026-11-22 по `origin/main` `e2f34a060579d452c1ca6ca7845560b78b8b7629`. Источник: OpenHands `src/stores/secret-request-store.ts:66-80` держит введённое значение секрета только в памяти: оно намеренно не попадает в localStorage, чтобы не оказаться на диске и не перезаписывать список запросов при каждом нажатии. `src/services/secret-request.ts:75-81` возвращает агенту результат без значения секрета даже при ошибке.

Разрыв: `internal/infra/store/redaction.go:3-8` объявляет один фильтр для всех записей в состояние, но применяется он только к параметрам SQL через `redactingConn` на `:48-107`. Запись карточек идёт мимо этого фильтра: `writeClaimFile` в `internal/infra/mcp/tool_task_claim.go:590` пишет сырые байты, а `applyCloseFields` в `internal/infra/mcp/tool_task_close.go:315` вставляет произвольную строку `Причина` в файл через `writeCloseFile` на `:495`. Карточки хранятся в git, поэтому секрет, попавший в `Goal` или `Причина`, становится частью публичной истории PR.

baseline: `rg -n 'Redact' internal/infra/mcp/tool_task_close.go internal/infra/mcp/tool_task_claim.go` = 0. `rg -n 'redactingDriverName|CheckNamedValue' internal/infra/store/redaction.go` = 4, все строки относятся к SQLite. `rg -n 'func applyCloseFields' internal/infra/mcp/tool_task_close.go` = 1, строка 315.
