Goal: a run leaves the running state when its agent session is cancelled or deleted, without waiting for an operator to notice.

Evidence: HandleHarnessEvent at internal/app/idle.go:51 handles idle and PR registration but has no death case. closeOrphan at idle.go:191-205 already applies EvCancel with reason `worker session exited without PR`, saves, releases the idle nudge, notifies the parent and cleans up. run.go:123 makes EvIdleNudge a self transition on running, so an idle nudge posts to a dead session. The orphan sweep at idle.go:182-185 runs every tick but needs IsAlive false, so a cancelled session that answers 200 never triggers it.

Steps: add the `session_dead` kind to HarnessEvent at pkg/core/ports.go:84-90. Branch in HandleHarnessEvent at internal/app/idle.go:51 on that kind and call closeOrphan with a clear reason instead of nudging. Keep the 90 second orphan sweep as a backstop. Add internal/app/session_death_test.go proving a death event closes the run and frees its slot, and that the backstop still closes a stale running run.

Accept: cancelling a session closes the run within one tick, the slot frees, and the next dispatch does not report that the task already has an active run.
