Goal: a card with an empty or malformed Scope must not become an all-files claim that overlaps every run.
Evidence: with strict_scope unset, planner.go:99-109 treats an empty scope as a:* so the card conflicts with every active run. .beacon/config.yaml does not set strict_scope. This is a marginal but immediate source of skipped cards.
Steps: set strict_scope: true in .beacon/config.yaml; add it to restartFields in cmd/beacon/config_watch.go only if changing it requires a restart, otherwise leave it reloadable; add a test that an empty scope card is rejected from ready tasks under strict mode.
Accept: no card without a valid explicit scope can enter dispatch.
