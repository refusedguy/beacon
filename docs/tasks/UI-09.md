# UI-09. Экран Stats
Статус: dropped
Фаза: P1
Тип: task
Владелец файлов: internal/ui/screens/stats.go
Зависимости: UI-05
Ссылка: ADR 0072 (proposed)
Агент: нет
Время: нет
Цель: Видно число активных Watch, обязательств, доставок и ошибок адаптера.
Контекст: beacon_stats уже отдает счетчики, UI должен их прочитать, а не считать заново.
Шаги: Показать счетчики из снимка state и подсветить ошибки адаптера.
Проверка: Тест с нулевыми и предельными значениями счетчиков.
Приёмка: Числа совпадают с beacon_stats на том же state.

## Подтверждение
- PR #394 DROPPED: Счётчики уже отдаёт beacon_stats (PointsThisHour, Budget, ActiveWatches, Persist, LoadErrors, Ladder, Version); дубль в UI-экране не нужен. Отдельный бинарник beacon-ui и пакет internal/ui в main отсутствуют; принятый ADR 0060 прямо отклоняет собственный TUI и веб-интерфейс ("Свой TUI или веб-интерфейс не создаётся"), ядро MCP-only (ADR 0086) с контрактом ровно семи инструментов (ADR 0094). Ссылка карточки на "ADR 0072 (proposed)" неверна: ADR 0072 принят и описывает авто-мерж, а ADR 0092-tui только proposed и противоречит ADR 0060.
