Цель: Задача, которой агент задал вопрос, переходит в needs_input; ответ человека возвращается в ту же задачу через submit(continue_of=…) с ограничением числа раундов; wait_result продолжает ожидание после ответа, не создавая новую задачу.

Проверка: Тесты перехода в needs_input и из него; лимит раундов; отсутствие новой задачи после ответа.
Приёмка: Ответ человека возвращается в исходную задачу, wait_result продолжает ожидание, число раундов ограничено.
