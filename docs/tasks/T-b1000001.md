Goal: give the daemon configuration for slot refilling on each tick and for state-age alerts, with both features off by default.

Evidence: Reconciler.Run calls only PromotePending, so a queue that empties stays empty while agent slots idle. Two audits proposed an auto top-up Dispatch port gated by config. The only wall-clock health check is the orphan sweep in internal/app/idle.go:106, which acts on running runs with PRNumber zero after 90 seconds. Runs in waiting_ci, needs_rebase, needs_agent_fix or blocked can keep a fresh UpdatedAt from observations and never alert.

Steps:
1. Add an auto_dispatch section in internal/infra/config/config.go with enabled default false, batch_size default equal to free agent slots, and dispatch_open default true. dispatch_open is the brake that freezes intake for maintenance or a red base. Keep these fields out of restartFields in cmd/beacon/config_watch.go so a hot reload cannot change them without a restart.
2. Add a watchdog section with an enabled flag and per-state ages for waiting_ci, needs_rebase, needs_agent_fix and blocked. Use defaults that do not change behavior until enabled. Keep the existing orphan timeout as the running-without-PR policy in internal/app/idle.go.
3. Add tests in internal/infra/config/autodispatch_watchdog_test.go for the three auto_dispatch defaults, the watchdog disabled default, and parsing of each watchdog age.

Accept: a fresh checkout keeps the current behavior, an operator can enable either feature through config, and no new hot-reload field reaches cmd/beacon/config_watch.go.
