# T3.395. Перестать называть любой retry rebase в наблюдаемости
Premise: проверено 2026-11-21 по origin/main (2815432), дубля нет. Карточка просит, чтобы retry wake не поднимал счётчик rebase. В wakeOne (internal/app/orchestrator/orchestrator.go) стояло `if verdict != VerdictWait`, поэтому RebaseRequested вызывался для retry, fail и любого другого verdict, кроме wait. Событие wake_requested уже пишется для всех verdict и несёт verdict и reason, поэтому отдельный rebase-сигнал нужен только для verdict=rebase. `git grep -n 'RebaseRequested' origin/main -- 'internal/app/orchestrator/*.go'` даёт одну строку. В origin/main карточка имеет Статус todo и ноль строк Premise, PR по T3.395 до этого отсутствует. Живой зонд не нужен: поведение проверяется юнитом wakeOne и метрикой rebase_requests_total. Условие сужено до `verdict == VerdictRebase`, добавлен тест на retry и rebase. Код написан в OwnerFiles, gofmt применён. Тесты локально не запускались по правилу AGENTS.md, проверку проведёт CI на PR.
baseline: `git grep -n 'RebaseRequested' origin/main -- 'internal/app/orchestrator/*.go'` = 1 строка; Premise в origin/main = 0; `gofmt -l` по двум go-файлам пуст; `git diff origin/main --stat` = 2 go-файла, 40 добавлено, 1 удалено.
