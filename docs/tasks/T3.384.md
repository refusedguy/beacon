# T3.384. Авто-подписка оркестратора на активные Watch
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/app/orchestrator/subscribe.go, internal/app/orchestrator/subscribe_test.go, cmd/beacon/subscribe.go, cmd/beacon/subscribe_test.go
Зависимости: 
Ссылка: ADR 0156
Агент: нет
Время: нет
Цель: Гарантировать, что у каждого активного Watch проекта есть обязательство подписчика с ролью orchestrator.
Контекст: Роль orchestrator уже есть в словаре домена, Fanout.Subscribe идемпотентен по подписчику. Daemon сейчас регистрирует оркестратора только на Watch, найденных checkall. Лимит в 50 Watch на подписчика действует, поэтому пропуск нужно показывать, а не прятать.
Шаги: Добавить SubscribeAll(ctx, watches, register) в internal/app/orchestrator/subscribe.go. Для каждого Watch без подписчика orchestrator вызвать register с ролью orchestrator и notify opencode:beacon-orchestrator. Повтор вызова с тем же подписчиком продлевает обязательство и не двигает ревизию. В cmd/beacon/subscribe.go собрать register-порт поверх существующего обработчика beacon_watch_pr. При LIMIT_EXCEEDED вернуть список непокрытых watchID для сводки.
Проверка: Повторный проход не создаёт второе обязательство и не меняет ревизию. Watch с подписчиком executor получает отдельного подписчика orchestrator. Blocked Watch тоже покрывается. При лимите 51-й Watch попадает в uncovered.
Приёмка: Каждый активный Watch проекта имеет обязательство оркестратора или явно перечислен в uncovered. Роль executor и его обязательство не затронуты. Восьмой MCP-инструмент не добавлен.
