# T3.243. Типы защита ввода
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.242
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Поддержать режимы off, hold, draft-aware, queue-only.
Контекст: Typing guard в OpenRig имеет роли off по умолчанию, draft-aware, hold и queue-only, legacy boolean fail safe в hold.
Шаги: Реализовать перечисление, audited set-permissions и held messages с просмотром и release.
Проверка: При недоступности появившегося ввода сообщение удерживается, а не теряется.
Приёмка: Человек, печатающий в pane, не получает автоматический текст.
