# T3.243. Типы защиты ввода
Статус: done
Фаза: P3
Тип: task
Владелец файлов: internal/infra/server/followups/typing_guard.go, internal/infra/server/followups/typing_guard_test.go
Зависимости: T3.242
Ссылка: ADR 0087
Агент: нет
Время: нет
Цель: Поддержать режимы off, hold, draft-aware, queue-only.
Контекст: Typing guard в OpenRig имеет роли off по умолчанию, draft-aware, hold и queue-only, legacy boolean fail safe в hold.
Шаги: Реализовать перечисление, audited set-permissions и held messages с просмотром и release.
Проверка: При недоступности появившегося ввода сообщение удерживается, а не теряется.
Приёмка: Человек, печатающий в pane, не получает автоматический текст.

## Подтверждение
- PR #1147: https://github.com/refusedguy/beacon/pull/1147. Добавлена чистая модель typing guard в internal/infra/server/followups/typing_guard.go. Четыре режима, функция выбора действия, held messages с просмотром и release, журнал аудита. Модель не выполняет I/O и не меняет адаптер доставки.
- Тест в typing_guard_test.go покрывает все четыре режима, включая fail-safe при неизвестном состоянии ввода и разницу между hold и draft-aware.
- Проверка gofmt -l пройдена. go test и go build оставлены CI по правилам задачи.
- Живой pane-зонд с эмуляцией набора текста в этой среде недоступен. Приёмка с человеком, печатающим в pane, остаётся за таким зондом.
