Implement the epic lifecycle in the reconciler. Children auto-merge into their epic branch; when all children are done, open the epic PR against main with ScmGateway.OpenPR. By default run an LLM reviewer on the epic PR and auto-merge when the review passes. Support `require_review: human` to wait for manual approval, and `require_review: none` to skip review. Use BaseIncident with BaseBranch equal to the epic branch when CI there is red, so children block and a fixer is spawned. Add tests for child merge, epic PR open, LLM review default, human gate and red epic branch. Run gofmt and targeted tests, open a PR and call beacon_watch_pr.
