# T3.443. Eval: plain ack не останавливает демон, blocked останавливает
Premise: проверено 2026-11-21 по origin/main (17270fe), дубля нет, но для приёмки нужен живой зонд. Карточка просит eval-сценарий с двумя ack и разными ожиданиями: plain ack оставляет wake активным, blocked останавливает его. Зависимость T3.412 в main имеет статус done, поэтому команда blocked уже понимает tool_ack.go:26-29 и 64-72, а daemon.go:219-220 описывает отдельный маршрут blocked wake. Код для проверки есть. В evals/main.go записаны четыре сценария B01-B04, но ни один не прогоняет два ack подряд с негативным контролем по wake. Приёмка карточки требует зелёного evals/run.sh. Скрипт запускает `go run -tags=eval .` с настоящим MCP-сервером и SQLite, а на слабом ПК доступны только текст и gofmt. Живой зонд недоступен, поэтому сценарий написать можно, но подтвердить негативный контроль я не могу. Статус todo сохранён, блокер возвращён оркестратору. OwnerFiles не менял, код не писал, gofmt не применял, дубль не создал, правка только текстовая.
