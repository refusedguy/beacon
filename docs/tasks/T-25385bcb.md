Goal: an invalid config edit must not be permanently ignored.
Evidence: reload at cmd/beacon/config_watch.go:174-179 stores cw.hash = sum before loadConfig succeeds. The next tick sees no change and never retries the edited file.
Steps: assign cw.hash only after loadConfig and cfg.Complete succeed; keep the previous state on failure; add a test that writes invalid YAML then valid YAML and asserts the watcher reloads on the second tick.
Accept: after an invalid edit is corrected the watcher applies the new config without restart.
