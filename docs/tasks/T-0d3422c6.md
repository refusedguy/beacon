Goal: Make the hot paths measurable with one repeatable command.

Evidence: The repo has no func Benchmark, and CI has no bench step. Every performance claim today is a guess from source reading.

Scope: internal/bench/** and docs/perf.md.

Steps: Add Go benchmarks for sqlite snapshot queries, task card parsing, JSON wire encoding, redaction, MCP journal and SSE fanout. Add a Node timing script for plugin grouping. Seed fixtures with realistic sizes. Print median and range, work counts, error counts, the named limiter and the end-to-end share for each micro result. Write docs/perf.md with the protocol: five alternating runs, production settings, no -race, fixed GOMAXPROCS.

Check: go test -bench=. -benchmem -count=5 ./internal/bench/ and the Node script each emit a report. A second run on the same machine stays within 15 percent of the first median.
