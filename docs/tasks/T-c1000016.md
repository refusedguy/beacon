## Goal
Preserve comparison evidence from the perf job through to the PR comment and artifact.

## Evidence
From T-a697580c: ci.yml says No comparable rows; see the artifact while the artifact step permits no files. ci.yml writes measurement trees differ, then the pass step truncates perf-status so the note is lost. This is a 1485-line hot singleton, kept whole because it cannot be split across cards without breaking single ownership. The 1200-line cap is exceeded by this one file only.

## Steps
Create perf-status before the hash step. Append rather than truncate. Carry a comment-builder failure into the advisory comment. Require the artifact to contain at least one comparison row or an explicit no-baseline marker.

## Accept
Every advisory perf note survives to the PR comment, and the artifact always explains an absent baseline.
