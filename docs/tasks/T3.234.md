# T3.234. Отдельный MCP entry для blocking wait
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/mcp/server.go
Зависимости: T3.228
Ссылка: ADR 0083
Агент: нет
Время: нет
Цель: Сделать блокирующие инструменты доступными напрямую в средах с Code Mode.
Контекст: T3 регистрирует t3-code и t3-code-direct; второй содержит только t3_thread_wait и delegate_task с omit_tools_from code_mode и deferred, потому что Code Mode отдаёт скрипт примерно через 30 секунд.
Шаги: Выделить wait и delegate в отдельный registration, описать presentation инструментов с двумя именами сервера.
Проверка: Модель видит прямое имя инструмента и не начинает опрашивать wait через скрипт.
Приёмка: Оба имени разрешаются в one tool, pending-work detection не ломается.
