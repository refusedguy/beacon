# T3.208. Events как подсказка, состояние как источник истины
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: internal/infra/wake/deliver.go, internal/infra/wake/deliver_test.go
Зависимости: T3.205
Ссылка: ADR 0080
Агент: нет
Время: нет
Цель: Не терять обязательства при потерянных событиях и дублирующих сигналах.
Контекст: Cursor: список source of truth, доставка best-effort, курсор живёт пять минут. Kilo: истина в durable-записи, dirty signal ёмкости один. Pi Chord: events не хранятся и не идут поздним подписчикам.
Шаги: Применять события идемпотентно по ID; периодически делать полное чтение с джиттером; не хранить курсоры между процессами; на 410 и cursor_expired делать ре-list.
Проверка: Пропущенное событие восстанавливается полным чтением; повтор события не меняет состояние; старый seq или revision отбрасывается.
Приёмка: Нет зависимости от автоматического reconnect; потеря webhook не теряет obligation.
