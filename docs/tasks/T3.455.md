# T3.455. Typed attention codes

Статус: done
Фаза: P2
Тип: task
Владелец файлов: internal/domain/attention.go, internal/app/orchestrator/workload.go, internal/domain/attention_test.go, docs/tasks/T3.455.md
Зависимости: T3.418
Ссылка: ADR 0203
Агент: executor
Время: 2026-11-21
Цель: Выдать список причин внимания вместо одного флага.
Контекст: OpenRig: trust_gate, login_required, update_gate, mcp_gate, codex_auth_refusal и другие; attention поднимает needsAttention. Beacon берёт из этого списка только четыре вердикта, которые уже блокируют Watch: retry, rebase, keep_working и timeout. Коды trust_gate, login_required и attention_required проект отклонил в PR #394, карточка T3.263 остаётся dropped и не возрождается.
Шаги: Добавить доменный тип Attention с уровнем, причиной и следующим действием; заменить булеву функцию needsAttention классификатором, который возвращает типизированную причину; группировать счётчик внимания по причинам; покрыть классификацию и компактный код тестом. Ложное значение означает «нет известного триггера», а не proof clear.
Проверка: Неизвестный источник даёт ? в компактном выводе.
Приёмка: Внимание объяснимо.

## Реализация
baseline (2026-11-21, origin/main @ c6cff98): `git grep -n 'func needsAttention(' origin/main -- internal/app/orchestrator/workload.go` = 1; `git grep -n 'NeedsAttention' origin/main -- cmd/beacon/workload.go` = 1; `rg -n 'func needsAttention\(|needsAttention\(' cmd internal` после правки = 0; `rg -n 'ByAttention' cmd internal` = 4; `rg -n 'func AttentionForVerdict\(' internal` = 1; `rg -n '^func Test' internal/domain/attention_test.go` = 3.

`internal/domain/attention.go` определяет `AttentionLevel`, `AttentionReason` и `Attention{Level, Reason, NextAction}`. `AttentionForVerdict` превращает вердикт в типизированную причину. `Compact` возвращает одну букву для известной причины и `?` для неизвестной. Нулевое значение означает отсутствие известного триггера, а не доказательство того, что Watch чист.

`internal/app/orchestrator/workload.go` заменил функцию `needsAttention(verdict) bool` на `attentionForVerdict(verdict) workloadAttention`. Приложение не импортирует `internal/domain` по ADR 0005, поэтому значения зеркалятся строками. `Workload.ByAttention` группирует заблокированные Watch по причинам, а существующее поле `NeedsAttention` осталось ради вывода таблицы в `cmd/beacon/workload.go`.

`internal/domain/attention_test.go` проверяет классификацию четырёх вердиктов, нормализацию регистра и пробелов, нулевое значение для ready, watching и неизвестных кодов, а также компактные коды и `?`.

T3.263 остаётся dropped. Ни один из её кодов не добавлен.

gofmt выполнен локально. `go test` и `go build` выполняет CI.
