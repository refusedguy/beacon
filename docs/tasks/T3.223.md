# T3.223. Смягчение выгрузки локации OpenCode
Статус: todo
Фаза: P3
Тип: task
Владелец файлов: 
Зависимости: T3.216
Ссылка: ADR 0061
Агент: нет
Время: нет
Цель: Выбрать способ, при котором плагин не исчезает из /api/plugin во время ожидания wake.
Контекст: location_idle_timeout по умолчанию 60 минут. При простое локация выгружается, плагин исчезает, polling останавливается. Варианты: false, внешний keepalive или будильник вне OpenCode.
Шаги: Проверить выбранный способ на простое больше 3 минут и зафиксировать результат в W12.
Проверка: При 2 minutes выгрузка примерно через 2 минуты 47 секунд, при false плагин держался больше 3 минут 39 секунд.
Приёмка: Ограничение задокументировано, выбранный способ смягчения проверен.
