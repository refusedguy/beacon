OpenCode shows `Instructions updated` often because `context.js` calls `ctx.session.instructions.entry.put` on every plugin load and after every compaction, even when the text is unchanged. Fix it: before `put`, call `ctx.session.instructions.entry.list({sessionID})`, find the entry with key `beacon/survival-rules`, and skip the write if its value equals SURVIVAL_RULES. On plugin startup write rules only for the current session, not every session in the project. In the compaction hook call the same guarded helper. Add a small JS test with a fake ctx that counts `put` calls: first call writes once, second call writes zero times, changed text writes again. Keep AGENTS.md rules unchanged. Run node --check and targeted JS test, open a PR and call beacon_watch_pr.
