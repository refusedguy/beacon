# T1.12. Redaction на записи и версия схемы в строках журнала
Статус: done
Фаза: P1
Тип: task
Владелец файлов: internal/infra/store/redaction.go, internal/infra/store/redaction_test.go
Зависимости: T1.7
Ссылка: ADR 0012
Агент: нет
Время: 2026-11-19T20:30:00Z
Цель: Провести все записи в базу через один фильтр, который убирает секреты и штампует версию схемы.
Контекст: ADR 0012: каждая строка events.jsonl содержит версию схемы, redaction работает как правило на записи и не даёт секретам попасть в состояние и логи. ADR 0015 переносит версию в журнале и redaction на записи в SQLite; corpus миграций это фикстуры базы до миграции. WORKER-PROMPT §4.2: токен GitHub не попадает в state.json и логи. C §2 требует валидации и нормализации на входе, а не проверки прав sessionID.
Шаги: 1. Реализовать RedactingWriter, оборачивающий единственный writer из T1.7, с фильтрацией токена GitHub, заголовков авторизации и учётных данных в URL. 2. Добавить колонку schema_version в журнальные строки и проставлять текущую версию до вставки. 3. Проверить чтение строк старых версий из corpus миграций.
Проверка: Тест с подставным токеном: секрет не сохраняется в базе и журнале; каждая новая строка имеет schema_version; фикстура старой версии читается без ошибки.
Приёмка: Ни одна запись не минует фильтр, версия строки однозначно определяет обработчик.
