# S1.001. Entry point и жизненный цикл сервера
Статус: dropped
Фаза: P0
Тип: task
Владелец файлов: internal/infra/server/main.go, internal/infra/server/lifecycle.go
Зависимости: 
Ссылка: ADR 0077
Агент: нет
Время: нет
Цель: Один процесс держит состояние и отвечает на start, stop, status, restart.
Контекст: Сейчас состояние разнесено между MCP и плагином.
Шаги: Entry point, pidfile, healthz, graceful drain, единичный lease через файловую блокировку.
Проверка: beacon server start/stop/status, healthz 200, второй start отказывает.
Приёмка: Два последовательных старта дают один слушающий процесс, второй получает понятную ошибку.

## Подтверждение
- PR #394 DROPPED: серверный entry point, pidfile и lease противоречат одному процессу и MCP-only (п.6 DECISIONS_FROM_DIALOGUE, ADR 0086, ADR 0094); internal/infra/server/main.go и lifecycle.go отсутствуют в main; дубль демона.
