Цель: Восемь инструментов описаны везде одинаково, batch-apply --check отклоняет невалидные Тип, Фазу и Статус до записи.
Контекст: Premise: server.go регистрирует восемь инструментов, а README и evals/main.go говорят про семь; --check пропустил Тип spike, из-за чего упал чек test. Дубли ADR 35, индекс ведётся вручную. baseline: `toolsListOrder` в `internal/infra/mcp/contract_test.go` содержит 8 имён. frozenContractToolsHash `b0a23b54…` в evals/main.go равен SHA-256 восьми отсортированных имён, соединённых переводом строки, значит eval уже на 8. ADR 0094 озаглавлен `Восемь инструментов ядра`. В README было 5 мест с числом 7 (строки 11, 22, 43, 50, 218) и таблица из 7 строк. go.mod:3 фиксирует `go 1.26.0`. Индекс docs/adrs/README.md содержал 299 строк при 302 ADR-файлах и вёлся вручную.
Шаги: Синхронизировать число 8, добавить валидацию значений в apply.go до записи, автогенерацию индекса ADR, зафиксировать go 1.26.0.
Проверка: gofmt, go test и гейты в CI.
Приёмка: batch-apply --check возвращает код 1 на невалидном Типе, расхождений 7 против 8 нет.
