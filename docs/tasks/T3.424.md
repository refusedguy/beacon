Фаза: P2
Тип: task
Владелец файлов: internal/infra/store/snapshot.go, cmd/beacon/snapshot.go
Зависимости: T3.396, T3.423
Ссылка: ADR 0191
Агент: нет
Время: нет
Цель: Сохранять конфигурацию и связи executed'ов для recovery.
Контекст: rig down --snapshot и rig up <name> --existing восстанавливают топологию после падения.
Шаги: Писать snapshot config version, role address и bindings; восстанавливать выборочно.
Проверка: После рестарта role адреса и config_id совпадают; отсутствующий snapshot не даёт тихого fallback.
Приёмка: Восстановление не создаёт вторую копию команды.
